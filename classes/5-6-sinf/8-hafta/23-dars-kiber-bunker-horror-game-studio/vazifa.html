1-TOPSHIRIQ 3 BALL

Three.js: Chiroq (SpotLight) va Tuman Zichligi

Quyidagi kod parchasini o'rganing va muhandislik savollariga javob bering:

// 3D Flashlight & Volumetric Darkness
scene.fog = new THREE.FogExp2(0x020408, 0.08);
const spotLight = new THREE.SpotLight(0xfff1dc, 3.8, 26, Math.PI / 4.2, 0.45, 1.4);

1) Agar tuman zichligi 0.08 dan 0.25 ga ko'tarilsa, o'yinchining ko'rish masofasi nima bo'ladi?
2) Nega chiroq kameraga (camera.add(spotLight)) biriktirilgan?

Muhandislik Kaliti:
1) Tuman 0.25 ga oshirilsa, qora zulmat 2-3 metr masofadanoq boshlanadi — o'yinchi deyarli ko'r bo'lib qoladi va qo'rquv keskin oshadi.
2) Chiroq kameraga biriktirilgan, chunki o'yinchi sichqoncha bilan qayerga qarasa, chiroq nuri ham xuddi haqiqiy tana kamerasidek o'sha tomonga ergashishi shart.
2-TOPSHIRIQ 3 BALL

WebSocket Xabarlarini Loyihalash (Dispetcher → Pilot)

Dispetcher telefondagi tugmani bosib Eshik A ni ochadi va o'yinchiga "🚨 QOCH! ORQANGDA!" xabarini yuboradi. Ushbu amallar uchun serverga yuboriladigan to'g'ri JSON paketini tuzing:

Muhandislik Kaliti:
{ "type": "cctv_door_override", "doorId": "doorA" } — Eshikni ochish paketi.
{ "type": "cctv_radio_msg", "text": "🚨 QOCH! MAXLUQ ORQANGDA!", "sender": "DISPATCH" } — O'yinchining ekraniga radio xabarini chiqaruvchi JSON paketi.
3-TOPSHIRIQ 2 BALL

Maxluqning Sun'iy Intellekti (AI State Machine)

O'yindagi maxluq 3 xil holatda bo'ladi: PATROL, HUNT va STUNNED. Qaysi voqealar ushbu holatlarni o'zgartiradi?

Muhandislik Kaliti:
1) PATROL → HUNT: O'yinchi 6.5 metr masofaga yaqinlashganda, yugurganda (Shift) yoki chiroq nuri maxluqqa tushganda, u ta'qib qilish holatiga o'tadi.
2) HUNT → STUNNED: Dispetcher pultidan "🚨 SIGNALIZATSIYA" sirenasini yoqqanda, baland tovush maxluqni 6 soniyaga to'xtatib qo'yadi.

Missiya Hisoboti: Jamoaviy Ish Tahlili (Post-Mortem)

"Pilot faqat yo'lakni ko'rdi. Dispetcher esa radarga qarab maxluq Sector B tomonga ketganini aytdi va biz tezda Sector A ga kirib 1-yadroni oldik. Chiroq o'chib qolmasligi uchun dispetcher zaxira quvvat impulsi yubordi. Hamjihatlik tufayli 03:40 daqiqada qochishga erishdik."
