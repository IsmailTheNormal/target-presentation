Fishing Detektori: Soxta Havolalar va Qopqonlar

Nega dunyodagi eng zo'r xakerlar ham kompyuterlarni emas, balki insonlarni aldashga urinishadi? Chunki kompyuterning shifrini buzish uchun minglab yillar kerak, lekin odamga 'Sizga bepul 5000 Robux chiqdi!' yoki 'Telegramingiz o'chirilmoqda, bu yerga bosing!' deb xabar yuborilsa, ko'pchilik o'z qo'li bilan parolini berib qo'yadi! Ushbu kiber-aldov Fishing (Baliq ovi) deb ataladi. Bugungi darsda biz kiber-detektivlarga aylanib, soxta havolalarni (URL), aldovchi harflarni va Telegram tuzoqlarini 1 soniyada fosh qilishni o'rganamiz!

Qanday aldashadi?

Fishing Nima va Nega Xakerlar Uni Yaxshi Ko'radi?

Fishing (Baliq Ovi) Qanday Ishlaydi? 🎣

  • 1. O'lja (Bait): Sizga juda yoqadigan narsa taklif qilinadi: 'Bepul Telegram Premium', 'Brawl Stars skin', 'Olimpiada sovg'asi'.
  • 2. Soxta Sahifa: Havolani bossangiz, aynan Telegram yoki Robloxga 100% o'xshash, ammo qalbaki sayt ochiladi.
  • 3. Qopqon: Siz login va SMS parolingizni yozganingiz zahoti, u to'g'ridan-to'g'ri hackerning telegram botiga jo'natiladi!

Nega 'Baliq Ovi' (Fishing) Deyiladi?

  • Baliqchi daryoga chiroyli qurt tashlaydi. Baliq qurt ortida temir qarmoq borligini ko'rmaydi va uni yutib yuboradi.
  • Hacker ham aynan shunday: 'Bepul Robux' yoki 'Telegram Premium' bu xakerning qurtidir!
  • Siz tugmani bosgan zahotingiz — qarmoqqa ilinasiz!
  • Qoidaga amal qiling: Internetda hech qachon notanish 'qurtlar'ni yutmang!

Brauzer qulfi nimani bildiradi?

Brauzerdagi 'Qulfcha' (HTTPS) Sizni Firibgardan Asramaydi!

Qulfcha (HTTPS) Aslida Nimani Bildiradi?

  • Ko'p bolalar o'ylaydi: 'Saytda yashil qulfcha bormi, demak u 100% xavfsiz va ishonchli!' — BU KATTA XATO!
  • Qulfcha faqat bitta narsani bildiradi: siz bilan ushbu server o'rtasidagi ma'lumot shifrlangan.
  • Ammo agar serverning egasi hackerning o'zi bo'lsa, siz o'z parolingizni hackerga shifrlangan chiroyli quvur orqali topshirgan bo'lasiz!

Hackerlar Qanday Qilib Qulfcha Qo'yadi?

  • Bugungi kunda har qanday odam (hatto firibgar ham) bepul SSL sertifikat (masalan Let's Encrypt) olishi mumkin.
  • Bugungi kunda fishing saytlarning 80% dan ortig'i qulfchaga ega!
  • Xulosa: Qulfchaga emas, sayt nomining harflariga qarang!

Python Skripti Soxta Havolalarni Qanday Fosh Qiladi?

import urllib.parse

OFFICIAL_DOMAINS = ["telegram.org", "roblox.com", "targetschool.uz"]

def inspect_url(link: str) -> str:
    # 1. URL manzilidan asosiy domenni ajratib olamiz
    parsed = urllib.parse.urlparse(link)
    hostname = parsed.hostname or link
    
    # 2. Xavfli kalit so'zlar bor-yo'qligini tekshiramiz
    traps = ["free-robux", "bonus", "gift", "verify-account", "telegram-premium"]
    for trap in traps:
        if trap in link.lower() and hostname not in OFFICIAL_DOMAINS:
            return f"🚨 XAVF! Soxta tuzoq aniqlandi: '{trap}'"
            
    # 3. Rasmiy saytlar ro'yxatiga solishtiramiz
    if any(hostname.endswith(domain) for domain in OFFICIAL_DOMAINS):
        return "✅ XAVFSIZ: Rasmiy tasdiqlangan domen."
        
    return "⚠️ DIQQAT! Noma'lum notanish sayt, parolni kiritmang!"

# Test:
print(inspect_url("https://robl0x-free-robux.site/login"))
# Natija: 🚨 XAVF! Soxta tuzoq aniqlandi: 'free-robux'

Telegram Akkauntingizni Qanday Qilib 100% Himoya Qilasiz?

Telegram Rasmiy Xabarlarini Qanday Taniymiz?

  • Telegram xizmati sizga hech qachon guruhlardan yoki begona botlardan xabar yozmaydi.
  • Haqiqiy Telegram xabarlarida doimo Moviy Tasdiqlash Belgisi (Verified Badge ✔️) bo'ladi va ularga javob yozib bo'lmaydi.
  • Telegram hech qachon 'Parolingizni botga yuboring' deb so'ramaydi!

Zudlik Bilan Yoqilishi Shart Bo'lgan 2 Ta Sozlama

  • 1. Bulutli Parol (Two-Step Verification): Sozlamalar → Maxfiylik → Ikki bosqichli tekshiruv. Parolingizni o'rnating!
  • 2. Faol Seanslar (Active Sessions): Sozlamalar → Qurilmalar. Begona telefon yoki kompyuter ko'rinsa, darhol 'Barcha boshqa seanslarni tugatish' tugmasini bosing!
