Xato Tahlili (Pitfall)

Sprayt ekrandan chiqib ketishi yoki X va Y chalkashishi

Tepaga sakrashda Y o'rniga X o'zgartirilgan, yoki devorga tekkanda qaytish bloki (`if on edge, bounce`) qo'yilmagani uchun sprayt sahnadan chiqib yo'qolgan.

// ❌ Xato:
change X by (50) // Tepaga sakramaydi, o'ngga suriladi!
Oltin Yechim (Best Practice)

Aniq koordinatalar va devordan qaytish

X gorizontal (chap/o'ng), Y vertikal (tepa/past). Devordan qaytish va aylanishni `left-right` qilish qahramonni har doim to'g'ri ushlaydi.

// ✅ To'g'ri:
change Y by (50) // Tepaga sakrash!
if on edge, bounce // Sahnada qolish!

1-DVIGATEL · NUTQNI TANISH (STT)

Kompyuter Quloqlari: Web Speech API

Chrome va zamonaviy brauzerlarda maxsus nutq qabul qiluvchi dvigatel bor: u mikrofondan kelgan tovushni matnga aylantiradi.

Nutq Qabul Qilishni Yoqish

Dasturda yangi recognition obyektini ochamiz va tilni tanlaymiz:

const rec = new webkitSpeechRecognition();
rec.lang = 'uz-UZ'; // O'zbek tili
rec.continuous = false; // Bitta gap
rec.start(); // Eshitishni boshlash

Natijani Tutish (onresult)

Siz gapirib bo'lishingiz bilan `onresult` voqeasi ishga tushadi va matnni beradi:

rec.onresult = function(event) {
  let gap = event.results[0][0].transcript;
  console.log("Eshitildi:", gap);
};
2-DVIGATEL · NIYATNI ANGLASH (NLP)

Yordamchi Miyasi: Niyatni Aniqlash (Intent Matching)

O'quvchilar bir xil gapirmaydi: "Salom", "Salom Jarvis", "Assalomu alaykum". AI kalit so'zlarni qidiradi.

Kichik Harflar va Kalit So'zlar

Barcha harflarni kichik qilib olamiz, keyin `includes()` bilan tekshiramiz:

let text = gap.toLowerCase();

if (text.includes("salom")) {
  javob = "Assalomu alaykum do'stim!";
} else if (text.includes("soat")) {
  javob = "Hozir soat " + new Date().toLocaleTimeString();
}

Noma'lum Buyruq (Fallback)

Agar shartlar mos kelmasa, dastur xato bermasdan xushmuomala javob qaytaradi:

else {
  javob = "Kechirasiz, bu buyruqni bilmayman. Menga yangi narsa o'rgating!";
}
3-DVIGATEL · OVOZ CHIQARISH (TTS)

Yordamchining Tili: speechSynthesis Dvigateli

Brauzer ichidagi ovoz sintezatori orqali istalgan matnni insoniy ovoz bilan eshittirish mumkin.

Ovoz Chiqarish Sintaksisi

Gapirilishi kerak bo'lgan jumlani yozamiz va dinamikdan yangratamiz:

function gapir(matn) {
  let utter = new SpeechSynthesisUtterance(matn);
  utter.rate = 1.0;  // Gapirish tezligi
  utter.pitch = 1.1; // Ovoz balandligi
  window.speechSynthesis.speak(utter);
}

Robot va Multfilm Ovozini Sozlash

`pitch` qiymatini 1.8 qilsangiz quvnoq multfilm qahramoni, 0.6 qilsangiz bahaybat kiber-robot ovozi chiqadi!

  • pitch: 0.6 — Og'ir Kiber-Robot
  • pitch: 1.0 — Normal Inson Ovozi
  • pitch: 1.8 — Scratch Mushukchasi
SCRATCH VA OVOZ BOG'LANISHI

Ovozli Buyruq: Spraytni Harakatga Keltirish!

Siz "Mushuk sakrasin!" deganingizda, JavaScript Scratch mushugini topadi va uni sakratadi!

Sakrash Funksiyasi

function mushukSakrasin() {
  const cat = document.getElementById("cat");
  // Tepaga 80 piksel sakrash:
  cat.style.transform = "translateY(-80px)";
  
  // 500 ms dan so'ng yerga tushish:
  setTimeout(() => {
    cat.style.transform = "translateY(0px)";
  }, 500);
}

Niyat bilan Bog'lash

if (text.includes("mushuk") || text.includes("sakra")) {
  mushukSakrasin();
  gapir("Bajarildi! Mushuk sakradi!");
}

Bitta ovozli buyruq bir vaqtning o'zida ham animatsiyani, ham Jarvis ovozini ishga tushiradi!
