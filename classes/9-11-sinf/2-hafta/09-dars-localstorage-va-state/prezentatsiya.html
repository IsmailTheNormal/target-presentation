Doimiy Xotira: LocalStorage va State

Saytni refresh (F5) qilganda barcha ma'lumotlar o'chib ketishidan charchadingizmi? Brauzer xotirasiga ma'lumot saqlashni o'rganamiz.

Amneziya Muammosi

Nega Veb-saytlar "Amneziya"ga uchraydi?

Brauzer har bir sahifa yangilanganda (F5 bosilganda) HTML, CSS va JS fayllarni boshidan qayta o'qiydi.

  • Amneziya: Siz tanlagan til (UZ), yoqqan tungi rejim (Dark mode) yoki hisoblagan valyutangiz o'chib ketadi!
  • Yechim: Foydalanuvchi kompyuterining qattiq diskidagi maxsus ombor — LocalStorage!
Mitti Ombor

LocalStorage nima?

LocalStorage — brauzer ichida har bir saytga beriladigan 5-10 Megabaytlik shaxsiy, doimiy xotiradir.

1. Doimiylik

Kompyuterni o'chirib yoqsangiz ham saqlangan ma'lumot o'chmaydi.

💾

2. Tezkorlik

Internet kerak emas! Barcha ma'lumot kompyuterning o'zida yashaydi.

⚡

3. Kalit-Qiymat

Xuddi JSON kabi: key -> value juftliklarida saqlanadi.

🔑
Sintaksis

LocalStorage ning 3 ta Sehrli Buyrug'i

JavaScript da xotira bilan ishlash uchun faqat 3 ta metodni bilish kifoya:

  • 1. Saqlash: localStorage.setItem("mavzu", "dark");
  • 2. O'qish: var rejim = localStorage.getItem("mavzu");
  • 3. O'chirish: localStorage.removeItem("mavzu");
Farqlar

LocalStorage vs Cookies vs SessionStorage

LocalStorage

Hajm: 5–10MB.
Umr: O'chirib tashlanmaguncha mangu yashaydi.
Qo'llanish: Mavzu, sozlamalar, kesh.

SessionStorage

Hajm: 5MB.
Umr: Vkladka yopilganda o'chib ketadi.
Qo'llanish: Bir martalik formalar.

Cookies

Hajm: 4KB (mitti).
Umr: Muddatli.
Qo'llanish: Server bilan sessiya va login tokenlari.

JSON Ko'prigi

Massivlarni Saqlash: stringify va parse

LocalStorage faqat oddiy Matn (String) tushunadi. Ro'yxat yoki Ob'ekt saqlash uchun nima qilamiz?

JSON.stringify(ro'yxat)

JavaScript ob'ektini yoki massivini matnga (string) aylantirib xotiraga yozadi.

JSON.parse(matn)

Xotiradan olingan matnni yana JavaScript massiviga aylantirib beradi.

Taqiqlangan Hudud

LocalStorage ga NIMALARNI Saqlash Mumkin EMAS?

LocalStorage mutlaqo OCHIQ ombordir. Kompyuterdan foydalangan har qanday odam uni o'qiy oladi.

  • ❌ Parollar: Foydalanuvchilar parolini hech qachon LocalStorage ga yozmang!
  • ❌ Bank kartalari va CVV: Moliyaviy maxfiy ma'lumotlar qat'iyan taqiqlanadi!
  • ✅ Mumkin: Tungi rejim sozlamasi, tanlangan til, hisob-kitob tarixi, savatchadagi mahsulotlar (Cart).
