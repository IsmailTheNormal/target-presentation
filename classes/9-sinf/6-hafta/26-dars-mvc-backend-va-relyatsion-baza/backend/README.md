# 26-Dars: MVC Backend & Relyatsion SQLite REST API

Ushbu loyiha 9-sinf o'quvchilari uchun professional **Model-View-Controller (MVC)** arxitekturasida yozilgan backend xizmatidir.

## Tuzilma:
```
backend/
├── models/         # SQLite bazasi va SQL so'rovlar (Database layer)
├── controllers/    # Biznes mantiq va kiruvchi ma'lumotlar validatsiyasi
├── routes/         # REST API yo'nalishlari (Routing endpoints)
├── public/         # Veb-boshqaruv paneli (Dashboard)
├── server.js       # Asosiy server fayli
└── package.json    # Paketlar sozlamasi
```

## Ishga tushirish:
```bash
npm install
npm start
```
Brauzerda `http://localhost:3000` ochiladi.
