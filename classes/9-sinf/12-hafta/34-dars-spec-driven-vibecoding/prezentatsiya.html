UY VAZIFASI TAHLILI · XATOLAR REVIZIYASI

O'tgan Dars Vazifasi Tahlili va Yangi Mavzuga Ko'prik

Xato Tahlili (Pitfall)

SPA havolada sahifa qayta yuklanishi

a[data-link] bosilganda e.preventDefault() unutilsa, brauzer serverga yangi GET so'rov yuboradi va SPA holati yo'qoladi.

// ❌ Xato: brauzer sahifani yangilaydi
document.addEventListener('click', (e) => {
  const a = e.target.closest('a[data-link]');
  if (a) navigateTo(a.href);
});
Oltin Yechim (Best Practice)

To'g'ri Event Delegation + pushState

e.preventDefault() bilan standart o'tish to'xtatiladi, history.pushState URL ni yangilaydi va popstate Orqaga tugmasini ushlaydi.

// ✅ Oltin yechim
document.addEventListener('click', (e) => {
  const a = e.target.closest('a[data-link]');
  if (!a) return;
  e.preventDefault();
  history.pushState(null, '', a.getAttribute('href'));
  router();
});
30s Blits-Nazorat

Blits-savol (30s): Nega SPA saytda /profile sahifasida F5 bosilganda Vercel/Nginx 404 xato beradi va uni qanday hal qilamiz?

Yangi Darsga Ko'prik

Ko'prik: Siz endi SPA, routing va LocalStorage ni bilasiz. Endi asosiy savol — bitta katta g'oyani AI yordamida 25 daqiqada qanday qilib 'spaghetti kod'siz, toza va ishlaydigan mahsulotga aylantiramiz?

3-MODUL · KONTEKST MUHANDISLIGI

AI Gallyutsinatsiyasini To'xtatish: Aniq Kontekst Berish

AI sizning faylingizda qaysi ID va o'zgaruvchilar borligini ko'rmasa, yangilarini o'ylab topadi — va kod ulanmay qoladi.

AI ga nimalarni berish shart?
  • Aniq State tuzilmasi (JSON kalitlari)
  • Mavjud DOM ID lar (#taskList, #addBtn)
  • O'zgartiriladigan funksiya qismi
  • Chrome Console dagi aniq xato matni
Toza Kontekstli Prompt Namuna
State: tasks = [{ id, text, done }]
DOM: #taskForm, #taskInput, #taskList
Rule: Use event delegation on #taskList.
Escape textContent (no raw innerHTML XSS).
Add ONLY deleteTask(id) and persist().
