Niyat va Fakt: package.json + lockfile

Aniq express versiyasi bilan package.json fragmentini yozing va package-lock.json nima uchun Git'da bo'lishi shartligini tushuntiring. Faqat runtime bog'liqliklarini o'rnatadigan buyruqni qo'shing.

Etalon yechim

{
  "dependencies": { "express": "4.19.2" }
}
# lockfile фиксирует точные версии и хеши,
# поэтому у коллеги и на сервере одинаковый установ.
npm ci --omit=dev
2-Daraja · Muhandislik 4 BALL

npm audit Hisoboti: Severity va Tuzatish Rejasi

npm audit ni ishga tushiring, bitta critical va bitta high zaiflikni yozing, paket, bog'liqlik yo'li va tuzatish buyrug'ini ko'rsating. npm audit fix --force nima uchun xavfli ekanini tushuntiring.

Etalon yechim

CRITICAL: lodash < 4.17.21 → prototype pollution.
  Путь: express → lodash. Фикс: npm audit fix.
HIGH: minimist < 1.2.6 → prototype pollution.
  Фикс: обновить зависимость, проверить тесты.

npm audit fix --force может поставить major-версию
и сломать API — сначала читаем отчёт и тесты.
3-Daraja · Kiber-Chaqiruv 2 BALL

Ta'minot Zanjiriga Hujum Ssenariysi

Typosquatting va postinstall skripti .env ni qanday o'g'irlashini bosqichma-bosqich yozing. So'ng uchta aniq himoyani taklif qiling va qaysi biri har bir qadamda hujumni bloklashini tekshiring.

Etalon yechim

1. Атакующий публикует crossenv (опечатка cross-env).
2. Разработчик ставит пакет: срабатывает postinstall.
3. Скрипт читает .env и отправляет токены на C2.

Защита:
- Проверка имени, загрузок и репозитория пакета.
- npm ci --ignore-scripts для пакетов без сборки.
- CI-секреты вне .env + npm audit --audit-level=high.
