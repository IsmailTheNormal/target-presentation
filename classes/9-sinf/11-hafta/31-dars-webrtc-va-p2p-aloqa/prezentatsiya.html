TARMOQ ARXITEKTURASI VA NAT DEVORI

Nega Internet To'g'ridan-to'g'ri Ulanishni Bloklaydi? (NAT Devori)

Dunyodagi aksariyat qurilmalar ommaviy IPv4 manziliga ega emas. Ular uy Wi-Fi routerlari yoki provayder NAT tizimi orqasiga yashiringan.

  • NAT (Network Address Translation): Router lokal IP manzilni (192.168.x.x) bitta umumiy tashqi IP ga o'zgartiradi.
  • Yashirin Port: Tashqi internet olami Alisaning noutbuki aynan qaysi ichki portda kutayotganini ko'ra olmaydi.
  • P2P Yechimi: Tashqi "ko'zgu" serveri (STUN) kerak, u har bir qurilmaga: "Sening tashqi ommaviy IP va porting mana bu!" deb aytadi.

JAVASCRIPT WEBRTC API

RTCPeerConnection va RTCDataChannel Kod Standarti

1. Uzel va Kanal Yaratish (Alice)

// STUN konfiguratsiyasi
const config = {
  iceServers: [{ urls: 'stun:stun.l.google.com:19302' }]
};
const peer = new RTCPeerConnection(config);

// P2P ma'lumotlar kanalini ochish
const channel = peer.createDataChannel('kiber-chat', {
  ordered: true // Paketlar tartibli yetib boradi
});

channel.onopen = () => console.log('✅ P2P Kanal Ochiq!');
channel.onmessage = (e) => console.log('Kelgan xabar:', e.data);

// ICE nomzodini tutish
peer.onicecandidate = (e) => {
  if (e.candidate) signaling.send({ candidate: e.candidate });
};

2. Kanalni Qabul Qilish va Javob (Bob)

const bobPeer = new RTCPeerConnection(config);

// Bob kiruvchi DataChannelni tinglaydi
bobPeer.ondatachannel = (e) => {
  const remoteChan = e.channel;
  remoteChan.onopen = () => console.log('✅ Bob: Kanal boglandi!');
  remoteChan.onmessage = (ev) => {
    console.log('Bob qabul qildi:', ev.data);
    remoteChan.send('Salom Alice! Paket yetib keldi.');
  };
};

// Offer qabul qilish va Answer yaratish
await bobPeer.setRemoteDescription(receivedOffer);
const answer = await bobPeer.createAnswer();
await bobPeer.setLocalDescription(answer);
signaling.send({ answer });
SHIFRLASH VA SCTP PROTOKOLI

Nega WebRTC-ni Quloq Solib Buzib Bo'lmaydi? (DTLS va SCTP)

UDP / Transport

Minimal Kechikish

WebRTC UDP ustida ishlaydi. TCP kabi sekinlashtiruvchi ortiqcha tekshiruvlar yo'q — kechikish <20ms gacha tushadi.

DTLS / Shifrlash

Kafolatlangan Shifr

DTLS (Datagram TLS) WebRTC standartining majburiy talabidir. Ochiq, shifrlanmagan ma'lumot yuborishning o'zi imkonsiz!

SCTP / Kanallar

Moslashuvchan Tartib

SCTP rejimni tanlash imkonini beradi: fayllar uchun tartibli (ordered), o'yinlar uchun esa o'ta tez tartibsiz oqim.

WebRTC DataChannel Protokollar Steki:
Ilova (Kiber-Chat) ➔ RTCDataChannel ➔ SCTP ➔ DTLS (AES-GCM-128/256) ➔ UDP / IP
