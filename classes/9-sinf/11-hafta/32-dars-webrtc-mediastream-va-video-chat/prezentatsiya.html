KAMERA VA MIKROFON QUVURI

Brauzer Kameraga Qanday Ulanadi? (navigator.mediaDevices)

MediaStream API: foydalanuvchining kamera va mikrofoni bilan xavfsiz ishlash imkonini beruvchi rasmiy brauzer texnologiyasi.

  • HTTPS Majburiy: Kamera va mikrofonga faqat shifrlangan HTTPS yoki localhost orqali ulanish mumkin.
  • Treklar: MediaStream ichida alohida Video trek va Audio trek mustaqil boshqariladi.
  • Mute Qilish: track.enabled = false orqali aloqani uzmasdan kamerani o'chirib qo'yish mumkin.
[Kamera Sozlamalari (Constraints)]
const constraints = {
  video: {
    width: { ideal: 1280, max: 1920 },
    height: { ideal: 720, max: 1080 },
    frameRate: { ideal: 30, max: 60 }
  },
  audio: {
    echoCancellation: true, // Echo aks-sado himoyasi
    noiseSuppression: true  // Shovqinni tozalash
  }
};
const stream = await navigator.mediaDevices.getUserMedia(constraints);
myVideoElement.srcObject = stream;

EKRAN ULASHISH API

Ekran Namoyishi: getDisplayMedia() va Treklarni Almashtirish

getDisplayMedia(): foydalanuvchiga butun ish stolini, ma'lum dastur oynasini yoki bitta brauzer tabini jonli translyatsiya qilish imkonini beradi.

  • Qayta bog'lanish shart emas: Kamerani ekranga almashtirish uchun ulanishni uzish kerak emas!
  • sender.replaceTrack(): Mavjud ulanish ichidagi kamerani bir zumda ekran tasviriga almashtirib yuboradi.
[Ekranni Almashtirish Kodi]
async function shareScreen() {
  const screenStream = await navigator.mediaDevices
    .getDisplayMedia({ video: true });
  const screenTrack = screenStream.getVideoTracks()[0];

  // RTCRtpSender orqali treknialmashtirish
  const sender = peerConnection.getSenders()
    .find(s => s.track.kind === 'video');
  await sender.replaceTrack(screenTrack);

  // Ekran ulashish to'xtatilganda kameraga qaytish
  screenTrack.onended = () => sender.replaceTrack(camTrack);
}
