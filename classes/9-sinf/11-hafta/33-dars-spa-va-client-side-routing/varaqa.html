Kiber-Missiya

Toza JavaScript yordamida to'liq ishlaydigan SPA (Single Page Application) tizimini loyihalash: History API pushState, havolalarni qayta yuklashsiz tutib qolish va Cyber-OS boshqaruv panelini yaratish.

01 SPA Arxitekturasining 4 Asosiy Ustuni

An'anaviy veb-saytlar (MPA) har bir havola bosilganda butun HTML hujjatni serverdan qayta yuklaydi va barcha WebSockets/WebRTC ulanishlarini uzib yuboradi. SPA (Single Page Application) arxitekturasi esa bitta bosh sahifani (index.html) yuklab, qolgan barcha ko'rinishlarni mijoz brauzerining o'zida 0.1 ms da yangilaydi.

SPA Arxitekturasining 4 Asosiy Ustuni:
1. History API (pushState): Brauzerda URL manzilini sahifani qayta yuklamasdan o'zgartirish.
2. Link Interception: e.preventDefault() bilan havolalarning yangilanishini to'xtatish.
3. popstate Handler: Brauzerning Orqaga/Oldinga tugmalari bosilganda sahifani tiklash.
4. Server Fallback (Rewrite): F5 bosilganda xato chiqmasligi uchun barcha yo'llarni index.html ga burish.
02 Vanilla JS SPA Router Yadrosi va Sintaksisi
// Vanilla JS SPA Router yadrosi:
function navigateTo(url) {
  window.history.pushState(null, '', url);
  router();
}
document.addEventListener('click', e => {
  const a = e.target.closest('a[data-link]');
  if (a) { e.preventDefault(); navigateTo(a.href); }
});
window.addEventListener('popstate', router);
