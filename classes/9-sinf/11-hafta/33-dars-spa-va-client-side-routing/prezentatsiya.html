  • Havolalar JS bilan tutib qolinadi, faqat <main> qismi yangilanadi.
  • Fon musiqasi, WebSocket va WebRTC aloqasi uzilishsiz ishlayveradi!
HTML5 HISTORY API

SPA Yuragi: pushState, replaceState va popstate

URL ni Qayta Yuklamasdan O'zgartirish

// 1. Yangi URL va tarix yozuvi:
window.history.pushState(
  { view: 'analytics' }, 
  'Analytics', 
  '/analytics'
);

// 2. Tarixni yangilamasdan almashtirish:
window.history.replaceState({ tab: 1 }, '', '/tab1');

// 3. Orqaga / Oldinga tugmalarini tutish:
window.addEventListener('popstate', (event) => {
  console.log('Foydalanuvchi orqaga qaytdi:', window.location.pathname);
  renderView(window.location.pathname);
});

pushState ning 3 Parametri

1. state — Tarix yozuviga biriktiriladigan ixtiyoriy JS obyekti.
2. title — Sarlavha (hozirgi brauzerlar ko'pincha e'tiborsiz qoldiradi).
3. url — Brauzer manzil qatorida ko'rinuvchi yangi URL yo'li!
⚡ Oltin Qoida: pushState manzil qatoridagi URL ni o'zgartiradi, lekin sahifani qayta yuklamaydi. Sahifani yangilash mas'uliyati 100% sizning JS kodingizga yuklanadi!
MARSHRUTLASH TURLARI

Hash Routing (#) va Path Routing (/) Taqqoslovi

1. Hash Routing (#/terminal)

URL Hash Belgisi Bilan

URL manzilda #/settings shaklida bo'ladi. # belgisi serverga yuborilmaydi, faqat brauzer ichida qoladi.

  • Afzalligi: Hech qanday server sozlamasini talab qilmaydi.
  • Kamchiligi: URL manzillar ko'rinishi unchalik chiroyli emas.
2. Path Routing (/terminal)

Toza URL Manzillari

URL toza va chiroyli: target.uz/settings. Barcha professional platformalar shu standartda ishlaydi.

  • Afzalligi: Toza, xalqaro standart va SEO uchun mukammal.
  • Talabi: F5 bosilganda server barcha so'rovlarni index.html ga yo'naltirishi shart!
LINK INTERCEPTION

Havolalarni Tutib Qolish: e.preventDefault() San'ati

Markaziy Klik Delegati

// Butun hujjat bo'yicha havolalarni tutib qolamiz:
document.addEventListener('click', (e) => {
  const link = e.target.closest('a[data-link]');
  if (!link) return;

  // Brauzerning sahifani yangilashini to'xtatamiz:
  e.preventDefault();

  const href = link.getAttribute('href');
  navigateTo(href);
});

function navigateTo(url) {
  window.history.pushState(null, '', url);
  router(); // Yangi sahifa komponentini chizish!
}

Mexanizm Qanday Ishlaydi?

  • Atribut filtri: Faqat data-link qo'yilgan ichki havolalar ushlanadi.
  • Yangilashni to'xtatish: Brauzer serverdan yangi fayl so'ramaydi.
  • Tashqi havolalar xavfsiz: Begona saytlarga havolalar erkin ishlaydi.
ROUTES MAP

Marshrutlar Jadvali va Dinamik Komponentlar

Marshrutlar Obyekti

const routes = {
  '/': ViewDashboard,
  '/traffic': ViewTraffic,
  '/terminal': ViewTerminal,
  '/settings': ViewSettings
};

function router() {
  const path = window.location.pathname;
  const viewRenderer = routes[path] || ViewNotFound;

  // Asosiy konteynerni yangilaymiz:
  const app = document.getElementById('app');
  app.innerHTML = viewRenderer();

  updateActiveNavLink(path);
}

Aktiv Menyu Tugmasi

Foydalanuvchi qaysi bo'limda turganini ko'rishi uchun menyudagi aktiv havolaga active klassi qo'yiladi:

function updateActiveNavLink(path) {
  document.querySelectorAll('.nav-item').forEach(el => {
    const isCurrent = el.getAttribute('href') === path;
    el.classList.toggle('active', isCurrent);
  });
}

DINAMIK URL LAR

Dinamik Parametrlar (/user/:id) va Wildcard 404

Regex Bilan Parametrlarni Ajratish

// /user/:id kabi yo'llarni aniqlash:
function matchRoute(routePath, currentPath) {
  const paramNames = [];
  const regexPath = routePath.replace(/:(\w+)/g, (_, key) => {
    paramNames.push(key);
    return '([^\/]+)';
  });

  const match = currentPath.match(new RegExp(`^${regexPath}$`));
  if (!match) return null;

  // Parametrlarni obyektga yig'amiz:
  const params = {};
  paramNames.forEach((name, i) => params[name] = match[i + 1]);
  return params;
}

SERVER FALLBACK SIRI

F5 Tuzog'i: Vercel va Nginx ni SPA ga Moslash

Nega F5 Bosilganda 404 Chiqadi?

Siz JS orqali /traffic ga o'tdingiz — barchasi ishlayapti. Ammo F5 bossangiz, brauzer to'g'ridan-to'g'ri serverdan /traffic faylini so'raydi. Diskda bunday papka bo'lmagani uchun server 404 xatosini beradi!

Yechim: Barcha So'rovlarni index.html ga Yo'naltirish

1. vercel.json:
{
  "rewrites": [
    { "source": "/(.*)", "destination": "/index.html" }
  ]
}
2. Nginx config:
location / {
  try_files $uri $uri/ /index.html;
}
