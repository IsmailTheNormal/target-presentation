📚 SQL va Laboratoriya Qo'llanmasi

1. DDL (Sxema yaratish): CREATE TABLE users (id INTEGER PRIMARY KEY, email TEXT UNIQUE);

2. DML (Ma'lumot kiritish): INSERT INTO users (full_name, email, balance) VALUES ('Jasur', 'jasur@target.uz', 500000);

3. DQL (Qidiruv): SELECT * FROM users WHERE balance > 100000 ORDER BY balance DESC;

4. Relyatsion JOIN: SELECT users.full_name, COUNT(orders.id) FROM users LEFT JOIN orders ON users.id = orders.user_id GROUP BY users.id;

5. ACID Tranzaksiya: BEGIN; UPDATE users SET balance = balance - 50000; COMMIT;

6. Indekslar: CREATE INDEX idx_orders_user_id ON orders(user_id);

7. Reja tahlili: EXPLAIN QUERY PLAN SELECT * FROM orders WHERE user_id = 1;
