Laboratoriya Vazifasi: Paket Tahlili va Nmap Auditi

Wireshark orqali jonli tarmoq paketlarini tutib olish, shifrlanmagan HTTP POST so'rovidan parolni ajratib olish, va Nmap yordamida serverdagi ochiq portlar va xizmatlarni aniqlash.

Protokol / BosqichTekshirish UsuliAniqlangan Ma'lumotHolat
1. TCP HandshakeWireshark filtri: `tcp.flags.syn == 1`SYN -> SYN-ACK -> ACK ketma-ketligi✅ Aniqlandi
2. HTTP Sniffing`http.request.method == "POST"`Ochiq matndagi login va parol
3. Nmap Skanerlash`nmap -sV -p 80,443,2222 <target>`Ochiq portlar va dastur versiyalari
4. HTTPS HimoyasiWireshark: `tls.handshake`Trafik to'liq shifrlangan (Application Data)

1. Nega ochiq Wi-Fi tarmog'ida HTTP orqali parollarni kiritish o'ta xavfli?


2. Nmap skanida 'Filtered' va 'Closed' port holatlari o'rtasida qanday farq bor?
