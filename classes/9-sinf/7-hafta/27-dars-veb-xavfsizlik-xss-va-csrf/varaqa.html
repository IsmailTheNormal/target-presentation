3 CSRF mudofaasi: Xavfsiz Kuki sozlamalari

Express res.cookie() funksiyasida CSRF va XSS ga qarshi 3 ta muhim parametrni yozing:

res.cookie('token', userJwt, {
  httpOnly: ____________, // JavaScript orqali o'qishni taqiqlash (XSS)
  secure: ____________, // Faqat HTTPS orqali jo'natish
  sameSite: '____________' // Boshqa saytlardan kuki yuborilishini bloklash (CSRF)
});
