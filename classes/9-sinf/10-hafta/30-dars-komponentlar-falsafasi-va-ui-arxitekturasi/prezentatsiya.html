Keng Tarqalgan Xato (Pitfall)

Link Orqali Xotirani Buzish

// user1.role haligacha "Dev"! Safe State update.

YANGI PARADIGMA · LEGO MODELI

UI Komponent Nima: 4 Qismdan Iborat Mustaqil Lego Bloki

Komponent — bu tashqi dunyoga bog'liq bo'lmagan, o'zining shabloni, stillari, parametrlari va ichki xotirasiga ega bo'lgan mustaqil dasturiy blok:

Komponentning 4 Ta Asosi

  • 1. Template (Shablon): HTML skeleti va ma'lumot joylashuv o'rinlari (Placeholder).
  • 2. Props (Xususiyatlar): Tashqaridan (ota komponentdan) uzatiladigan o'zgarmas sozlamalar (Read-only).
  • 3. State (Ichki Holat): Komponentning ichida yashovchi va o'zgaruvchi shaxsiy xotirasi (Masalan: `count: 5`, `isOpen: true`).
  • 4. Events (Hodisalar): Tugma bosilganda ota elementga signal jo'natish (`CustomEvent`).
Matematik Formula
UI = Component(Props, State)

Interfeys endi qo'lda qatorma-qator yozilmaydi! U berilgan Props va joriy State qiymatiga qarab avtomatik generatsiya qilinadi.

IKKI XIL USUL: FACTORY VS WEB COMPONENTS

Vanilla JavaScriptda Komponent Yaratishning 2 Ta Usuli

Modulli interfeys qurish uchun React yoki boshqa og'ir kutubxonalar shart emas. Brauzerning o'zida 2 ta toza usul mavjud:

1. Factory Function Pattern 
export function createBadge(props) {
  const el = document.createElement("span");
  el.className = `badge badge-${props.variant}`;
  el.textContent = props.text;
  
  el.onclick = () => {
    el.dispatchEvent(new CustomEvent("badge-click", {
      bubbles: true,
      detail: { text: props.text }
    }));
  };
  return el;
}

Oddiy, yengil va tezkor. DOM elementini yasab qaytaradi.

2. Native Web Component (W3C Standart) 
class CyberBadge extends HTMLElement {
  connectedCallback() {
    const text = this.getAttribute("text") || "BADGE";
    const variant = this.getAttribute("variant") || "info";
    this.innerHTML = `
      <span class="badge ${variant}">${text}</span>
    `;
  }
}
customElements.define("cyber-badge", CyberBadge);
// HTMLda ishlatish: <cyber-badge text="ONLINE" variant="green"></cyber-badge>

HTML teglari kabi brauzerga o'rnatiladi. HTML fayl ichida bevosita ochiladi!

HOLAT BOSHQARUVI VA REAKTIV RE-RENDER

Komponent Qanday Yangilanadi: setState Mexanikasi

Ichki ma'lumotlar o'zgarganda sahifa butunlay qayta yuklanmaydi, faqat ushbu komponentning o'zi avtomatik yangilanadi (Targeted Re-render):

Holat Tsikli Qadamlari

  1. Hodisa sodir bo'ladi: Foydalanuvchi tugmani bosadi (Click).
  2. setState chaqiriladi: this.setState({ count: this.state.count + 1 }).
  3. Nusxa olinadi: Eski xotira mutatsiya qilinmaydi, yangi holat yoziladi.
  4. Targeted render: Faqat komponent shabloni yangi qiymat bilan qayta chiziladi.
✓ Natija: Qolgan 99 ta komponent o'z joyida qoladi, xotira va protsessor tejaladi!
Mutlaqo Taqiqlanadi 
// ❌ XATO: DOMni qo'lda o'zgartirish!
button.onclick = () => {
  document.getElementById("cnt").innerText = 10;
};

// ✅ TO'G'RI: State orqali boshqarish!
button.onclick = () => {
  counter.setState({ value: counter.state.value + 1 });
};

Komponentlar hech qachon begona ID larni tahrirlamaydi! Yagona haqiqat manbasi (Single Source of Truth) — faqat State bo'lishi shart.
