ARXITEKTURA · ASOS

ES Modules: Named Export vs Default Export

JavaScript-da ma'lumotlarni eksport qilishning 2 xil professional usuli bor: Nomli va Standart (Default).

Named Export (Nomli)
export const API_URL = "/api/v1";
export function hash(data) {{ ... }}

// Import:
import {{ API_URL, hash }} from "./utils.js";

Qavslar ichida aniq nom bilan chaqiriladi. Yordamchi funksiyalar uchun standart.

Default Export (Yagona)
export default class Agent {{ ... }}

// Import (xohlagan nom bilan):
import MyAgent from "./Agent.js";

Faylda faqat bitta bo'ladi (jingalak qavssiz). Bosh xizmat yoki sinf uchun mos.

ES6+ SINTAKSIS QUDRATI

Destructuring va Spread/Rest: Toza va Qisqa Kod

Obyekt va massivlar bilan ishlashda 10 qatorlik eski kodni 1 qatorlik nafis sintaksisga almashtiramiz.

1. Destructuring (Parchalash)

const order = {{ id: 101, amount: 450, status: "paid" }};

// Eski usul: order.id, order.amount...
// Yangi ES6+ usuli:
const {{ id, amount }} = order;
console.log(id, amount);

2. Spread / Rest operatori (...)

const defaultSettings = {{ theme: "dark", sound: true }};
const userCustom = {{ sound: false }};

// Obyektlarni xavfsiz birlashtirish:
const final = {{ ...defaultSettings, ...userCustom }};
// final -> {{ theme: "dark", sound: false }}

EVOLYUTSIYA · REFAKTORING

Callback Do'zaxi (Hell) vs async / await

Ilgari 3 ta API ketma-ket chaqirilsa, kod o'ng tomonga qarab piramida bo'lib ketardi. async/await buni tozaladi.

Callback Hell (Eski usul)
getUser((u) => {{
  getOrders(u.id, (o) => {{
    calcTotal(o, (t) => {{
      render(t); // Xatoni ushlash azob!
    }});
  }});
}});
async / await (Zamonaviy)
async function loadData() {{
  const user = await getUser();
  const orders = await getOrders(user.id);
  const total = await calcTotal(orders);
  render(total);
}}
XATOLARNI BOSHQARISH

Asinxron Xatolarni Tutish: try / catch / finally

Tarmoq uzilsa yoki server 500 qaytarsa, sayt o'lib qolmasligi uchun har bir await try/catch blokiga olinishi shart.

Himoyasiz So'rov
const res = await fetch("/api/pay");
const data = await res.json();

Internet o'chsa, xatolik ushlanmay qoladi va sahna to'xtab qoladi.

Mustahkam Qalqon
try {{
  showSpinner(true);
  const res = await fetch("/api/pay");
  return await res.json();
}} catch (err) {{
  showToast("To'lovda xatolik yuz berdi");
}} finally {{
  showSpinner(false);
}}

finally har qanday holatda ham yuklanish spinnerrini to'xtatadi.

KIBER-TEST · EVENT LOOP

Viktorina: Konsolga Qaysi Ketma-ketlikda Ma'lumot Chiqadi?

Quyidagi kodni tahlil qiling: Call Stack, Microtasks va Macrotasks qonuniyatini eslang.

console.log("1");
setTimeout(() => console.log("2"), 0);
Promise.resolve().then(() => console.log("3"));
console.log("4");
A) 1 -> 2 -> 3 -> 4
B) 1 -> 4 -> 3 -> 2
C) 1 -> 3 -> 4 -> 2
D) 4 -> 1 -> 3 -> 2
To'g'ri javob: B (1 -> 4 -> 3 -> 2)!

1 va 4 Call Stack-da darhol sinxron bajariladi. So'ngra Microtask navbati (Promise.then -> 3) ishlaydi. Eng oxirida esa Macrotask navbatidan setTimeout -> 2 ishga tushadi!
