Topshiriq 1

1. Monolit Kodni Toza ES Modullarga Ajratish

2.5 Ball

Dasturchi soliq hisobi, ma'lumotlar bazasi so'rovlari va SMS yuborishni bitta faylga aralashtirib yozgan. Ushbu logikani 3 ta alohida modulga qanday ajratish kerak? export va import misollarini yozing.

Etalon Yechim:

1) taxCalculator.js: export function calcTax(amount) { return amount * 0.12; }
2) dbService.js: export default class Database { ... }
3) notifyService.js: export async function sendSMS(phone, msg) { ... }
app.js da esa: import Database from "./dbService.js"; import { calcTax } from "./taxCalculator.js"; Har bir modul o'z sohasiga javob beradi!

Topshiriq 2

2. Event Loop Navbatlari: Microtasks va Macrotasks

2.5 Ball

Nega hatto kechikish 0 millisekund bo'lsa ham, Promise.resolve().then() har doim setTimeout(() => {}, 0) dan oldin bajariladi? Event Loop navbatlari mexanizmini tushuntiring.

Etalon Yechim:

Standart bo'yicha Promise.then() Microtask navbatiga tushadi. Event Loop har bir sinxron amaldan keyin Macrotask (setTimeout) ga o'tishdan oldin BARCHA Microtask-larni to'liq bajarib bo'lishi SHART. Shu sababli Promise har doim taymerdan o'zib ketadi!

Topshiriq 3

3. Asinxron Kod Qalqoni: try / catch / finally

2.5 Ball

1) loading=true holatini yoquvchi; 2) await fetch(url) bilan ma'lumot oluvchi; 3) xatoni chiroyli ushlovchi; 4) finally da loading=false ni o'chiruvchi xavfsiz funksiya kodini yozing.

Etalon Yechim:

async function fetchSecureData(url) {
  let loading = true;
  try {
    const res = await fetch(url);
    if (!res.ok) throw new Error('HTTP ' + res.status);
    return await res.json();
  } catch (err) {
    console.error('API Error:', err.message);
    alert('Xatolik: ' + err.message);
  } finally {
    loading = false;
  }
}

Topshiriq 4

4. Destructuring va Obyektlarni Xavfsiz Yangilash

2.5 Ball

Berilgan: const user = { id: 1, name: 'Ali', role: 'student', score: 85 }. Destructuring orqali name va score ni ajrating. So'ngra spread (...) orqali eski obyektni buzmasdan score: 100 qilingan yangi updatedUser obyektini yarating.

Etalon Yechim:

1) Destructuring: const { name, score } = user;
2) Spread orqali xavfsiz yangilash: const updatedUser = { ...user, score: 100 };
Eski user obyekti buzilmasdan saqlanib qoladi (score: 85)!
