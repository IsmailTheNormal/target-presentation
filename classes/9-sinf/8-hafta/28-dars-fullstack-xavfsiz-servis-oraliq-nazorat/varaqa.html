1-CHORAK ORALIQ NAZORAT MUHANDISLIK MISSIYASI

Siz Full-Stack veb-servis loyihangizni himoya qilmoqdasiz. Vazifangiz — 4 ta amaliy muhandislik topshirig'ini bajarish: middleware xavfsizlik zanjirini ulash, zaif SQL so'rovini parametrli '?' ko'rinishiga o'tkazish, frontend formasini XSS dan tozalash va xavfsiz Dockerfile tuzish.

1 Express Middleware: Xavfsizlik zanjirini sozlash

Express ilovasida middleware modullari qaysi tartibda ulanishi kerak? Quyidagi 4 ta middleware to'g'ri o'rnini yozing:

1. app.use( ________________________ ); // Xavfsizlik sarlavhalari (Helmet)
2. app.use( cors({ origin: "________________________" }) ); // Ruxsat berilgan frontend domeni
3. app.use( ________________________ ); // DoS va Brute-Force dan himoya (Rate limiter)
4. app.use( express.json({ limit: "________" }) ); // Katta payload hujumidan himoya
2 SQLite Baza: Parametrlangan so'rovlar orqali SQLi himoyasi

3 Frontend XSS: DOMPurify va HttpOnly cookie himoyasi

Nega JWT tokenini localStorage da saqlash qat'iyan taqiqlanadi? Express res.cookie() dagi 3 ta muhim xavfsizlik bayrog'ini yozing:

1. [ ________________________ ]: true ➔ JavaScript orqali cookie o'qilishini butkul taqiqlaydi (XSS himoyasi)
2. [ ________________________ ]: true ➔ Cookie faqat shifrlangan HTTPS protokoli orqali jo'natiladi
3. [ sameSite ]: '________________' ➔ Boshqa saytlardan kelgan soxta so'rovlarda token qo'shilmaydi (CSRF himoyasi)
