Tool Callingning 3 Oltin Qoidasi

  • LLM — aql, Asboblar — qo'llar: Neyrotizim kodni o'zi bajarmaydi; u faqat backend serveringiz uchun aniq JSON chaqiruvini shakllantiradi.
  • JSON Schema — qat'iy shartnoma: description maydoni semantik mayoqdir; u bo'lmasa model qaysi asbobni tanlashni bilmaydi.
  • Xavfli amallar — nazorat ostida: Bazani o'zgartirish va to'lovlar doim Human-in-the-Loop (inson tasdig'i) va eng kam huquqlarni talab qiladi.
