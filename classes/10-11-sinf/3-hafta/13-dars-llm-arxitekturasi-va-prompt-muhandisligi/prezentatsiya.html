Arxitektura Matematikasi

Self-Attention: Nega Kontekst Kvadratik $O(N^2)$ Qimmatlashadi?

Scaled Dot-Product Attention Formulalari

$$ ext{Attention}(Q, K, V) = ext{softmax}\left( rac{Q K^T}{\sqrt{d_k}} ight) V$$

Har bir token 3 ta tenzorga aylanadi: Query (So'rov), Key (Kalit) va Value (Qiymat). Yangi token kontekstdagi avvalgi BARCHA tokenlar bilan skalyar ko'paytiriladi.

Kvadratik Hisoblash Portlashi

  • N = 1,000 token: Diqqat matritsasi = $10^6$ (1 million) ta juftlik bog'lanishi.
  • N = 128,000 token: Diqqat matritsasi = $1.63 imes 10^{10}$ (16 milliard!) ta operatsiya!
  • Xulosa: Prompt hajmi 10 barobar oshsa, GPU hisoblash quvvati 100 barobar ko'p talab qilinadi!

"Lost in the Middle": Nega Model Hujjat O'rtasidagi Faktlarni Unutadi?

1. Boshlanishi (Primacy)

Faktni topish aniqligi: 98%. Birinchi tokenlar transformatorning barcha qatlamlariga langar bo'lib xizmat qiladi.

2. O'rtasi (Yo'qolish Hududi)

Aniqlik 28% gacha qulab tushadi! Stenford tadqiqoti isbotladi: o'rtadagi detallar e'tibordan chetda qoladi.

3. Oxiri (Recency)

Aniqlik: 94%. Eng oxirgi tokenlar model javob berishi arafasida eng yangi holatda bo'ladi.

Ehtimollik Nazariyasi

Sampling: Temperature va Softmax Ehtimollik Taqsimoti

Masshtablangan Softmax Formulalari

$$P(w_i) = rac{\exp(z_i / T)}{\sum_j \exp(z_j / T)}$$

Logitlar ($z_i$) temperaturaga ($T$) bo'linadi:
• T → 0 (Greedy Decoding): Logitlar farqi cheksizga intiladi. Eng yuqori token 100% ehtimol oladi. Kod va JSON uchun SHART!
• T = 0.7: Tahlil va muloqot uchun oltin muvozanat.
• T > 1.2: Ehtimolliklar tekislanadi, model gallyutsinatsiya to'qishni boshlaydi.

Filtrlash Algoritmi

Top-K va Top-P: Xavfli "Dum" Ehtimolliklarni Kesish

Top-K Filtr (Qat'iy Soni)

Model faqat eng yuqori K ta tokenni (masalan, K=50) qoldirib, lug'atdagi qolgan 99,950 ta so'zni o'chiradi. Ammo bitta so'z 99% ishonchga ega bo'lsa ham, qolgan 49 ta keraksiz so'z ro'yxatda qoladi!

Top-P / Nucleus (Yig'indi Ehtimollik)

Model ehtimolliklarni kamayish tartibida yig'ib boradi (masalan, $P=0.90$). Agar 2 ta so'zning o'zi 90% bersa — ro'yxat 2 tagacha qisqaradi! Bu xomxayol safsatani kesib tashlovchi eng aqlli usuldir.

Vektorli Yo'naltirish

In-Context Learning: Few-Shot Orqali Vektor Qoliplash

Zero-Shot (Namunaviy Misolsiz)

"Manzilni JSON qil". Model diqqati milliardlab assotsiatsiyalarga sochiladi. Kalit so'zlarni o'zicha to'qiydi: goh street, goh addr, goh location. Format doimiy o'zgarib turadi!

Few-Shot (2–3 Ta Namunaviy Misol)

Prompt ichida 2-3 ta tayyor KIRISH $ ightarrow$ CHIQISH namunasi beriladi. Model hech qanday qayta o'qitishsiz (Fine-tuning) o'z diqqat matritsasini aynan shu qolipga 100% bog'laydi!

Mashina Shartnomasi

Structured Outputs: 100% Kafolatlangan JSON va DFA Nazorati

Ortiqcha Gapirish Xatosi

Agar model "Albatta, mana siz so'ragan JSON: {...}" deb so'z qo'shsa, backend dasturining JSON.parse() funksiyasi SyntaxError bilan qulab, butun veb-sayt ishlamay qoladi.

Yechim: Logitlarni Majburiy Maskalash

LLM API tizimi JSON Schemani Deterministik Chekli Avtomatga (DFA) aylantiradi. Har bir token chiqarilishidan oldin barcha noo'rin belgilar logitlari majburan $-\infty$ ga tenglashtiriladi.
