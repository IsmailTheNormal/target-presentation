Asosiy Qoidalar: API va JSON Основные правила: API и JSON Key Rules: API and JSON

  • API (Ko'prik): Ikkita dastur bir-biri bilan ma'lumot almashadigan mexanizm.Механизм обмена данными между двумя программами.Mechanism for two applications to exchange data.
  • JSON Formati: "Kalit" : "Qiymat" shaklida saqlanadigan xalqaro ma'lumot standarti.Международный стандарт данных в формате "Ключ" : "Значение".Global data exchange standard formatted as "Key" : "Value".
  • Status 200 vs 404: 200 — ma'lumot muvaffaqiyatli keldi; 404 — bunday manzil topilmadi.200 — данные успешно получены; 404 — ресурс не найден.200 — successful response; 404 — resource not found.
