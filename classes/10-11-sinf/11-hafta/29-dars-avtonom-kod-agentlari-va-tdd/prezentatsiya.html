SANDBOX TEST RUNNER

Xavfsiz Sandboxda Testlarni Run Qilish va Tahlil

AI yozgan kodni hech qachon asosiy serverda ishga tushirmang! U cheklangan vaqt (timeout 3s) va xavfsiz konteynerda bajarilishi shart.

  • Loglarni yig'ish: Barcha konsol xabarlari va Tracebacklar JSON formatida saqlanadi.
  • Chiqish kodi (Exit Code): 0 bo'lsa barcha testlar muvaffaqiyatli, 1 bo'lsa xatolik.
  • Qotib qolishdan himoya: 3 soniyadan oshgan cheksiz while sikllari avtomatik o'chiriladi.
[Sandbox Runner Rejimi]
import subprocess

def run_tests_safe(code_str, test_str):
    full_script = f"{code_str}

{test_str}"
    res = subprocess.run(
        ["python3", "-c", full_script],
        capture_output=True, text=True,
        timeout=3.0 # Xavfsiz vaqt cheklovi
    )
    return {
        "success": res.returncode == 0,
        "stdout": res.stdout,
        "stderr": res.stderr
    }
CRITIC VA REFLEKSIYA

Critic Qanday Qilib Xatoni Tahlil Qiladi va Tuzatadi?

Testlar yiqilganda Coderga butun kodni noldan yozdirish xato! Critic xatolikning tub ildizini (Root Cause) aniqlab, qaysi qatorda nima o'zgarishi kerakligini aytadi.

  • Kutilgan vs Haqiqiy: Nega test 42 kutganida, funksiya None qaytardi?
  • Xatolik nuqtasi: Qaysi o'zgaruvchi yoki if shartida xato ketgani ko'rsatiladi.
  • Boshqa qismlarga tegmaslik: Ishlab turgan testlarni buzib qo'ymaslik qoidasi.
