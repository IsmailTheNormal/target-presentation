01 TDD Refleksiyasining 3 Bosqichi (RED ➔ GREEN ➔ REFACTOR)

Dars Missiyasi: Coder ➔ Runner ➔ Critic zanjiridan iborat avtonom multi-agent tizimini qurish: kod generatsiyasi, testlarni xavfsiz sandboxda run qilish va xatolarni inson aralashuvisiz tuzatish.

TDD Refleksiyasining 3 Bosqichi:
1. RED (Qizil): Amalga oshirishdan oldin chekka holatlar uchun qat'iy testlar yozish.
2. GREEN (Yashil): Coder testlardan o'tish uchun toza Type Hints bilan kod yozadi.
3. REFACTOR / HEAL: Critic xato qatorini aniqlab, boshqa testlarni buzmasdan tuzatadi.
02 Izolyatsiyalangan Sandbox Test Runner Arxitekturasi

Xavfsiz sandbox muhitida testlarni ishga tushirish kodi:

import subprocess

def run_tests_safe(code_str: str, test_str: str) -> dict:
    full_script = f"{code_str}\n\n{test_str}"
    res = subprocess.run(
        ["python3", "-c", full_script],
        capture_output=True, text=True,
        timeout=3.0 # Timeout guard protiv while True
    )
    return {"ok": res.returncode == 0, "stderr": res.stderr}
