STRUKTURAVIY SAQLASH · SQLITE SXEMASI

Epizodik Xotira: SQLite-da Voqealar Arxivi

Agent amalga oshirgan har bir harakat va foydalanuvchi qoidalari SQLite relyatsion jadvalida indekslanib saqlanadi:

SQLite Sxemasi 
CREATE TABLE agent_memories (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  session_id TEXT NOT NULL,
  user_id TEXT NOT NULL,
  category TEXT CHECK(category IN ('preference','fact','error','task')),
  content TEXT NOT NULL,
  importance REAL DEFAULT 1.0, -- 1.0 dan 5.0 gacha
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_user_cat ON agent_memories(user_id, category);

Epizodlarni Qidirish va Filtrlash

Prompt yozilishidan oldin agent SQL so'rovi orqali foydalanuvchining shaxsiy preferensiyalarini yuklab oladi:

SELECT content FROM agent_memories 
WHERE user_id = 'user_99' 
  AND category = 'preference' 
ORDER BY importance DESC LIMIT 5;
✓ Natija: Agent "Ali faqat Python va Dark Mode ishlatadi" degan faktni bilgan holda kod yozadi!
MATEMATIK MA'NO · EMBEDDINGS & TOP-K

Semantik Xotira: Vektor Qidiruv va Kosinus O'xshashlik

Foydalanuvchi savolidagi so'zlar bazada aynan bir xil bo'lmasa, semantika yordamga keladi: matn 1536 o'lchamli vektorga aylantiriladi:

Kosinus O'xshashlik Geometriyasi

cos(θ) = (A · B) / (||A|| × ||B||)
  • cos = 1.0: Ma'no 100% bir xil (masalan: "avtomobil" va "mashina").
  • cos > 0.75: Yuqori bog'liqlik — agent promptiga qo'shiladi!
  • cos < 0.30: Begona mavzu (filtrdan o'tkazilmaydi).
Vektor Qidiruv Konveyeri 
// 1. Matnni vektorga aylantirish
const queryVector = await embed("Kiber-xavfsizlik parollari");

// 2. Vektor bazadan eng yaqin 3 ta xotirani tortish (Top-K)
const memories = await vectorDb.query({
  vector: queryVector,
  topK: 3,
  minSimilarity: 0.75
});

// 3. Promptga kontekst sifatida uzatish
const context = memories.map(m => m.text).join("
");

Xotira Bahosi Formulasi

Stenford generativ agentlar formulasi:

Score = α·Recency + β·Importance + γ·Relevance
  • Recency: Voqea qachon sodir bo'lgani (vaqt o'tishi bilan kamayadi).
  • Importance: Muhimlik darajasi (kalitlar, ismlar = 5.0).
  • Relevance: Hozirgi savolga kosinus o'xshashligi.
