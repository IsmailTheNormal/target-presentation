REACT TSIKLI

Thought → Action → Observation

Agent har iteratsiyada kuzatadi, harakat qiladi va natijani qayta o‘qiydi.

Amaliy bosqichlar

  1. Kod bazasini o‘qish (Read)
  2. Reja va fayllar ro‘yxati (Plan)
  3. Tahrir / buyruq (Action)
  4. Test va diff natijasi (Observation)
  5. Xato bo‘lsa yana 2-qadamga qaytish
while (!testsGreen && iterations < MAX) {
  const obs = await read(state);
  const action = await plan(obs);
  await apply(action);
}

QIZIL · YASHIL · REFAKTORING

Test birinchi yoziladi — agent keyin

Qizil test agentga aniq maqsad beradi; yashildan keyingi refaktoring regressiyani ushlaydi.

Amaliy bosqichlar

  1. Qizil: xatti-harakat testi yoziladi va o‘tmaydi
  2. Yashil: agent eng oddiy kodni yozadi
  3. Refaktor: structura tozalanadi, test yashil qoladi
  4. Hisobot: diff + o‘tgan testlar soni
// 1) QIZIL
test('not found -> null', () => assert.equal(find([]), null));
// 2) YASHIL
const find = xs => xs[0] ?? null;
// 3) REFAKTOR — test o'zgarmaydi
