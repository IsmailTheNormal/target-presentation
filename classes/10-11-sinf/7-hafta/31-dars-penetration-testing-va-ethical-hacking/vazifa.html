2-Topshiriq: OWASP API #1 BOLA / IDOR Zaifligini Kodda Tuzatish

Quyidagi Express endpointida BOLA zaifligi mavjud (har qanday user boshqaning maxfiy hujjatini `docId` ni o'zgartirib o'qiy oladi). Kodni shunday o'zgartiringki, u faqat so'rov yuborgan `req.user.id` ga tegishli hujjatlarni qaytarsin, aks holda `403 Forbidden` tashlasin:
app.get('/api/docs/:id', (req, res) => { const doc = db.get(req.params.id); res.json(doc); });

TUZATILGAN XAVFSIZ KOD (IDOR FIX):
app.get('/api/docs/:id', authenticateToken, (req, res) => {
  const doc = db.get(req.params.id);
  if (!doc) {
    return res.status(404).json({ error: 'Hujjat topilmadi' });
  }
  // BOLA/IDOR QALQONI:
  if (doc.owner_id !== req.user.id) {
    return res.status(403).json({ error: 'Ruxsat berilmagan! (403 Forbidden)' });
  }
  res.json({ success: true, doc });
});

3-Topshiriq: HTTP Security Headers va Helmet Integratsiyasi

Brauzer darajasidagi hujumlarning oldini olish uchun server qaysi 3 ta muhim HTTP sarlavhasini qaytarishi kerak? Har birining vazifasini yozing (`Content-Security-Policy`, `X-Frame-Options`, `Strict-Transport-Security`) va Node.js Express loyihasiga `helmet` paketini qanday ulashni ko'rsating.

SECURITY HEADERS TAHLILI VA INTEGRATSIYA:
1. X-Frame-Options: DENY — saytni iframe ichiga tiqish (Clickjacking) hujumini to'xtatadi.
2. Content-Security-Policy (CSP) — faqat ruxsat berilgan manbalardan skript yuklashga ruxsat berib, XSS ni to'xtatadi.
3. Strict-Transport-Security (HSTS) — brauzerni faqat shifrlangan HTTPS orqali ulanishga majburlaydi (SSL Strip himoyasi).
Helmet kodi:
const helmet = require('helmet');
app.use(helmet());

4-Topshiriq: Shaxsiy CLI Skaneriga RegEx Qoidalarini Qo'shish

Darsdagi shaxsiy Node.js skanerimiz (`scanner/scanner.js`) JavaScript va HTML fayllarni sizib chiqqan kalitlarga tekshiradi. Ushbu skanerga GitHub Personal Access Token (`ghp_[a-zA-Z0-9]{36}`) va AWS Access Key ID (`AKIA[0-9A-Z]{16}`) larni qidiruvchi RegEx qoidalarini qanday qo'shish kerakligini kod shaklida yozing.

SCANNER REGEX QOIDALARI:
const SECRET_PATTERNS = [
  {
    name: 'GitHub Personal Access Token',
    regex: /ghp_[a-zA-Z0-9]{36}/g,
    severity: 'CRITICAL',
    cvss: 9.8
  },
  {
    name: 'AWS Access Key ID',
    regex: /(?:A3T[A-Z0-9]|AKIA|AGPA|AIDA|AROA|AIPA|ANPA|ANVA|ASIA)[A-Z0-9]{16}/g,
    severity: 'CRITICAL',
    cvss: 9.5
  }
];
