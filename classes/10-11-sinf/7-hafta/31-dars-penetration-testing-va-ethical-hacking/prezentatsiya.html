BOLA / IDOR: Zamonaviy API larning 1-Raqamli Xatosi

Server foydalanuvchining autentifikatsiyasini tekshiradi, lekin so'ralgan obyekt aynan unga tegishli ekanini tekshirmaydi.
// ❌ ZAIF KOD: Faqat auth bor, lekin ob'ekt huquqi yo'q app.get('/api/v1/users/:id/balance', verifyToken, async (req, res) => { const user = await db.findUser(req.params.id); // Hujumchi :id ni 42 qilib boshqaning hisobini ko'radi! return res.json({ balance: user.balance }); }); // ✅ XAVFSIZ KOD: Kiruvchi token bilan ob'ekt egasi tekshiriladi app.get('/api/v1/users/:id/balance', verifyToken, async (req, res) => { if (req.user.id !== req.params.id && req.user.role !== 'admin') { return res.status(403).json({ error: '403 Forbidden: Kirish taqiqlangan' }); } const user = await db.findUser(req.params.id); return res.json({ balance: user.balance }); });
Brauzer Mudofaasi

HTTP Security Headers: 4 Ta Mudofaa Qalqoni

Maxsus javob sarlavhalari brauzerga foydalanuvchini Clickjacking, XSS va MITM tinglashlaridan himoya qilishni buyuradi.
Content-Security-Policy (CSP)

Begona xakerlik JavaScript skriptlari va stillar bajarilishini to'liq bloklaydi.

X-Frame-Options: DENY

Saytni ko'rinmas iframe ichiga joylab aldash (Clickjacking) hujumining oldini oladi.

Strict-Transport-Security (HSTS)

Brauzerni faqat shifrlangan HTTPS protokoli orqali ulanishga majburlaydi (SSL Strip himoyasi).

X-Content-Type-Options: nosniff

Zararli dasturlarni soxta rasm qiyofasida yuklash (MIME-sniffing) xavfini kesadi.

Maxfiy Kalitlar Sizishi

RegEx Orqali Maxfiy Kalitlar Sizishini Fosh Qilish

Ko'plab dasturchilar xatolik tufayli AWS kalitlari va shaxsiy parollarni API javoblarida ochiq holda qaytarib yuborishadi.
// Kiber-skanerimizdagi RegEx detektor qoidalari: const RULES = [ { name: 'AWS Access Key', regex: /AKIA[0-9A-Z]{16}/g, cvss: '9.8 CRITICAL' }, { name: 'JWT Token Leak', regex: /eyJ[A-Za-z0-9_-]{10,}\.[A-Za-z0-9_-]{10,}\.[A-Za-z0-9_-]{10,}/g, cvss: '8.8 HIGH' }, { name: 'Plaintext Password', regex: /password\s*[:=]\s*["'][^"']+["']/gi, cvss: '9.0 CRITICAL' } ]; // Tekshirish algoritmi: const matches = apiResponseBody.match(RULES[0].regex); if (matches) { triggerVulnerabilityAlert('AWS Key Exposed in API Body!'); }
Bulutli Xatarlar

SSRF: Bulutli Metama'lumotlar Hujumi (169.254.169.254)

Server-Side Request Forgery hujumi serverni o'zining nomidan ichki yopiq AWS/GCP metama'lumotlariga so'rov yuborishga majbur qiladi.
Capital One Keysi (2019)

Hujumchi tekshirilmagan parametr orqali 169.254.169.254 manzilini bergan. Server IAM admin kalitini qaytargan va 106 mln kredit kartalari o'g'irlangan.

To'g'ri Mudofaa

Ichki IP diapazonlarini (127.0.0.1, 169.254.0.0/16) qat'iy bloklash va faqat ruxsat berilgan tashqi domenlarga (Whitelist) ruxsat berish.
