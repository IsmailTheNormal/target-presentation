DevSecOps Quvuri va Cloud Audit Demo Day

Qanday qilib kiberxavfsizlikni rivojlanish to'sig'idan avtomatlashgan himoya qalqoniga aylantirish mumkin? GitHub Actions quvurida 4 ta xavfsizlik darvozasi (Security Gates): Secret Scanning, SAST, Trivy va Checkov. Demo Day poligonida to'liq himoyalangan deploy.

Paradigma O'zgarishi

DevOps vs DevSecOps: Xavfsizlik Endi To'siq Emas

Eski Yondashuv (Xavfsizlik To'sig'i)

  • Dasturchilar 2 oy kod yozadi, serverga chiqaradi, so'ng xavfsizlik bo'limi keladi.
  • Audit 200 ta zaiflik topib, ishga tushishdan 1 kun oldin butun loyihani to'xtatadi.
  • Jamoalar to'qnashuvi: dasturchilar xavfsizlik xodimlarini dushman deb biladi.

Zamonaviy DevSecOps (Shift-Left)

  • Xavfsizlik bevosita kod ombori va Git quvuriga avtomat singdirilgan.
  • Har bir commit Pull Request ochilgan zahoti 15 soniyada tekshiriladi.
  • Dasturchi xatoni o'z IDE sida darhol ko'rib, bir necha soniyada tuzatadi.
Quvur Anatomiyasi

CI/CD Quvuridagi 4 Ta Xavfsizlik Darvozasi

Avtomatlashgan Himoya Quvuri Sxemasi

git push → [ Gate 1: Gitleaks (Secret Scan) ]
             ↓
         [ Gate 2: Semgrep (SAST Code Logic) ]
             ↓
         [ Gate 3: Checkov (IaC Terraform) ]
             ↓
         [ Gate 4: Trivy (Docker CVE Scan) ]
             ↓
SUCCESS → Deploy to AWS Production (K8s / ECS)

'Break the Build' Qoidasi

Agar 4 ta skanerdan BITTASI bo'lsa ham HIGH yoki CRITICAL zaiflik topsa, quvur darhol to'xtaydi (Exit Code 1). Himoyasiz kod jismonan serverga o'ta olmaydi!

Sirlar va Kod Himoyasi

1-Darvoza: Gitleaks va 2-Darvoza: SAST (Semgrep)

Gate 1: Secret Scanning

Gitleaks: Git dagi Sirlarni Tutuvchi Qopqon

  • Commit ichidagi o'zgarishlarni Shannon entropiyasi va shablonlar bilan tekshiradi.
  • AWS (AKIA...), Stripe va GitHub tokenlarini bir zumda ushlaydi.
  • Dasturchi noutbukidan chiqmasidan oldin push qilishni bloklaydi.
Gate 2: SAST Code Analysis

Semgrep: Ilova Kodining Statik Tahlili

  • Kodni ishga tushirmasdan turib, xom matnni tahlil qiladi (White-box).
  • Xavfli SQL so'rovlarni va XSS xatolarini sintaksis darajasida fosh etadi.
  • Eskirgan zaif shifrlash usullarini (MD5, SHA1) darhol belgilaydi.
Infratuzilma va Konteynerlar

3-Darvoza: Checkov (IaC) va 4-Darvoza: Trivy (Konteynerlar)

Gate 3: IaC Compliance

Checkov: Terraform va Kubernetes Auditi

  • HCL fayllarini CIS AWS Benchmark xavfsizlik talablariga solishtiradi.
  • Ochiq SSH portlari va shifrlanmagan disklarni fosh qiladi.
  • Ochiq S3 chelaklar yaratilishini quvurda to'xtatadi.
Gate 4: Container CVEs

Trivy: Docker Obrazlari va Paketlar Tahlili

  • Docker tagidagi operatsion tizim paketlarini tekshiradi.
  • Global CVE bazasiga qarab, ma'lum zaifliklarni aniqlaydi.
  • Xavfli npm va Python kutubxonalarini bloklaydi.
Temir CI/CD Qoidasi

"Break the Build" Siyosati: Prodda Murosa Yo'q

Nega Ogohlantirishlarni E'tiborsiz Qoldirib Bo'lmaydi?

Ko'p jamoalar continue-on-error: true yozib, skanerlarni behuda spomga aylantiradi. DevSecOps da kritik xato relizni TO'XTATISHI shart.

- name: Run Trivy Scanner
  uses: aquasecurity/trivy-action@master
  with:
    image-ref: 'target-api:latest'
    exit-code: '1' # Fails the pipeline!
    severity: 'CRITICAL,HIGH'

Natija: Beg'ubor Production

  • Serverlarda faqat tekshirilgan va imzolangan konteynerlar ishlaydi.
  • API kalitlarining ochiq Git ga tushib qolish ehtimoli 0 ga teng.
  • SOC 2 va ISO 27001 xalqaro auditlari avtomatik tarzda topshiriladi.
Muhandislik Kodi

.github/workflows/devsecops.yml Fayli Spetsifikatsiyasi

name: Enterprise DevSecOps Gatekeeper
on: [push, pull_request]

jobs:
  security_gates:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      # Gate 1: Secret Hunting
      - name: Gitleaks Scan
        uses: gitleaks/gitleaks-action@v2

      # Gate 2: IaC Benchmark Verification
      - name: Checkov IaC Compliance
        run: checkov -d . --framework terraform --compact

      # Gate 3: Container CVE Evaluation
      - name: Trivy Vulnerability Scan
        run: trivy image --exit-code 1 --severity CRITICAL target-app:prod

      # Gate 4: Zero Trust Deployment
      - name: Deploy to Cloud (Conditional on All Gates)
        if: success()
        run: echo "Production deployment completed securely!"
Dasturiy Zanjir Hujumi

SolarWinds (2020): CI/CD Quvurining O'zi Buzilganda

Sunburst Hujumi Xronologiyasi

  • Xakerlar mijozlarni emas, balki SolarWinds kompaniyasining CI/CD serverini buzdi.
  • Kompilyatsiya vaqtida zararli kod avtomatik tarzda rasmiy yangilanishga qo'shildi.
  • 18 000 ta yirik kompaniya va AQSh vazirliklari rasmiy yangilanishni yuklab oldi.

DevSecOps Uchun Saboq

  • Dasturiy ta'minotni kriptografik raqamli imzo bilan tasdiqlash.
  • SBOM: dastur ichidagi har bir paket va kutubxona pasportini yuritish.
  • CI/CD serverlarini har bir run dan keyin qayta yaratiluvchi izolyatsiyada saqlash.
