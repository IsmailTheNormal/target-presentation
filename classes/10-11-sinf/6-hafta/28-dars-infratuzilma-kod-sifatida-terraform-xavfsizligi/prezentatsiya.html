Infratuzilma Kod Sifatida (IaC) va Terraform Xavfsizligi

Nega qo'lda boshqariladigan ClickOps o'rnini deklarativ HCL kodi egalladi, ammo keng ko'lamli sizishlarga yo'l ochdi? `terraform.tfstate` dagi ochiq sirlar, 0.0.0.0/0 ochiq portlar xavfi hamda Checkov skaneri yordamida Shift-Left xavfsizligini joriy etish.

Infratuzilma Evolyutsiyasi

ClickOps O'limi va Kod Ko'rinishidagi Infratuzilma Xatarlari

Qo'lda Boshqarish (ClickOps) Falokati

  • Muhandis AWS konsolida 50 ta tugma bosadi: insoniy xatolik muqarrar.
  • Konfiguratsiya siljishi (Drift): real bulut bir haftada hujjatlardan uzilib qoladi.
  • Falokat paytida tizimni oldingi xavfsiz holatga qaytarib bo'lmaydi.

Deklarativ IaC (Terraform) Xavfi

  • Git dagi bitta xato bir necha soniyada 100 ta himoyasiz serverni ishga tushiradi.
  • Avtomatlashtirish nafaqat tizimni, balki zaifliklarni ham butun dunyoga yoyadi.
  • Terraform kodlari ko'pincha maxfiy API kalitlari bilan birga GitHub ga sizib chiqadi.
HCL Anatomiyasi

Terraform Bulutli Infratuzilmani Qanday Boshqaradi

HCL Resursining Sintaksisi

resource "aws_security_group" "web_sg" {
  name = "production-web-firewall"
  description = "Inbound HTTP and restricted SSH"
  vpc_id = aws_vpc.main.id

  ingress {
    from_port = 443
    to_port = 443
    protocol = "tcp"
    cidr_blocks = ["0.0.0.0/0"] # OK: HTTPS
  }
}

Deklarativ model: biz kerakli holatni yozamiz (What), Terraform esa AWS API larini o'zi chaqiradi (How).

Terraform Buyruqlari Hayot Tsikli

  • terraform init: Provayderlarni yuklaydi va backendni tayyorlaydi.
  • terraform plan: Kod va real bulutni solishtirib reja tuzadi (quruq sinov).
  • terraform apply: Bulutda resurslarni yaratadi yoki o'zgartiradi.
  • terraform destroy: Infratuzilmani butunlay o'chirib tashlaydi.
Terraform ning Katta Sirlari

terraform.tfstate Falokati: Sirlarning Ochiq Matnda Qolishi

State Fayli Nima?

Terraform siz yozgan kod va AWS dagi real resurslar bog'lanishini terraform.tfstate JSON faylida saqlaydi.

{
  "type": "aws_db_instance",
  "name": "production_sql",
  "attributes": {
    "username": "postgres_admin",
    "password": "SuperSecretP@ssword2026!",
    "endpoint": "prod-db.c7x.rds.amazonaws.com"
  }
}

Nega Bu Kiber-Halokat?

  • O'zgaruvchi sensitive = true bo'lsa ham, .tfstate ichida parol OCHIQ MATNDA saqlanadi!
  • Faylni tasodifan GitHub ga yuklash butun ma'lumotlar bazasini xakerlarga topshiradi.
  • Noutbukdagi mahalliy .tfstate fayli shifrlanmagan bo'ladi.
Eng Xavfli IaC Xatolari

Xavfli Standartlar: 0.0.0.0/0 va Ochiq Portlar

CKV_AWS_24

SSH Butun Dunyoga Ochiq

ingress {
  from_port = 22
  to_port = 22
  protocol = "tcp"
  cidr_blocks = ["0.0.0.0/0"]
}

Botnetlar 22-portni bir zumda topib, root parolini buzish hujumini boshlaydi.

CKV_AWS_17

Ommaviy Ma'lumotlar Bazasi

resource "aws_db_instance" {
  engine = "postgres"
  publicly_accessible = true
  skip_final_snapshot = true
}

Baza ommaviy IP oladi va to'g'ridan-to'g'ri tashqi hujumlarga nishon bo'ladi.

CKV_AWS_145

Shifrlanmagan Xotira

resource "aws_ebs_volume" {
  availability_zone = "us-east-1a"
  size = 100
  encrypted = false
}

Moliya va foydalanuvchi ma'lumotlari bo'lgan disklar shifrsiz saqlanadi.

Shift-Left Tamoyili

Deploydan Oldin To'xtatish: Checkov va Trivy Statik Skanerlari

Shift-Left Xavfsizligi Nima?

Zaifliklarni ishlayotgan serverdan izlash o'rniga, xavfsizlik chapga — kod yozish va Pull Request bosqichiga ko'chiriladi.

$ checkov -f main.tf
FAILED: CKV_AWS_24 (Port 22 SSH open to 0.0.0.0/0)
FAILED: CKV_AWS_20 (S3 Bucket Public Access open)
PASSED: CKV_AWS_145 (S3 Server Side Encryption)

Policy-as-Code Qanday Ishlaydi?

  • Checkov kodning sintaktik daraxtini (AST) o'qib chiqadi.
  • Har bir qatorni 1000 dan ortiq CIS xavfsizlik qoidalariga solishtiradi.
  • Agar xavfli qator topilsa, CI/CD quvuri kodni qabul qilmaydi (Exit Code 1).
Backend Arxitekturasi

Xavfsiz Remote State: S3 + KMS + DynamoDB Qulflash

Himoyalangan Backend Konfiguratsiyasi

terraform {
  backend "s3" {
    bucket = "corp-terraform-state-prod"
    key = "finance/terraform.tfstate"
    region = "us-east-1"
    encrypt = true
    kms_key_id = "arn:aws:kms:.../key-01"
    dynamodb_table = "terraform-locks"
  }
}

tfstate Faylining 3 Qatlamli Himoyasi

  • 1. KMS Shifrlash: Barcha sirlar AWS apparat kaliti (KMS) bilan shifrlanadi.
  • 2. DynamoDB Qulfi: Ikki muhandis bir vaqtda apply qilib tizimni buzishini to'xtatadi.
  • 3. IAM Izolyatsiyasi: Chelakka faqat avtomatlashgan CI/CD serverlari kira oladi.

Oltin Standart

Xavfsiz IaC Muhandisining Konstitutsiyasi

4 Ta Mustahkam Ustun

  • 1. Kodda nol sir: HCL ichida hech qachon parol yozilmaydi (Vault ishlatiladi).
  • 2. Masofaviy State: Noutbukda `.tfstate` saqlash mutlaqo taqiqlanadi.
  • 3. Checkov darvozasi: Xatoli kod hech qachon bulutga deploy qilinmaydi.
  • 4. Kichik huquqlar: Terraform ga to'liq root huquqi emas, kerakli ruxsatlar beriladi.
