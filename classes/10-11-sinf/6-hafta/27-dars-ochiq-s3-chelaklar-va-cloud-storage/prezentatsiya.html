Kirish Huquqlari Mexanikasi

Ikki Xil Ruxsat Tizimi: ACL vs Bucket Policy

📜 Eski S3 ACL (O'tgan Zamondan Qolgan)

  • 2006-yilgi meros: har bir faylga alohida ruxsat berish (Object ACL).
  • Xavf: muhandis tasodifan faylni `--acl public-read` bilan yuklab qo'yishi mumkin edi.
  • Zamonaviy AWS standarti: ACL larni butunlay o'chirish (Bucket Owner Enforced)!

🛡️ AWS Bucket Policy (Zamonaviy JSON)

  • Butun chelak darajasida markazlashtirilgan JSON xavfsizlik qoidasi.
  • Qat'iy shartlar (Condition): faqat VPC Endpoint orqali yoki faqat TLS bilan kirish.
  • Qat'iy rad etish (Deny) har qanday ruxsatni (Allow) yo'qqa chiqaradi.
Zaiflik Tahlili

Xavfli Siyosat Anatomiyasi: "Principal: *"

❌ Zaif Siyosat (Kiber-Szish)

{
  "Effect": "Allow",
  "Principal": "*",          // 🚨 ХАКЕР СО ВСЕГО МИРА!
  "Action": "s3:GetObject",
  "Resource": "arn:aws:s3:::kyc-passports/*"
}

`*` belgisi butun dunyodagi har qanday nomsiz foydalanuvchiga barcha fayllarni o'qish huquqini beradi.

✅ Xavfsiz Siyosat (Faqat Ichki VPC)

{
  "Effect": "Allow",
  "Principal": "*",
  "Action": "s3:GetObject",
  "Resource": "arn:aws:s3:::kyc-passports/*",
  "Condition": {
    "StringEquals": {
      "aws:sourceVpce": "vpce-1a2b3c4d"
    }
  }
}

Fayllarga kirish FAQAT kompaniya ichki serverlariga (VPC Endpoint) cheklangan.

AWS Asosiy To'sig'i

S3 Block Public Access (BPA): 4 Qutqaruv Qalqoni

2018-yilda AWS doimiy kiber-szishlardan charchab, barcha xatoliklarni to'xtatuvchi 4 ta markaziy kalitni yaratdi:

  • 1. BlockPublicAcls: Yangi ommaviy ACL ruxsatlar bilan fayl yuklashni butunlay taqiqlaydi.
  • 2. IgnorePublicAcls: Mavjud barcha ommaviy ACL larni bir zumda bekor qiladi.
  • 3. BlockPublicPolicy: Ommaviy kirish beruvchi yangi siyosatlarni saqlashga yo'l qo'ymaydi.
  • 4. RestrictPublicBuckets: Chet foydalanuvchilar kirishini batamom cheklaydi.
Ma'lumotlar Himoyasi

Serverda Shifrlash: SSE-S3 vs SSE-KMS

🔐 SSE-S3 (Birlamchi AES-256)

2023-yildan boshlab barcha fayllar avtomatik AES-256 bilan shifrlanadi.

  • Bepul va avtomatik ishlaydi.
  • Kamchiligi: S3 ga kirgan har kim faylni ochiq o'qiydi.

🛡️ SSE-KMS (KMS Kalitlari Bilan Himoya)

Alohida boshqariluvchi AWS KMS kalitlari orqali shifrlash:

  • Xaker S3 ga kirgan taqdirda ham, `kms:Decrypt` ruxsatisiz faylni o'qiy olmaydi!
  • Har bir shifrni ochish harakati audit logiga yoziladi.

S3 Uchun CIS Benchmark Standartlari

📋 CIS Majburiy Talablari

  • 2.1.1: S3 Block Public Access ni AKKAUNT va CHELAK darajasida yoqish.
