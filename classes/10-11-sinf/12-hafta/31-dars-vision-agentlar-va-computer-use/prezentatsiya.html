ANTHROPIC COMPUTER-USE API · HARAKATLAR TSIKLI

Computer-Use API: Skrinshot → Qaror → Harakat

Tsiklning To'rt Bosqichi

  1. Joriy ekran skrinshoti modelga rasm sifatida yuboriladi.
  2. Model harakat va [x, y] koordinatalari bilan tool_use qaytaradi.
  3. Drayver klik, matn kiritish yoki tugma bosishni bajaradi.
  4. Yangi skrinshot olinadi va natija tayyor bo'lguncha tsikl takrorlanadi.

Model Javobi (tool_use)

{ "role": "assistant", "content": [{ "type": "tool_use", "name": "computer", "input": { "action": "left_click", "coordinate": [512, 384] } }] }

Koordinatalar har doim model to'riga (masalan, 1024×768) normallashtirilgan, real monitorga emas.

VISUAL GROUNDING · KOORDINATALARNI O'TKAZISH

Visual Grounding: 1024×768 To'ridan Haqiqiy Piksellarga

Nega Koordinatalar Siljiydi?

Model kichraytirilgan skrinshotni ko'radi. Uning koordinatalari bo'yicha 4K monitorda to'g'ridan-to'g'ri bossangiz, kursor yuzlab piksel chetga ketadi.

Formula:

scaleX = screen.width / 1024, scaleY = screen.height / 768, so'ng round().

Ishchi Drayver Kodi

// Model qaytargan koordinatalar const apiX = 512, apiY = 384; const apiW = 1024, apiH = 768; // Haqiqiy ekranga o'tkazish const realX = Math.round(apiX * (screen.width / apiW)); const realY = Math.round(apiY * (screen.height / apiH)); pyautogui.click(realX, realY);

HiDPI: devicePixelRatio'ni hisobga oling va skrinshotni model kutgan masshtabda oling.

COMPUTER-USE XAVFSIZLIGI · SANDBOX + HITL

Ekran Agentining Xavflari va Uch Himoya Qatlami

  • Vayronkor klik: faylni o'chirish yoki to'lov yuborish.
