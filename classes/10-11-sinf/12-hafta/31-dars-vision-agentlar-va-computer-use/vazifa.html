Vision Model Koordinatalarini O'tkazish

1024×768 to'ri koordinatalarini real ekran piksellariga o'tkazadigan va natijani yaxlitlaydigan toScreen(apiX, apiY, screenW, screenH) funksiyasini yozing.

Etalon yechim

function toScreen(apiX, apiY, screenW, screenH) {
  const realX = Math.round(apiX * (screenW / 1024));
  const realY = Math.round(apiY * (screenH / 768));
  return { realX, realY };
}

for (let step = 0; step < MAX_STEPS; step++) {
  const shot = captureScreen();
  const action = await visionModel(shot, task);

  if (action.type === "delete" || action.type === "send") {
    if (!(await askHuman(action))) break;   // HITL
  }

  const { realX, realY } = toScreen(action.x, action.y, W, H);
  driver.click(realX, realY);
  if (await verifyResult()) break;
}

Ekran Agenti Xavfsizlik Auditi

Uch tahdidni sanang (ekranda prompt injection, vayronkor klik, .env sizib chiqishi) va har biriga aniq texnik nazorat taklif qiling: sandbox, least privilege yoki HITL.

Etalon yechim

1. Prompt injection на экране → sandbox + белый список приложений.
2. Разрушительный клик → HITL перед delete/send/payment.
3. Утечка .env → запрет монтирования домашней папки, read-only secrets.
