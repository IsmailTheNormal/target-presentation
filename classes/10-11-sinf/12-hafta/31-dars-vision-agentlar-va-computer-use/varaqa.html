Kiber-Missiya

DOM chegarasidan chiqib, ekran piksellarini ko'radigan va sichqonchani boshqaradigan Computer-Use agentini loyihalash: skrinshot → vision model → koordinata → harakat → tekshiruv tsiklini tushunish va xavfsiz sandboxda sinash.

01 Computer-Use Arxitekturasi: Ko'z, Qaror va Qo'l

1. Ko'z (Skrinshot)

Agent ekran suratini oladi va uni multimodelga rasm sifatida yuboradi.

2. Qaror (Vision Model)

Model tugmani piksellar bo'yicha topadi, [x, y] koordinatalari va tanlangan harakatni qaytaradi.

3. Qo'l (Drayver)

PyAutoGUI yoki OS drayveri klik, matn kiritish yoki tugma bosishni bajaradi.

4. Tekshiruv (Yangi Skrinshot)

Har harakatdan keyin yangi surat olinadi: natija tasdiqlanmaguncha tsikl takrorlanadi.

{ "type": "tool_use", "name": "computer", "input": { "action": "left_click", "coordinate": [512, 384] } }
02 Visual Grounding: 1024×768 To'ridan Real Pikselga

❌ Oddiy xato

Model koordinatalari masshtablashsiz pyautogui.click() ga uzatiladi. Retina yoki 4K da kursor yuzlab pikselga xato qiladi.

pyautogui.click(apiX, apiY); // xato!

✅ Oltin standart

Avval scaleX va scaleY hisoblanadi, so'ng natija round() bilan butun pikselga yaxlitlanadi.

const rx = Math.round(apiX * (screen.width / 1024)); const ry = Math.round(apiY * (screen.height / 768));

Formula: realX = round(apiX × screen.width / 1024), realY = round(apiY × screen.height / 768). HiDPI uchun devicePixelRatio'ni ham hisobga oling.
