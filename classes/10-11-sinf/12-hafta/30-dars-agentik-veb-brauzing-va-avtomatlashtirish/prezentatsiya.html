TEXNOLOGIK STEK

Headless Brauzer Arxitekturasi: CDP va Playwright

CDP Mexanizmi

Chromium yadrosi bilan to'g'ridan-to'g'ri JSON-RPC

Headless brauzer — bu grafik oynasisiz (GUI) ishlovchi to'liq Chromium brauzeri. Biz uni CDP protokoli orqali boshqaramiz: klaviatura, sichqoncha va DOM hodisalarini uzatamiz.

# Playwright orqali headless sessiya
from playwright.async_api import async_playwright

async with async_playwright() as p:
    browser = await p.chromium.launch(headless=True)
    page = await browser.new_page()
    await page.goto("https://market.uz")
Veb-Agent Vositalari
Selenium: Eski, sekin ishlovchi WebDriver. Tezkor AI tsikllar uchun og'ir.
Playwright: Tezyurar, asinxron, element paydo bo'lishini avtomatik kutadi.
Browser-Use / Stagehand: Playwright ustidagi AI qatlam: Vision + DOM Pruning + Harakatlar bajaruvchisi.

GIBRID YONDASHUV

Vision-Action Tsikli: Skrinshot va DOM Selektorlar Gibridi

1. Kuzatish (Observe)

Skrinshot + Set-of-Mark (SoM)

Brauzer skrinshot oladi va barcha bosiladigan elementlarga raqamli ramka `[12]` qo'yadi (Set-of-Mark). AI inson kabi ko'radi.

2. Fikrlash (Plan)

Maqsad tahlili va reja

Agent maqsad bilan ekranni solishtiradi: "Reklama oynasi qidiruvni to'syapti. Avval [3] ni yopish, keyin [12] ga qidiruv kiritish kerak".

3. Bajarish (Act)

Playwright orqali hodisa

Agent qat'iy JSON chiqaradi: `{"action": "click", "index": 3}`. Playwright apparat darajasida klik qiladi va DOM yangilanishini kutadi.

BUYRUQLAR SPETSIFIKATSIYASI

Agent Harakatlar Sxemasi: Qat'iy JSON Protokoli

Mavjud Harakatlar To'plami
  • click(index) — Berilgan indeksli tugma/havolani bosish
  • type(index, text) — Maydonni tozalab, matn yozish
  • scroll(direction, px) — Sahifani pastga/yuqoriga aylantirish
  • wait(seconds) — AJAX ma'lumotlari yuklanishini kutish
  • extract(schema) — Ko'ringan ma'lumotlarni JSON ga olish
  • finish(summary) — Vazifa yakunlanganini e'lon qilish
Model JSON Chiqishi
{
  "thought": "Do'kon qidiruv maydoni [4] raqamida topildi. 'MacBook' so'zini yozamiz va [5] Izlash tugmasini bosamiz.",
  "action": {
    "name": "type",
    "params": {
      "index": 4,
      "text": "MacBook Pro M3"
    }
  },
  "follow_up": {
    "name": "click",
    "params": { "index": 5 }
  }
}
KIBERXAVFSIZLIK VA XAVFSIZ CHEGARALAR

Bloklanishdan Himoya: Rate Limiting va Inson Nazorati (HITL)

1. CAPTCHA Qat'iy Qoidasi

Avtomat CAPTCHA buzilmaydi

Agent HECH QACHON Cloudflare yoki reCAPTCHA ni avtomat yorishga urinmasligi shart. Captcha chiqqanda jarayon to'xtatilib, insonga (HITL) topshiriladi.

2. Tabiiy Insoniy Kechikish

Tasodifiy kechikish (Jitter)

Agar agent sekundiga 50 ta so'rov bersa, WAF server IP manzilni darhol bloklaydi. Harakatlar orasiga 300-800 ms tabiiy kechikish qo'shiladi.

3. Parollar va .env Himoyasi

Parollar promptda berilmaydi

Parollar hech qachon LLM promptiga yozilmaydi. Ular `.env` fayldan to'g'ridan-to'g'ri Playwright drayveriga kiritiladi.
