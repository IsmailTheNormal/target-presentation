TARMOQ ARXITEKTURASI

Long Polling vs Webhook: Farq nimada?

Foydalanuvchi xabar yozganini bizning server qanday biladi? Ikki xil fundamental aloqa usuli mavjud.

  • 01
    Long Polling (Doimiy so'rov) Server tinimsiz Telegram serveridan «Yangi xabar bormi?» deb so'raydi. Ortiqcha trafik, protsessor yuki va kechikish.
  • 02
    Webhook (Voqeaga asoslangan chaqiruv) Server tinch kutadi. Xabar kelishi bilan Telegram darhol bizning HTTPS URL manzilimizga HTTP POST so'rov jo'natadi!
// Webhook arxitekturasi:
[Telegram User] ──> (Xabar yozdi)
      │
      ▼
[Telegram Cloud Engine]
      │ HTTPS POST /webhook
      ▼
[Bizning Express Server] ──> [LLM API]
      │
      ▼ sendMessage(chatId, aiReply)
[Foydalanuvchi ekrani]

VS CODE DEV TUNNELS

Port Forwarding: Lokal port global HTTPS ga aylanadi

Microsoft kompaniyasi rasmiy SSL sertifikatiga ega ishonchli shifrlangan dev-tunnelni to'g'ridan-to'g'ri VS Code ichida taqdim etadi.

  • 01
    Ports panelini ochish Pastki terminal panelida `Ports` tugmasini bosing va `Forward a Port` ni tanlang.
  • 02
    3000-port va Public qilish `3000` deb yozing. O'ng tugma → `Port Visibility` → `Public` (aks holda Telegram kirishi taqiqlanadi!).

WEBHOOK SERVERNINI YOZISH

Express Webhook marshrutining anatomiyasi

Telegram har safar JSON ob'ekt yuboradi. Serverimizning birinchi vazifasi — darhol 200 OK qaytarish va xabarni o'qishdir.

const express = require('express');
const app = express();
app.use(express.json()); // JSON paketlarini o'qish uchun middleware

app.post('/webhook', async (req, res) => {
  // 1. Telegram serveriga zudlik bilan 200 OK qaytaramiz:
  res.sendStatus(200);

  const { message } = req.body;
  if (!message || !message.text) return;

  const chatId = message.chat.id;
  const userText = message.text;
  console.log(`Xabar keldi: ${userText}`);

  // 2. Javob qaytarish
  await sendTelegram(chatId, `Siz yozdingiz: ${userText}`);
});
WEBHOOKNI ULASH

Telegram'ni Dev Tunnel bilan qanday bog'laymiz?

Telegram xabarlarni qayerga jo'natishni bilishi shart. Buning uchun `setWebhook` buyrug'i brauzer orqali bir marta chaqiriladi.

  • GET
    Brauzer qidiruv qatoriga yoziladi: https://api.telegram.org/bot<TOKEN>/setWebhook?url=<TUNNEL_URL>/webhook
  • OK
    Muvaffaqiyatli Telegram javobi Telegram SSL sertifikatini tekshiradi va tasdiq javobini beradi.
// Muvaffaqiyatli javob:
{
  "ok": true,
  "result": true,
  "description": "Webhook was set"
}

// Tekshirish buyrug'i:
.../getWebhookInfo
SUN'IY INTELLEKT INTEGRATSIYASI

LLM aqli: Groq, DeepSeek va tizimli shaxsiyat

Oddiy echo-bot bitta Chat Completion so'rovi va to'g'ri berilgan System Prompt orqali intellektual yordamchiga aylanadi.

async function getAIReply(userPrompt) {
  const res = await fetch('https://api.groq.com/openai/v1/chat/completions', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${process.env.GROQ_API_KEY}`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      model: 'llama-3.3-70b-versatile',
      messages: [
        { role: 'system', content: 'Sen 10-sinf IT va kiberxavfsizlik repetitorisan. Qisqa va lo'nda javob ber.' },
        { role: 'user', content: userPrompt }
      ]
    })
  });
  const data = await res.json();
  return data.choices[0].message.content;
}
KIBER-TEST VA NOSOZLIKNI TOPISH

Nega Telegram bot javob bermayapti yoki 401 bermoqda?

Kodni va dev-tunnelni yoqdingiz, lekin telefonda bot javob bermayapti. Qaysi sabab eng ehtimolli?

🛠 Muhandislik tekshiruvi (Checklist):
1. VS Code Ports panelida port yonida qulf belgisi emas, yer shari (Public) turishi kerak.
2. Express marshrutida birinchi bo'lib res.sendStatus(200); yozilishi shart. Aks holda Telegram timeout bo'lib, botni vaqtincha bloklab qo'yadi.
3. Brauzerda https://api.telegram.org/bot<TOKEN>/getWebhookInfo ni ochib, last_error_message qatorini o'qing!
