Kiber-Missiya

ReAct metodologiyasi (Yao et al., 2022) asosida avtonom agentni loyihalash. Asboblarni JSON Schema formatida ta'riflash, Thought-Action-Observation zanjirini ulash va cheksiz sikllardan himoya qiluvchi Max Iterations qalqonini o'rnatish.

01 ReAct Anatomiyasi: Sikl fazasi va uning muhandislik vazifasini juftlang

ReAct Tsikli Fazalari

1. Thought — Ichki rejalashtirish

2. Action — Asbobni chaqirish

3. Observation — Muhit / API javobi

4. Final Answer — Yakuniy xulosa

Agent Xotirasidagi Hodisa

02 Zaiflik Tahlili: Action xatosida cheksiz sikl xavfi
while (!hasFinalAnswer && steps < MAX_STEPS) {
  const thought = await model.reason(messages);
  const action = parseToolCall(thought);
  const observation = await executeTool(action);
  messages.push({ role: "tool", content: observation }); // Muhim qator!
}
