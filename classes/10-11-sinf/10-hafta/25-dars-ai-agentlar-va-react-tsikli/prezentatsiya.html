Murakkab topshiriqni mustaqil tahlil qilib, kalkulyator va API-larni chaqirib yechuvchi shaxsiy AI agent prototipi.

UY VAZIFASI TAHLILI · BOTLAR ZAIFLIGI

1-Chorak Telegram Boti Tahlili va Agentik AIga Ko'prik

Xato Tahlili (Pitfall)

Passiv botlarda gallyutsinatsiya va asbobsizlik

Oddiy passiv bot faqat matn to'qiydi. 'Tesla kapitallashuvi + 18.5% necha pul?' deb so'ralsa, kalkulyatori yo'qligi uchun mutlaqo yolg'on son aytadi!

// ❌ Xato:
const answer = await llm.generate(prompt); // Gallyutsinatsiya!
Oltin Yechim (Best Practice)

ReAct Tsikli: Mulohaza va Asbob chaqiruvi

Agent avval o'ylaydi (Thought), tashqi API-ni chaqiradi (Action: Calculator), natijani oladi (Observation) va 100% to'g'ri javob beradi.

// ✅ To'g'ri:
Thought: Menga jonli narx kerak -> Action: search_api("Tesla")
Observation: $2.4B -> Action: calc(2.4 * 1.185) -> Final Answer!
30s Blits-Nazorat

ReAct siklining 3 asosiy bosqichini ayting? Javob: Thought (Fikrlash) $ ightarrow$ Action (Harakat) $ ightarrow$ Observation (Kuzatuv)!

Yangi Darsga Ko'prik

1-chorakda webhookli passiv Telegram bot yasagan edik. Endi 2-chorakda unga asboblar (Tools) berib, mustaqil ish bajaruvchi avtonom agentga aylantiramiz!

Oddiy prompt berganda model birinchi kelgan ehtimollik bo'yicha javob to'qishga tushadi (Greedy decoding). Natijada: gallyutsinatsiya va faktik yolg'onlar.

To'g'ridan-to'g'ri so'rov (Xavfli)

"X kompaniyasining kapitallashuvi + 18.5% necha pul?"

O'ylash $ ightarrow$ Qidirish $ ightarrow$ Hisoblash

ILMIY ETALON · PRINCETON / GOOGLE

ReAct Falsafasi: Mulohaza (Reasoning) va Harakat (Acting)

Shunyu Yao et al. (ICLR 2023): Inson muammoni qanday yechsa, sun'iy intellekt ham aynan shunday fikrlashi va harakat qilishi kerak.

1. Thought (Fikr)

Niyatni aniqlash

Model o'ziga reja tuzadi: "Menga foydalanuvchi buyurtmasini bajarish uchun avval bazadan narxni olish kerak".

2. Action (Amal)

Dasturiy asbobni chaqirish

Model standart JSON formatida buyruq beradi: qaysi asbobni qanday parametrlar bilan ishga tushirish kerak.

3. Observation (Kuzatuv)

Tashqi muhit natijasi

Dastur asbobni ishga tushiradi va natijani modelning xotirasiga qaytaradi. Model haqiqatni ko'radi!

INLINE SVG · REACT TSIKLI

ReAct Ijro Tsikli va Axborot Oqimi

Model 'Final Answer'ga erishmaguncha yoki maksimal qadamlar (Max Iterations) tugamaguncha tsikl to'xtovsiz aylanadi.

👆 Yuqoridagi tugmani yoki sxema bloklarini bosing: ReAct agent ijrosi jonli ko'rinadi!
TOOL CALLING STANDARTI

Asboblar Ta'rifi: JSON Schema Spetsifikatsiyasi

Model o'zidan o'zi qanday funksiyalar borligini bilmaydi. Unga tizimli ravishda JSON Schema orqali asboblar ro'yxati beriladi.

const tools = [
  {{
    name: "calculate_inflation",
    description: "Berilgan summa va inflyatsiya foizi bo'yicha yakuniy narxni hisoblaydi",
    parameters: {{
      type: "object",
      properties: {{
        base_amount: {{ type: "number", description: "Boshlang'ich summa" }},
        rate: {{ type: "number", description: "Inflyatsiya foizi (masalan 0.12)" }}
      }},
      required: ["base_amount", "rate"]
    }}
  }}
];
ARXITEKTURA MUHOFAZASI

Cheksiz Sikllar va Token Portlashi: Max Iterations Qalqoni

Agar tashqi API xato bersa, agent bir xil xato buyruqni qayta-qayta chaqirib, soniyada minglab dollarlik tokenlarni yoqib yuborishi mumkin.

Cheksiz Qaytalanish (Infinite Loop)

Agent tuzoqqa tushdi

Bir xil so'rov xato berishiga qaramay, 500 marta qaytariladi va API balansi tugaydi.

Maksimal Qadamlar Cheklovi

Qat'iy Limit va To'xtatish

Agar 5 ta urinishda masala yechilmasa, dastur to'xtatiladi va xavfsiz xabar qaytariladi.

BENCHMARK TAQQOSLASH

Prompt Muhandisligi Evolyutsiyasi: Direct vs CoT vs ReAct

Benchmark testlari (HotpotQA va ALFWorld) ReAct arxitekturasining so'zsiz ustunligini isbotlagan.

Direct Prompting

Faktik Aniqlik: 34%

Bir qadamli javob. Sanalar, narxlar va hisob-kitoblarda 60%+ xatolik.

Chain-of-Thought (CoT)

Faktik Aniqlik: 56%

Bosqichma-bosqich o'ylaydi, ammo tashqi ma'lumot ololmaydi. Eskirgan ma'lumotlar xatosi.

ReAct Paradigmasi

Faktik Aniqlik: 89%+

Fikrlar jonli API ma'lumotlari va kalkulyator hisoblari bilan 100% asoslanadi!

ENTERPRISE KIBERXAVFSIZLIK

Human-in-the-Loop va Sandbox: Ruxsatsiz Xakerlikni To'xtatish

Agar agentga 'Bash terminal' asbobi berilsa, prompt injection orqali xaker butun serverni o'chirib tashlashi mumkin.

1. Izolyatsiyalangan Sandbox

Konteyner ichida ishlash

Agent kodi asosiy serverda emas, balki alohida yopiq virtual konteynerda bajariladi.

2. Inson Tasdig'i (HITL)

Muhim amallarda ruxsat so'rash

Pul yechish, bazani tozalash yoki xat yuborishdan oldin dasturchi 'Tasdiqlash' tugmasini bosishi shart.

3. Birlamchi O'qish Rejimi

Least Privilege tamoyili

Agentga boshida faqat ma'lumot o'qish huquqi beriladi, o'zgartirish esa taqiqlanadi.

KIBER-TEST · AGENT DEBUGGING

Viktorina: ReAct Tsiklidagi Qaysi Xatolik Tizimni Qulatadi?

Quyidagi logni ko'ring: model bir xil harakatni takrorlamoqda. Buning sababi nima?

Thought 1: Kursni bilishim kerak -> Action: get_rate("USZ")
Observation: Error: Invalid Currency Code "USZ"
Thought 2: Kursni bilishim kerak -> Action: get_rate("USZ")
Observation: Error: Invalid Currency Code "USZ"
... (50 marta takrorlandi)
A) API server buzilgan va javob bermayapti
B) Observation xatosi model tarixiga qo'shilmayapti yoki MAX_STEPS cheklovi yo'q
C) Model eskirgan JSON Schema ishlatmoqda
D) Darhol Final Answer chaqirilishi kerak edi
To'g'ri javob: B!

Agar dasturchi Observation xatosini modelning xabarlar tarixiga (messages) qo'shishni unutsa, model o'tgan safar xato qilganini eslay olmaydi va bir xil xatoni cheksiz takrorlayveradi. Shuningdek, MAX_ITERATIONS qalqoni qo'yilmagan!
