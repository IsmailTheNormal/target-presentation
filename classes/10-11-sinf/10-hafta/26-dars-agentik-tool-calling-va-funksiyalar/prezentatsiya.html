ASBOBLAR TAVSIFI · JSON SCHEMA STANDARTI

Model Asbobni Qayerdan Biladi: JSON Schema

Model vositani to'g'ri tanlashi uchun unga aniq JSON Schema beriladi: nomi, maqsadi (description o'ta muhim!), parametrlari va turlari.

Kanonik Tool Sxemasi

{
  "name": "get_stock_price",
  "description": "Berilgan aksiya belgisi (ticker) bo'yicha jonli narxni oladi",
  "parameters": {
    "type": "object",
    "properties": {
      "ticker": { "type": "string", "description": "AAPL, TSLA, MSFT" }
    },
    "required": ["ticker"]
  }
}

Sxema Bo'yicha Oltin Qoidalar

  • Description — model aynan qachon bu asbobni ishlatishini tushuntiradi.
  • required — argument tashlab ketilmasligini kafolatlaydi.
  • type — noto'g'ri formatdagi ma'lumotlarni bloklaydi.
MA'LUMOTLAR HAVFSIZLIGI · ARGUMENTLAR VALIDATSIYASI

Argumentlarni Tekshirish: Hech Qachon Xom JSONga Ishonmang!

Model ba'zan raqam o'rniga so'z yozishi yoki kutilmagan null berishi mumkin. Server qulab tushmasligi uchun Zod yoki Pydantic bilan tekshiramiz.

Validatsiya Qatlami

function executeTool(name, rawArgs) {
  // 1. JSON parse xavfsizligi
  const args = JSON.parse(rawArgs);

  // 2. Majburiy parametrlar tekshiruvi
  if (!args.ticker || typeof args.ticker !== 'string') {
    throw new Error("Invalid parameter: ticker is required string!");
  }
  
  return fetchTickerPrice(args.ticker.toUpperCase());
}

Xato Chiqsa Nima Qilish Kerak?

Serverni o'chirib qo'ymang! Xatolik matnini Observation orqali modelga qaytaring. Model xatosini tushunib, 2-urinishda to'g'rilab yuboradi!

KIBER-TEST · BILIMNI TEKSHIRISH

Kiber-Sinov: JSON Schemadagi Kritik Xatoni Toping!

Dasturchi `get_weather` asbobini yozdi, lekin model ba'zan shahar nomini bermasdan xato chiqaryapti. Sxemada nima tushib qolgan?

A) Asbob nomi kichik harflar bilan yozilgan
B) Majburiy maydonlar massivi `required: ['city']` yozilmagan
C) JSON o'rniga C++ ishlatish kerak edi
To'g'ri javob: B!

Agar `required` ko'rsatilmasa, model parametrni ixtiyoriy deb o'ylaydi va uni yubormaydi. Natijada server `undefined` xatosini oladi!
