Dushmanlar, Ochko va Leaderboard: Dvigateldan O'yingacha

O'tgan darsda siz dvigatel qurdingiz: tsikl, delta time, fizika, to'qnashuv. Lekin dvigatel — bu hali o'yin emas. O'yin bo'lishi uchun maqsad, xavf va natija kerak. Bugun biz ochko tizimini, dushman to'lqinlarini va sinf reyting jadvalini quramiz — hamda nega ochkoga ishonib bo'lmasligini bilib olamiz.

Dvigatel ≠ o'yin

Harakatlanadigan kvadrat — bu hali o'yin emas

1 · MAQSAD

O'yinchi nima uchun harakat qiladi? Ochko yig'ish, omon qolish, rekord o'rnatish. Maqsadsiz o'yin — bu ekran saqlagich.

2 · XAVF

Yutqazish mumkin bo'lishi shart. Yutqazib bo'lmaydigan o'yinda g'alabaning qiymati yo'q. Xavf — bu ochkoning narxi.

3 · NATIJA

O'yin tugagach raqam qolishi kerak — va uni boshqalar bilan solishtirish mumkin bo'lsin. Mana shuning uchun leaderboard bor.

Bugungi darsning tuzilishi

Uchala element bugun quriladi: ochko (maqsad), dushman to'lqinlari (xavf) va reyting jadvali (natija). Dars oxirida sinfda bitta umumiy jadval bo'ladi va siz undagi o'rningizni ko'rasiz.

Teskari aloqa halqasi

Ochko — bu mukofot emas, bu xabar

Ochko o'yinchiga nima deydi

  • "To'g'ri qilding" — ochko o'sganda o'yinchi qaysi harakat foydali ekanini tushunadi.
  • "Xavf arziydi" — qiyinroq dushman ko'proq ochko bersa, o'yinchi xavfni tanlaydi. Bu qiziqarli qaror.
  • "Yaxshiroq bo'lyapsan" — o'z rekordini urish — eng kuchli motivatsiya.

Kombo: oddiy, lekin kuchli

// Ketma-ket urish kombo beradi
kombo = kombo + 1;
ochko = ochko + 10 * kombo;

// Xato qilsa — kombo nolga tushadi
if (jarohat) kombo = 0;

// 5 ta ketma-ket: 10+20+30+40+50 = 150
// 5 ta uzilib:    10+10+10+10+10 = 50

Nega kombo o'yinni o'zgartiradi

Kombosiz o'yinchi ehtiyotkor o'ynaydi. Kombo bilan u tavakkal qiladi — chunki uzilish og'riqli. Bitta qator kod o'yinchining butun xulq-atvorini o'zgartiradi. Mana bu — dizayn.

Qiyinlikni oshirishning 3 yo'li

  • Ko'proq dushman — eng oddiy, lekin tez zeriktiradi.
  • Tezroq dushman — yaxshiroq, reaksiyani sinaydi.
  • Boshqacha dushman — eng yaxshi: yangi xulq, yangi strategiya kerak bo'ladi.
  • Eng yomon usul: dushmanga ko'p jon berish. Bu qiyin emas, bu uzoq va zerikarli.

🎮 Stendda

Stendda har 15 soniyada yangi to'lqin boshlanadi: dushman tezligi oshadi va oraliq qisqaradi. Yuqorida joriy to'lqin raqami ko'rsatiladi. Necha to'lqingacha yetganingizni varaqaga yozing.

O'yin holat mashinasi

O'yinda uchta ekran bor — va ular chalkashmasligi kerak

MENU

Ism kiritiladi, boshlash tugmasi. O'yin tsikli ishlaydi, lekin update qahramonni qimirlatmaydi.

PLAYING

Asosiy holat: fizika, dushmanlar, ochko, to'lqinlar. Klaviatura qahramonni boshqaradi.

GAME OVER

Yakuniy ochko ko'rsatiladi, rekord saqlanadi, leaderboard yangilanadi. Space — qaytadan.

Nega bu muhim

function update(dt){
  if (holat === 'MENU')      return;          // hech narsa qilmaydi
  if (holat === 'GAMEOVER')  return;
  // faqat shu yerdan pastda o'yin mantig'i
  qahramonniYangila(dt);
  dushmanlarniYangila(dt);
}

// Holatni tekshirmasangiz: GAME OVER ekranida
// dushmanlar harakatda qoladi va ochko o'sishda davom etadi.
Ma'lumotni saqlash tili

JSON — obyektni matnga, matnni obyektga

Ikkita funksiya — hammasi shu

var natija = { ism:'Aziz', ochko:1240, tolqin:7 };

// Obyekt -> matn (saqlash uchun)
var matn = JSON.stringify(natija);
// '{"ism":"Aziz","ochko":1240,"tolqin":7}'

// Matn -> obyekt (o'qish uchun)
var qayta = JSON.parse(matn);
qayta.ochko + 10;   // 1250 — bu yana son!

Nega matnga aylantirish kerak

  • localStorage faqat matn saqlaydi — obyektni to'g'ridan-to'g'ri qo'ysangiz [object Object] chiqadi.
  • Tarmoq bo'ylab ham faqat matn uzatiladi. Server JSON qabul qiladi.
  • JSON — barcha tillar tushunadigan format: Python, Java, PHP, Swift.

⚠️ Eng ko'p uchraydigan xato

// ❌ parse ni unutish
var reyting = localStorage.getItem('top');
reyting.push(yangi);   // XATO: bu matn, massiv emas!

// ✅ To'g'ri
var reyting = JSON.parse(localStorage.getItem('top') || '[]');
reyting.push(yangi);
localStorage.setItem('top', JSON.stringify(reyting));
Massiv, sort, top-10

Reyting jadvali — uchta amaldan iborat

Uchta amal

// 1. Qo'shish
reyting.push({ ism:ism, ochko:ochko, sana:Date.now() });

// 2. Saralash — kattadan kichikka
reyting.sort(function(a, b){
  return b.ochko - a.ochko;
});

// 3. Faqat top-10 ni qoldirish
reyting = reyting.slice(0, 10);

sort() ni tushunish

  • sort ga taqqoslash funksiyasi beriladi: u ikkita elementni oladi va son qaytaradi.
  • b.ochko - a.ochko → kamayish (katta birinchi). a.ochko - b.ochko → o'sish.
  • ⚠️ Funksiyasiz sort() sonlarni matn sifatida saralaydi: [100, 9, 80] → [100, 80, 9]. Klassik tuzoq!
Darsning eng muhim g'oyasi

Mijoz tomonidan kelgan ochkoga hech qachon ishonmang

Buzish qanchalik oson

// Brauzerda F12 -> Console va bitta qator:
localStorage.setItem('top',
  JSON.stringify([{ism:'Men', ochko:999999}]));

// Yoki to'g'ridan-to'g'ri o'zgaruvchiga:
ochko = 999999;

// Tamom. Rekord "o'rnatildi".

Nega bunday

  • Brauzerdagi butun kod o'yinchi kompyuterida ishlaydi — demak u kodni ham, xotirani ham o'zgartira oladi.
  • localStorage — bu himoya emas, bu shunchaki qulaylik. U parol bilan yopilmagan.
  • Shuning uchun jiddiy o'yinlarda ochko serverda hisoblanadi.

Real o'yinlar buni qanday hal qiladi

  • Server hisoblaydi. Mijoz faqat harakatlarni yuboradi, ochkoni server o'zi chiqaradi. Eng ishonchli, lekin qimmat.
  • Takrorlash yozuvi (replay). O'yin barcha tugma bosishlarini saqlaydi, server o'yinni qayta o'ynab tekshiradi.
  • Mantiqiy tekshiruv. "30 soniyada 999999 ochko olish mumkin emas" — shubhali natija rad etiladi.
