Canvas da Boss va Qahramon Jon Barlari (HP)

Proportsiya Formulasi

Jon kamaygan sari chiziq qisqarishi uchun:

`let hpPercent = boss.hp / boss.maxHp;`
`let currentWidth = totalBarWidth * hpPercent;`

100 dan 50 jon qolganda koeffitsiyent 0.5 bo'ladi — chiziq roppa-rosa yarmigacha qisqaradi!

Canvas da Chizish Kodi

// Fon ramkasi (qora/kulrang)
ctx.fillStyle = '#152642';

// Jon miqdori (yashil yoki qizil)
ctx.fillStyle = boss.hp < 30 ? '#ff2a5f' : '#00ff88';
ctx.fillRect(200, 16, 340 * (boss.hp / 100), 16);
Quvvatlantirgichlar

Power-uplar Tizimi: Qalqonlar va Qo'shimcha Jonlar

1. Kiber-Qalqon (Shield 🛡️)

Qahramon atrofida 5 soniyaga (300 kadr) nurli himoya gumbazini yoqadi.

Qalqon vaqtida dushman lazerlari qahramonga umuman zarar yetkaza olmaydi!

2. Jon Tiklash (❤️)

Yo'qotilgan 1 ta jonni qayta tiklaydi (maksimal 3 tagacha):

`player.hp = Math.min(player.maxHp, player.hp + 1);`

Qiyin vaziyatda o'yinni qutqarib qoladi!

Muvozanat Sirlari

I-Frames Sirlari: Nega Zarbadan So'ng 1 Soniya Daxlsizlik Kerak?

1 Kadrda O'lib Qolish Muammosi

O'yin sekundiga 60 kadr tezlikda ishlaydi. Agar lazer qahramonga 0.1 soniya tegib tursa — ketma-ket 6 marta zarar beradi!

Barcha 3 ta jon ko'z ochib yumguncha tugab qoladi va o'yinchi nima bo'lganini ham tushunmaydi!

Yechim: I-Frames (Miltillash)

Zarba olgach, qahramonga 60 kadr (1 soniya) daxlsizlik beriladi:

1. `player.iFrames = 60;`.
2. Qahramon ekranda miltillaydi.
3. Bu vaqt ichida boshqa lazerlar zarar bermaydi va o'yinchi qochib ulguradi!

Xotira Gigienasi

FPS Tushib Ketmasligi Uchun Lazerlarni `splice` Qilish

Tozalanmasa Nima Bo'ladi?

Har sekundda 2 ta lazer paydo bo'ladi. 2 daqiqadan so'ng massivda 250 dan ortiq ko'rinmas ob'yektlar yig'ilib qoladi.

Brauzer ekrandan chiqib ketgan narsalarni ham hisoblab charchaydi va o'yin qotishni boshlaydi!

Orqadan Tozalash Usuli

for (let i = bossLasers.length - 1; i >= 0; i--) {
  let l = bossLasers[i];
  l.y += l.vy;
  // Ekrandan chiqib ketdimi? O'chiramiz!
  if (l.y > canvas.height) {
    bossLasers.splice(i, 1);
  }
}

Fayllarsiz Sof Ovoz: Web Audio API Sintezi

Nega Tashqi .mp3 Fayl Kerak Emas?

1. Tashqi mp3 fayllar internet sekin bo'lsa yuklanmay qolishi mumkin.
2. Web Audio API tovushlarni to'g'ridan-to'g'ri matematik chastotalardan (Gerts) sintez qiladi:
• Sakrash: baland mayin to'lqin (580 Gts).
• Lazer: o'tkir arracha to'lqin (sawtooth).
• Portlash: past bas (140 Gts).

Tovush Generator Kodingiz

function beep(freq, dur, type = 'sine') {
  const osc = audioCtx.createOscillator();
  const gain = audioCtx.createGain();
  osc.type = type;
  osc.frequency.setValueAtTime(freq, audioCtx.currentTime);
  osc.connect(gain);
  gain.connect(audioCtx.destination);
  osc.start(); osc.stop(audioCtx.currentTime + dur);
}
