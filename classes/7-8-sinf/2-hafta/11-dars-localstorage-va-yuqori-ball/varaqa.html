1. Asosiy Xotira Metodlari (3 ball)
Amal JavaScript Sintaksisi Nima saqlanadi?
Rekordni saqlash localStorage.setItem('', 500); Key: 'best' -> Value: '500'
Rekordni o'qib olish const best = localStorage.getItem(''); '500' matnini (yoki null) qaytaradi
Yozuvni o'chirish localStorage.('best'); Kalit xotiradan butkul o'chiriladi
2. JSON Orqali Ob'yektlarni Saqlash (3 ball)
Matnga Aylantirish (Ob'yekt -> Matn):

const pilot = { name: "Alex", score: 950 };
const str = JSON.(pilot);
localStorage.setItem('user', str);

Ob'yektni Qayta Tiklash (Matn -> Ob'yekt):

const raw = localStorage.getItem('user');
const obj = JSON.(raw);
console.log(obj.score); // 950

Yangi rekordni tekshirish kodini to'ldiring:

if (currentScore savedBest) {
