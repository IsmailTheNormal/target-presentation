O'yin Polirovkasi

Tugallangan O'yin Belgilari: Menyular, Retry va Mute

1. Boshlang'ich Ekran

"START" ekrani. Safari va Chrome brauzerlarida audio autoplay blokirovkasini hal qiladi.

2. Audio Mute Toggle

Ovozni yoqish/o'chirish tugmasi. Jamoat joyida o'ynayotgan o'yinchilar uchun zaruriy qulaylik.

3. Game Over & Retry

Natijalar xulosasi, yangi rekord va sahifani qayta yuklamasdan davom etish ("RETRY").

Doimiy Rekord

LocalStorage: Brauzer Yopilganda Ham Rekord O'chmaydi

O'yin boshlanganda rekordni o'qish:
let highScore = 0; try { // String matnni raqamga o'giramiz: highScore = parseInt( localStorage.getItem('cyber_high') || '0', 10 ); } catch(e){}
Yangi rekord o'rnatilganda saqlash:
if (score > highScore) { highScore = score; // Brauzer doimiy xotirasiga yozamiz: localStorage.setItem( 'cyber_high', String(highScore) ); }
Veb-Deploy Qoidalari

Deploy Sirlari: Nega Bosh Fayl Qat'iy index.html Bo'lishi Shart?

Xalqaro Veb-Server Standarti:

Brauzer saytga kirganda, server ildiz papkadan avtomatik index.html ni qidiradi. Agar faylni game.html deb atasangiz, server 404 Not Found xatosini ko'rsatadi!

O'yinlar uchun bepul bulutli platformalar:
  • Vercel: Tezkor avto-deploy, dunyo bo'ylab CDN kesh.
  • GitHub Pages: Repozitoriy sozlamalaridan bitta klik bilan yoqiladi.
  • Netlify: Loyiha papkasini sudrab tashlash (Drag-and-Drop) orqali deploy.
