Chastota O'zgarishi

Lazer O'qi Tovushi: Chastotaning Eksponensial Pasayishi

"Pew-Pew" tovushi mexanikasi:

Lazer shunchaki bitta notadagi ovoz emas. Bu chastotaning 900 Hz dan (yuqori xushtak) 100 Hz gacha (pastki bas) atigi 0.12 soniyada keskin tushib ketishidir!

// 1. Boshlang'ich baland nota: osc.frequency.setValueAtTime(900, ctx.currentTime); // 2. Eksponensial pastga qulash: osc.frequency.exponentialRampToValueAtTime( 100, ctx.currentTime + 0.12 );
⚠️ 0 Hz Matematik tuzog'i:

Hech qachon `exponentialRamp` parametriga 0 Hz bermang! Eksponensial funksiya matematik jihatdan 0 ga yeta olmaydi (xatolik beradi). Har doim kamida 1 Hz yoki 10 Hz ko'rsating!

Partikllar Tizimi

Partikllar Tizimi (Particle Emitter) Nima?

1. Emitter (Manba)

Portlash yoki lazer dushmanga tekkan fazoviy koordinata `(x, y)`.

2. Radial Tarqalish

30 ta zarracha yaratiladi. Har biri $0 \dots 2\pi$ burchak ostida tasodifiy yo'nalish oladi.

3. Hayot va O'lim (TTL)

Har bir partikl 0.5 soniya yashaydi, sekin shaffoflashib (alpha) yo'qoladi.

Partikllar Matematikasi

Har Bir Partiklning Trigonometriyasi va Gravitatsiyasi

Har tomonga sochilish formulalari:
const angle = Math.random() * Math.PI * 2; const speed = Math.random() * 4 + 2; const p = { x: originX, y: originY, vx: Math.cos(angle) * speed, vy: Math.sin(angle) * speed, life: 1.0, // 100% ko'rinadi decay: 0.02 // Har freymda so'nadi };
O'yin tsiklida yangilanish (Game Loop):
p.x += p.vx; p.y += p.vy; p.vy += gravity; // Pastga tortadi! p.life -= p.decay; // Chizishda shaffoflik: ctx.globalAlpha = Math.max(0, p.life); ctx.arc(p.x, p.y, p.size, 0, Math.PI * 2); ctx.fill();
Xotira Gigiyenasi

Nega `splice` bo'lmasa o'yin 2 daqiqada qotadi?

🚨 Xotira toshishi fojiasi:

Har bir portlash 30 ta obyekt yaratadi. 1 daqiqada 5000+ partikl to'planadi! Agar o'lgan partikllar (`life <= 0`) massivdan o'chirilmasa, protsessor ko'rinmas nuqtalarni hisoblab holdan toyadi. FPS 60 dan 10 ga tushib ketadi!

✅ Xavfsiz teskari tozalash tsikli:
// Orqadan oldinga yuramiz (indeks xatosiz!): for (let i = particles.length - 1; i >= 0; i--) { if (particles[i].life <= 0) { particles.splice(i, 1); // Xotiradan tozalash! } }
