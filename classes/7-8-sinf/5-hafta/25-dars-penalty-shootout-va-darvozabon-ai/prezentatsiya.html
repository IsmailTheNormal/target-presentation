Chiziqli Interpolyatsiya: LERP Formulasi

To'pning 11 metrlik nuqtadan darvozaga silliq uchib borishi uchun LERP (Linear Interpolation) formulasi qo'llaniladi. Shu bilan birga to'p o'lchami masshtabi kichrayib, 3D chuqurlik effekti hosil bo'ladi.

// Chiziqli interpolyatsiya formulasi: t = 0 dan 1 gacha function lerp(start, end, t) { return start + (end - start) * t; } // Har bir kadrda koordinata va 3D masshtab hisoblanadi: const currentX = lerp(spotX, targetX, progress); const currentY = lerp(spotY, targetY, progress); const ballScale = lerp(1.0, 0.45, progress); // Uzoqlashish illyuziyasi

// 9 ta zona bo'yicha zarbalar tarixi massivi: const shotHistory = [0, 0, 0, 0, 0, 0, 0, 0, 0]; // Laplas ehtimollik formulasi: function calculateProbability(zoneIndex) { const totalShots = shotHistory.reduce((a, b) => a + b, 0); // Har bir zonaga +1 qo'shiladi, umumiy maxrajga +9: return (shotHistory[zoneIndex] + 1) / (totalShots + 9); }
