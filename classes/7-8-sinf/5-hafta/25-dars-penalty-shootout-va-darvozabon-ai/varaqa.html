2. Chiziqli Interpolyatsiya: LERP va 3D Masshtab 2 ball

To'pning 11 metrlik nuqtadan to'r tomon uzoqlashishi va 3D chuqurlik hosil qilishi uchun LERP formulasi ishlatiladi:

function lerp(start, end, t) { return start + (end - start) * t; }
// t = 0.0 (tepish vaqti) dan t = 1.0 (to'rga yetib borish) gacha
Parvoz vaqti (t) Masshtab formulasi (scale) Hosil bo'lgan o'lcham Vizual natija
t = 0.0 (Boshlanish) lerp(1.0, 0.45, 0.0) 1.00 (100%) To'p nuqtada, o'quvchiga yaqin va yirik
t = 0.5 (Parvoz yarmi) lerp(1.0, 0.45, 0.5) 0.72 (72%) To'p havoda, o'rtacha masofada
t = 1.0 (Darvoza to'ri) lerp(1.0, 0.45, 1.0) 0.45 (45%) To'p darvoza to'rida, uzoqda va ixcham
