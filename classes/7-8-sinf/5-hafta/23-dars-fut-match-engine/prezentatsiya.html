Ehtimoliylik Matematikasi

Vaznli Tasodifiylik: Nega Har Bir Zarba Gol Bo'lavermaydi?

🎲 Tasodifiy Son (0 dan 1 gacha)

Kompyuter 0.00 dan 0.99 gacha tasodifiy son beradi. 25% ehtimollikdagi hujum uchun shart:

const roll = Math.random(); if (roll < 0.25) { // 25% ehtimol bilan xavfli hujum! }

⚖️ OVR va Kimyo Ustunligi Bonusi

Kuchliroq jamoa matematik bonus oladi. Agar sizning OVR 90, raqibniki 80 bo'lsa, omad eshigi kengayadi!

const advantage = (myOvr - oppOvr) * 0.02; // roll < (0.50 + advantage) if (roll < 0.70) { // To'p bizda qoladi! }

Expected Goals (xG): Qanday Qilib Xavfli Vaziyatlar O'lchanadi?

🎯 xG Nima (0.00 dan 0.99 gacha)?

Zarbaning gol bilan yakunlanish ehtimolligi. Penalti xG = 0.79 (79% gol), 35 metrdan zarba esa xG = 0.02 (2%).

// Jarima maydonchasi ichidan zarba: const chanceXg = 0.15 + Math.random() * 0.45; stats.xgHome += chanceXg;

📊 xG vs Haqiqiy Hisob

Jamoa xG = 3.20 to'plab, raqib posbonining qahramonligi tufayli 0:1 yutqazishi mumkin. Ammo uzoq masofada xG yuqori jamoa doim chempion bo'ladi!
