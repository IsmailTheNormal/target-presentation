BOZOR MATEMATIKASI • TALAB VA TAKLIF

Dastur Kodida Talab va Taklif Qonuni

Bozor narxi formulasi sotuvdagi kartalar soni (Taklif) va sotib olmoqchilar soni (Talab) nisbatiga tayanadi:

// Narx o'zgarishi algoritmi (Dynamic Price Shift) let priceMultiplier = 1.0 + (demand - supply) / Math.max(supply, 1); let newMarketPrice = Math.round(basePrice * priceMultiplier); // Agar talab 500, taklif 50 bo'lsa -> narx keskin qimmatlaydi (+900%)! // Agar yangi paketlar ochilib, taklif 1000 ga yetsa -> narx arzonlashadi (-50%).
🟢 Yuqori Talab (Weekend League):

Juma oqshomi: hamma turnir uchun eng kuchli tarkib yig'adi. Talab taklifdan ortib ketadi → Elita kartalar narxi 15-20% ga qimmatlaydi.

🔴 Ortiqcha Taklif (Pack Crash):

Yangi promo-paketlar ochildi: minglab o'yinchilar kartalarini bozorga ommaviy chiqaradi → Bozor to'lib ketadi, narxlar tushadi.

SAVDO ALGORITMI • AUCTION ENGINE

Lot Anatomiyasi: Start Bid, Joriy Stavka va Buy Now

Har bir bozor e'loni ikkita xarid yo'liga ega bo'lgan dasturiy obyektdir: auksion savdolashuvi yoki bir zumda xarid.

1. Start Bid

Sotuvchi belgilagan boshlang'ich minimal stavka (masalan, 10,000 tanga).

2. Step Bid (+1,000)

Yangi stavka joriy biddan kamida qat'iy qadamga yuqori bo'lishi shart.

3. Buy Now

Auksion vaqtini bekor qilib, kartani bir soniyada sotib oladigan narx.

BOTLARDAN HIMOYA • ANTI-SNIPING TAYMER

Oxirgi Soniyada O'g'irlashdan Qanday Himoyalanadi?

Agar vaqt 00:01 ga yetganda bot millisekundda stavka qilsa, odam ulgurmaydi. Shuning uchun taymerni avtomatik uzaytirish algoritmi ishlaydi:

function handleBid(card, newBid, user) { if (user.coins < newBid) return { error: "Mablag' yetarli emas" }; card.currentBid = newBid; card.highestBidder = user.id; // Anti-Sniping himoyasi: agar 20 soniyadan kam qolgan bo'lsa +30 soniya qo'shiladi! if (card.timeLeft < 20) { card.timeLeft += 30; notifyAllBidders("Vaqt uzaytirildi! Yangi stavka qabul qilindi."); } }
💡 Adolatli Raqobat Kafolati:

Vaqtning uzaytirilishi odamga o'ylab, javob stavkasini qilish imkonini beradi va botlarning poygasini adolatli kurashga aylantiradi.

3. Bir Zumda Buy Now

MOLIYAVIY HISOBLASH • TRADE PROFIT

Treyderning Sof Foydasi Formulari

5% soliq tufayli zarar ko'rib qolmaslik uchun har bir bitimning foyda nuqtasini oldindan hisoblash lozim:

// Sof foyda formulasi (Net Trade Profit): let grossSalePrice = 100000; let eaTax = Math.round(grossSalePrice * 0.05); // -5,000 tanga let netPayout = grossSalePrice - eaTax; // 95,000 tanga let boughtPrice = 80000; let profit = netPayout - boughtPrice; // +15,000 SOF FOYDA! // Nuqtai nazar: Sotish narxi xarid narxidan kamida 1.053 barobar yuqori bo'lishi shart!
📊 Amaliy Misol:

Siz Saliba kartasini 40,000 tangaga olib, 42,000 ga sotdingiz. Foyda qildingizmi? Yo'q! 42,000 − 5% = 39,900. Siz 100 tanga zarar qildingiz! Doimo soliqni hisobga oling.
