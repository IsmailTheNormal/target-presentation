Dinamik Formalar

HTML5 Elementlari: Text, Select va Range Slayderlar

1. Matn va Emojilar

O'yinchi ismi va davlat bayrog'i (Emoji). Maxlength orqali kartochka kengligidan chiqib ketmaslik ta'minlanadi.

<input type="text" id="inpName" maxlength="16">

2. Tanlov (Dropdown)

Pozitsiyani belgilash: ST, LW, RW, CAM, CM, CB, GK. Tanlov OVR hisoblash formulasini o'zgartiradi!

<select id="inpPos"> <option value="ST">ST</option> <option value="CB">CB</option> </select>

3. Range Slayderlar

Sichqoncha bilan 40 dan 99 gacha surish imkoniyati. Har bir siljish oniy hodisa (input event) qo'zg'atadi.

<input type="range" min="40" max="99" id="rngPac">
FileReader Texnologiyasi

Serverga Yubormasdan Brauzerda Rasm O'qish Siri

❌ Eski va og'ir yo'l (Serverga yuklash):
  • Faylni internet orqali serverga yuborish (HTTP POST).
  • Serverda saqlab, yangi URL manzilini kutish.
  • Internet sekin bo'lsa yoki server o'chsa dastur ishlamaydi.
⚡ Zamonaviy FileReader API (0 ms, Mahalliy):
  • Brauzer to'g'ridan-to'g'ri foydalanuvchi kompyuteridan rasmni xotiraga o'qiydi.
  • Rasmni Base64 Data URL formatiga aylantirib, <img> manziliga qo'yadi.
  • Internet shart emas — 100% oflayn va chaqmoqdek tez ishlaydi!
Kod Tahlili

FileReader JavaScript Mexanizmi

const fileInput = document.getElementById('fileInput'); const cardPhoto = document.getElementById('cardPhotoImg'); fileInput.addEventListener('change', (e) => { const file = e.target.files[0]; if (!file) return; // 1. Yangi FileReader obyektini yaratamiz const reader = new FileReader(); // 2. O'qish tugagach nima qilishni aytamiz reader.onload = (event) => { cardPhoto.src = event.target.result; // Data URL! }; // 3. Faylni Data URL ko'rinishida o'qishni boshlaymiz reader.readAsDataURL(file); });

Algoritmning 3 ta Qadami:

  • 1. Obyekt yaratish: new FileReader() brauzer xotirasida yangi o'qish oqimini ochadi.
  • 2. Hodisa eshituvchi: onload xuddi eshik qo'ng'irog'i kabi fayl to'liq o'qib bo'lingan soniyada chaqiriladi.
  • 3. Data URL kodi: Rasm data:image/png;base64,... matnli kodga aylanib to'g'ridan-to'g'ri src ga birikadi.

Reyting Matematikasi

Vaznli O'rtacha: OVR Reytingini Hisoblash Formulasi

🎯 ST (Hujumchi) Formulasi

Hujumchi uchun zarba (SHO) va tezlik (PAC) 57% vaznga ega, himoya esa deyarli ta'sir qilmaydi!

OVR = round( PAC * 0.22 + SHO * 0.35 + PAS * 0.10 + DRI * 0.20 + DEF * 0.03 + PHY * 0.10 );

🛡️ CB (Himoyachi) Formulasi

Himoyachi uchun DEF (45%) va PHY (25%) hal qiluvchi kuch — zarbasi past bo'lsa ham OVR 90+ bo'la oladi!

OVR = round( PAC * 0.15 + SHO * 0.02 + PAS * 0.08 + DRI * 0.05 + DEF * 0.45 + PHY * 0.25 );

📐 Matematik qoida: barcha koeffitsiyentlar yig'indisi har doim roppa-rosa 1.00 (100%) bo'lishi shart!

Vizual Estetika

Oltin Gradient, Soya va Shimmer Teksturasi

1. Oltin Gradient

Kartochka foni qorong'i oltin ranglardan tashkil topgan ko'p qatlamli burchakli gradient bilan boyitiladi.

background: linear-gradient( 145deg, #1C1504 0%, #3B2A06 35%, #181203 100% );

2. Drop Shadow

O'yinchi fotosurati tagiga chuqur soya berilib, rasm kartochka ichidan bo'rtib chiqib turganday ko'rinadi.

filter: drop-shadow( 0 8px 16px rgba(0,0,0,0.7) );

3. OVR Tipografikasi

Manrope 900 qalin shrifti, -1px harflar orasi va oltin matn nuri yordamida haybatli ko'rinish.

font-family: "Manrope"; font-size: 42px; font-weight: 900; color: #FFE58F;
