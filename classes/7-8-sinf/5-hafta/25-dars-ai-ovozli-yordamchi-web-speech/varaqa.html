2. Mikrofon Hodisalari Tsikli (Event Lifecycle) 2 ball

Ovozni tanish jarayoni hodisalar (events) orqali boshqariladi. Hodisalarning ishlash tartibini tushuntiring:

const rec = new webkitSpeechRecognition();
rec.onstart = () => { updateStatus("listening"); };
rec.onresult = (e) => { const text = e.results[0][0].transcript; process(text); };
rec.onend = () => { updateStatus("ready"); };
