Ma'lumotlar Modeli

O'yinchi Obyekti Tuzilmasi: Kimyo Hisoblash uchun Atributlar

📦 O'yinchi JavaScript Obyektida

Kimyo zanjirini hisoblash uchun 4 ta asosiy atribut shart: pos, club, league va nation.

const mbappe = { id: "mbappe", name: "K. Mbappé", pos: "ST", altPos: ["LW"], ovr: 91, club: "Real Madrid", league: "La Liga", nation: "France" };

🏟️ Tarkib Xaritasi (Squad Dictionary)

Har bir taktik slotga (GK, CB1, ST) o'yinchi obyekti biriktiriladi (agar bo'sh bo'lsa null bo'ladi).

const currentSquad = { "st": mbappe, "lw": vinicius, "rw": rodrygo, "cam": bellingham, "cb1": rudiger };
Taktik Maydon Koordinatalari

Taktik Sxemalar: 4-3-3, 4-4-2 va Foizli Koordinatalar (%)

⚡ 4-3-3 (Attack)

Klassik hujumkor sxema: 1 darvozabon, 4 himoyachi (LB, 2 CB, RB), 3 yarimhimoyachi (2 CM, CAM) va hujum uchligi (LW, ST, RW).

⚖️ 4-4-2 (Balanced)

Inglizcha muvozanatli klassika: 4 himoyachi, 4 yarimhimoyachi qatorda (LM, 2 CM, RM) va ikki markaziy hujumchi (ST1, ST2).

📐 Foizli Joylashtirish

Slotlar CSS foizlarida joylashadi: left: X%; top: Y%. Natijada maydon har qanday ekranda proporsional qoladi!

// Slot koordinatasi maydonning foizlarida aniqlanadi: { id: 'st', pos: 'ST', x: 82, y: 50 }, // Hujumchi markazda oldinda { id: 'gk', pos: 'GK', x: 8, y: 50 } // Darvozabon o'z darvozasida
Graf Nazariyasi

Futbol Maydoni Graf Sifatida: Tugunlar (Nodes) va Bog'lanishlar (Links)

🟢 Tugunlar (Nodes)

Maydondagi har bir pozitsiya — bu grafning alohida tuguni (jami 11 ta). Tugun o'yinchi obyekti ma'lumotini saqlaydi.

slots: [ { id: 'gk' }, { id: 'cb1' }, { id: 'cb2' }, { id: 'cm1' }, { id: 'st' } ... ]

🔗 Qovurg'alar / Chiziqlar (Links)

Pozitsiyalar orasidagi taktik bog'liqlik. Masalan, darvozabon faqat CB1 va CB2 bilan, hujumchi esa CAM, LW va RW bilan bog'langan!

links: [ ['gk', 'cb1'], ['gk', 'cb2'], ['cb1', 'cb2'], ['cam', 'st'], ['lw', 'st'], ['rw', 'st'] ]

// Mbappé ST slotida joylashdi slot.pos === player.pos // true → Kimyo hisoblanadi!

Agar hujumchini markaziy himoyaga qo'yib qo'ysangiz: uning shaxsiy kimyosi 0/3 bo'ladi va qizil xatolik belgisi chiqadi!
