4 Tomonlama Qo'shnilar

Har bir (x, y) katakdan bot 4 tomonga 1 qadam tashlashi mumkin:

  • Yuqoriga: (x, y - 1)
  • O'ngga: (x + 1, y)
  • Pastga: (x, y + 1)
  • Chapga: (x - 1, y)

Chegaradan chiqib ketmaslik sharti: x >= 0 && x < cols && y >= 0 && y < rows.

BFS QIDIRUV MEXANIZMI

Kenglik Bo'yicha Qidiruv (BFS): To'lqinsimon Tarqalish

1. FIFO Navbati

queue.push() va shift()

Boshlang'ich katak navbatga qo'yiladi. Biz birinchi elementni olib, uning barcha qo'shnilarini tekshiramiz.

2. Visited To'plami

visited Set() to'plami

Tekshirilgan har bir katak `visited` ga yoziladi. Bu dushmanning bir joyda doira bo'ylab aylanib qolishini oldini oladi.

3. Parent Xaritasi

parent[qo'shni] = joriy

Har bir qo'shniga kimdan kelinganini yozib boramiz. Shu orqali o'yinchigacha bo'lgan yo'l tiklanadi.

YO'LNI ORQAGA TIKLASH

Backtracking: Dushman Birinchi Qadamni Qayoqqa Qo'yishi Kerak?

Orqaga Tiklash Mantig'i

To'lqin o'yinchiga yetganda, biz `parent` zanjiri bo'yicha o'yinchidan dushmanga qarab orqaga qaytamiz va massivni `path.reverse()` qilib aylantiramiz!

JS Tiklash Kodi
function reconstructPath(parent, startKey, targetKey) {
  const path = [];
  let curr = targetKey;
  while (curr && curr !== startKey) {
    path.push(curr);
    curr = parent[curr];
  }
  return path.reverse(); // [keyingi_katak, ..., o'yinchi]
}
XULQ-ATVOR MASHINASI

Dushman Holat Mashinasi: Patrul ➔ Ta'qib ➔ Hujum

1. PATROL (Patrul)

Sokin aylanib yurish

O'yinchi uzoqda bo'lsa (masofa > 8 katak), dushman protsessorni qiynamasdan, faqat belgilangan 2 ta nuqta orasida aylanib yuradi.

2. CHASE (Ta'qib)

O'yinchi ko'rish maydonida!

Masofa < 8 katak! Qizil trevoga yoqiladi, BFS chaqirilib dushman eng qisqa yo'l bilan o'yinchini aylanib quva boshlaydi.

3. ATTACK (Hujum)

Zarba berish masofasi

Masofa < 1.5 katak! Bot to'xtaydi va o'yinchiga zarba beradi yoki Math.atan2 burchagi bo'yicha lazerdan o't ochadi.
