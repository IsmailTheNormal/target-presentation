HTML5 DRAG AND DROP · HODISALAR ZANJIRI

Drag & Drop Anatomiyasi: 3 Ta Asosiy Hodisa

1. ondragstart

Buyumni Ko'tarish

Sichqoncha bilan buyumni ushlaganda ishlaydi. dataTransfer xotirasiga buyum ID-sini yozamiz:

e.dataTransfer.setData( "text/plain", item.id );
2. ondragover

Tashlashga Ruxsat

Brauzer odatda tashlashni taqiqlaydi! Tashlashga ruxsat berish uchun preventDefault() shart:

slot.ondragover = (e) => { e.preventDefault(); // Ruxsat! };
3. ondrop

Slotga Tushish

Maqsadli slotda ishlaydi. ID-ni o'qib olib, slot turi to'g'ri kelsa, buyumni kiygizadi:

const id = e.dataTransfer .getData("text/plain"); equipItem(id, slotType);
SLOT VALIDATSIYASI · TURLAR MOSLIGI

Qoidalar Nazorati: Qilichni Boshga Kiyib Bo'lmaydi!

Turlar Mosligi Qoidasi

Agar o'yinchi Qilichni ('weapon') Bosh kiyim slotiga ('head') tashlamoqchi bo'lsa, tizim buni rad etishi va slotni qizil rangda ogohlantirishi kerak:

function canEquip(item, targetSlotType) { // Agar xalta sloti bo'lsa - istalgan buyum tushadi if (targetSlotType === "backpack") return true; // Agar tanadagi slot bo'lsa - turlar 100% mos bo'lishi shart! return item.type === targetSlotType; }

Avtomatik O'rin Almashish (Swap)

Agar qo'lda eski boltacha turgan bo'lsa va uning ustiga yangi qilich qo'yilsa — bolta yo'qolmaydi, balki xaltaning bo'shagan katagiga qaytariladi (Swap mexanizmi)!
