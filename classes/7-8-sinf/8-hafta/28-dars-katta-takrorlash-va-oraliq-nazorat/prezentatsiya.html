Prompt Injiniringi va SVG Vektor Grafikasi

2-MODUL · SEMANTIK HTML VA CSS FLEXBOX

Semantik HTML va CSS Flexbox Maketi

  • Semantik HTML: <main> — sahifaning yagona bosh mazmuni; <canvas> — 2D grafika chizish paneli; <section> — mustaqil tematik blok.
  • Flexbox bilan markazlashtirish: Elementni konteyner markaziga qo'yishning eng toza usuli — display: flex; justify-content: center; align-items: center;.
  • O'qlar farqi: justify-content gorizontal (asosiy o'q), align-items esa vertikal (kesishuvchi o'q) bo'yicha boshqaradi.
/* O'yin kartochkasini markazga joylash */ .game-arena { display: flex; justify-content: center; /* Gorizontal markaz */ align-items: center; /* Vertikal markaz */ gap: 16px; }

4-MODUL · LOCALSTORAGE VA DEVTOOLS KONSOLI

Doimiy Xotira (LocalStorage) va DevTools

  • LocalStorage nima: Foydalanuvchi kompyuterida kalit-qiymat ko'rinishida saqlanuvchi doimiy xotira. Sahifa yangilansa yoki brauzer yopilsa ham o'chmaydi.
  • Metodlar: localStorage.setItem('highScore', 1500) — yozish; localStorage.getItem('highScore') — o'qib olish.
  • DevTools Konsoli: Qizil xabarlar — jiddiy xatolik (Error); sariq — ogohlantirish (Warning). console.log() esa holatni tekshirish vositasi.
// Yangi rekordni tekshirish va saqlash const savedScore = localStorage.getItem('highScore') || 0; if (currentScore > savedScore) { localStorage.setItem('highScore', currentScore); console.log("Yangi rekord o'rnatildi!"); }
5-MODUL · HTML5 CANVAS VA 60 FPS O'YIN TSIKLI

Canvas 2D va requestAnimationFrame Tsikli

  • HTML5 Canvas: JavaScript orqali bevosita piksellarni chizish paneli. Chizish vositasi: const ctx = canvas.getContext('2d');.
  • Game Loop (O'yin tsikli): Har bir kadrda 3 ta ketma-ket qadam bajariladi: 1. ctx.clearRect() (tozalash) → 2. Harakat hisobi → 3. Chizish.
  • Nega setInterval emas? requestAnimationFrame monitorning kadr yangilanishiga (60 Hz / 60 FPS) moslashadi va o'yinni muzlatmasdan silliq qiladi.

6-MODUL · O'YIN FIZIKASI VA TO'QNASHUVLAR (COLLISION)

Gravitatsiya va AABB To'qnashuv Algoritmi

  • Gravitatsiya simulyatsiyasi: Har kadrda vertikal tezlikka og'irlik kuchi qo'shiladi: player.vy += gravity; so'ngra player.y += player.vy;.
  • Sakrash mexanikasi: Tugma bosilganda qahramonga yuqoriga qaragan manfiy impuls beriladi: player.vy = -jumpForce;.
  • AABB (Axis-Aligned Bounding Box): Ikki to'g'ri to'rtburchakning X va Y o'qlarida bir vaqtning o'zida kesishishi to'qnashuv (zarar yoki tanga olish) ekanini bildiradi.
// AABB To'qnashuvni tekshirish funksiyasi function checkCollision(a, b) { return ( a.x < b.x + b.w && a.x + a.w > b.x && a.y < b.y + b.h && a.y + a.h > b.y ); }

10-MODUL · KIBER-KO'Z VA BIOMETRIK FACE ID

Harakat Detektori va Liveness Anti-Spoofing

  • Frame Differencing: Veb-kameradan olingan ketma-ket ikki kadr piksellari bir-biridan ayiriladi (|Kadr1 - Kadr2| > threshold). O'zgargan hudud harakat sifatida aniqlanadi.
  • 68 Yuz Tayanch Nuqtalari: Ko'zlar, qoshlar, burun va iyak konturlari matematik vektorlarga aylantiriladi. IPD (ko'zlararo masofa) doimiy o'zgarmas biometrik kalit bo'lib xizmat qiladi.
  • Liveness Anti-Spoofing: Xakerlar telefon ekranida fotosurat tutganda, tizim EAR (Eye Aspect Ratio) orqali tirik odamning ko'z miltillashini tekshiradi va soxta hujumni rad etadi.
// EAR Ko'z nisbati formulasi function calcEAR(eyePoints) { const dVert1 = dist(eyePoints[1], eyePoints[5]); const dVert2 = dist(eyePoints[2], eyePoints[4]); const dHoriz = dist(eyePoints[0], eyePoints[3]); return (dVert1 + dVert2) / (2.0 * dHoriz); }
