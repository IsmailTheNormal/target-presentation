01 Flexbox Maketini Markazlashtirish va Tuzatish

O'yin kartochkalari va boshqaruv blokini ekranning qoq o'rtasiga tekis joylashtirish (gorizontal va vertikal markazlashtirish) uchun .arena selektoriga qaysi Flexbox xossalarini yozish kerak?

.arena { /* Ushbu joyga Flexbox markazlashtirish qoidalarini yozing */ min-height: 100vh; gap: 20px; }
RASMIY YECHIM (2.5 ball):
display: flex; — konteynerni elastik Flex konteynerga aylantiradi.
justify-content: center; — elementlarni asosiy o'q (gorizontal) bo'yicha markazga joylaydi.
align-items: center; — elementlarni ko'ndalang o'q (vertikal) bo'yicha o'rtaga keltiradi.
To'liq qoida: .arena { display: flex; justify-content: center; align-items: center; min-height: 100vh; gap: 20px; }
02 addEventListener va LocalStorage Rekordini Saqlash

#saveBtn tugmasi bosilganda (click hodisasi), o'yin ochkosi score qiymatini brauzerning doimiy xotirasiga 'highScore' kaliti bilan saqlovchi JavaScript kodini yozing:

const saveBtn = document.getElementById('saveBtn'); let score = 250; // addEventListener va localStorage.setItem kodini yozing:
RASMIY YECHIM (2.5 ball):
saveBtn.addEventListener('click', function() {
  localStorage.setItem('highScore', score);
  console.log('Rekord saqlandi:', score);
});
Izoh: addEventListener('click', fn) foydalanuvchi bosishini ushlaydi, localStorage.setItem(kalit, qiymat) esa sahifa yangilansa ham ma'lumotni saqlab qoladi.
03 Canvas 60 FPS Game Loop va AABB To'qnashuv

Canvas o'yin tsiklida: 1) Nega yangi kadr chizishdan oldin ctx.clearRect(0, 0, w, h) chaqirilishi shart? 2) 60 FPS chastota bilan silliq ishlash uchun qaysi brauzer funksiyasi chaqiriladi? 3) Ikki to'g'ri to'rtburchak to'qnashganini (AABB) tekshiruvchi formulani yozing:

function gameLoop() { // 1. Ekranni tozalash // 2. Yangilanish (60 FPS) // 3. AABB to'qnashuv: r1 va r2 }
RASMIY YECHIM (2.5 ball):
1) ctx.clearRect(0, 0, w, h) eski kadr qoldiqlarini tozalaydi, aks holda harakatlanayotgan qahramon orqasidan qora iz (smear) cho'zilib ketadi.
2) requestAnimationFrame(gameLoop) monitor chastotasiga (60 FPS) moslashadi va batareyani tejaydi.
3) AABB to'qnashuv sharti:
r1.x < r2.x + r2.w && r1.x + r1.w > r2.x && r1.y < r2.y + r2.h && r1.y + r1.h > r2.y
04 FUT Kimyo Graflari va Liveness EAR Formulasi

1) FUT Squad Builder loyihasida qo'shni o'yinchilarning bir xil klub yoki ligada o'ynashi jamoa kimyosiga (Chemistry) qanday ta'sir qiladi? 2) Biometrik yuz skanerida EAR (Eye Aspect Ratio) formulasi qanday qilib tirik odamni telefondagi 2D fotosuratdan ajratadi?

RASMIY YECHIM (2.5 ball):
1) FUT kimyosi: O'yinchilar umumiy klub, millat yoki ligaga ega bo'lsa, ularni bog'lovchi graf qovurg'asi yashil bo'ladi va o'yinchiga +1, +2 yoki +3 ballik maksimal kimyo beradi (11 o'yinchiga jami maksimal 33 ball).
2) Liveness EAR: EAR = (dVert1 + dVert2) / (2.0 * dHoriz). Tirik inson tabiiy ravishda har 2–4 soniyada ko'z qisadi (EAR ko'rsatkichi 0.30 dan 0.15 ga tushib yana ko'tariladi). Fotosurat esa statik bo'lib, EAR qiymati mutlaqo o'zgarmaydi. Agar EAR o'zgarmasa, tizim 2D soxtalikni (Spoofing) aniqlab, qizil signal beradi.
