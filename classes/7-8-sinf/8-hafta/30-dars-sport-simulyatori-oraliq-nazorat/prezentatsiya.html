O'YINCHI STATISTIKASI

Karta statistikasi: OVR qanday hisoblanadi?

Umumiy reyting (OVR) — shunchaki sonlar yig'indisi emas. Hujumchi, yarim himoyachi va himoyachi uchun parametrlar vazni turlicha baholanadi. 

// Hujumchi (Striker / ST) uchun vaznli OVR formulasi:
function calculateStrikerOVR(stats) {
  const weights = { pac: 0.25, sho: 0.35, pas: 0.10, dri: 0.20, def: 0.05, phy: 0.05 };
  const ovr = (stats.pac * weights.pac) + (stats.sho * weights.sho) +
              (stats.pas * weights.pas) + (stats.dri * weights.dri) +
              (stats.def * weights.def) + (stats.phy * weights.phy);
  return Math.round(ovr);
}
  • PAC Tezlik (Pace): Himoyachilardan qochish va bo'sh hududga yorib kirish tezligi.
  • SHO Zarba (Shooting): Darvoza burchagiga aniq tepish va gol ehtimolligi koeffitsienti.

MATCH ENGINE VA FSM

FSM: Kompyuter 90 daqiqalik matchni qanday o'ynaydi?

Finite State Machine matchni bir nechta holatlarga bo'ladi: to'pga egalik qilish, qarshi hujum, yakkama-yakka duel va darvozaga zarba. 

// Yakkama-yakka duel ehtimolligi formulasi:
function resolveDuel(attackerDRI, defenderDEF) {
  const totalPower = attackerDRI + defenderDEF;
  const winProbability = attackerDRI / totalPower; // 0.0 dan 1.0 gacha
  const diceRoll = Math.random(); // Tasodifiy son
  return diceRoll < winProbability ? "DRIBBLE_SUCCESS" : "BALL_TACKLED";
}
  • 01 Matematika va Tasodif: Kuchli o'yinchi ko'proq yutadi, biroq kutilmagan gollar uchun doim imkoniyat qoladi.
  • 02 xG modeli: Darvoza yaqinidan zarbaning gol bo'lish ehtimoli 75%, 30 metrlik uzoq zarbaniki esa atigi 4%.

VIRTUAL BOZOR VA VALYUTA

Bozor qonuni: Nega EA Sports 5% soliq joriy qilgan?

Agar o'yinda tangalar faqat g'alaba uchun tarqatilsa, giperinflyatsiya yuzaga keladi. Narxlar keskin oshib ketmasligi uchun tangalarni yo'qotuvchi (Coin Sink) mexanizm zarur. 

// 5% Savdo solig'i va sotuvchi oladigan toza foyda:
function calculateTransferPayout(soldPrice) {
  const TAX_RATE = 0.05; // 5% EA Solig'i
  const taxAmount = Math.round(soldPrice * TAX_RATE);
  const sellerReceives = soldPrice - taxAmount;
  return { taxAmount, sellerReceives };
}
// Misol: 100,000 tangaga sotilgan o'yinchi ➔ 5,000 tanga o'yindan o'chiriladi!
