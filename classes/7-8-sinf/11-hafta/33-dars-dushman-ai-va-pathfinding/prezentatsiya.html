BFS: KENGAYTIRILGAN QIDIRUV

BFS: To'lqinsimon Qidiruv va Eng Qisqa Yo'l

BFS xuddi suvga tosh otgandek har tomonga bir tekis to'lqin bo'lib tarqaladi:

  • Navbat (Queue): Birinchi kirgan birinchi chiqadi (FIFO).
  • Visited to'plami: Bir xil katakka qayta kirmaslik kafolati.
  • Kafolat: Har doim eng qisqa qadamlar sonini topadi!
  • Kamchiligi: Keraksiz tomonga ham ko'r-ko'rona tarqaladi.
// BFS ning asosiy sikli
const queue = [startNode];
const visited = new Set();
while (queue.length > 0) {
const current = queue.shift();
if (current == target) break; // Topildi!
for (const neighbor of getWalkableNeighbors(current)) {
if (!visited.has(neighbor)) {
visited.add(neighbor);
queue.push(neighbor);
}
}
}
A* (A-STAR) EVRISTIKASI

A* Algoritmi: Aqlli Qidiruv va f = g + h

BFS ko'r-ko'rona qidirsa, A* maqsad qaysi tomondaligini bilib, faqat to'g'ri tomonga intiladi:

f(n) = g(n) + h(n)
g(n): Boshlang'ich nuqtadan yurilgan qadamlar soni
h(n): Qahramongacha qolgan taxminiy masofa (Heuristic)
f(n): Umumiy baho (eng kichik f(n) birinchi tekshiriladi)

Manhattan Masofasi Formulasi

function manhattan(a, b) {
  return Math.abs(a.x - b.x) + Math.abs(a.y - b.y);
}

Nyu-York ko'chalaridek: binolarni teshib o'tib bo'lmaydi, faqat to'g'ri burchakli bloklar bo'ylab hisoblanadi.

⚡ Natija: A* butun xaritani emas, faqat maqsad tomon kataklarni tekshiradi va 5-10 barobar tezroq ishlaydi!
