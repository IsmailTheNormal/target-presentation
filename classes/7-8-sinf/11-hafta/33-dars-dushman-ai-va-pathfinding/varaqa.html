01 Aqlli Dushmanning 4 Ta Asosiy Qoidasi

Dars Missiyasi: Roguelike labirintida tosh devorlarni aylanib o'tib, qahramonni quvuvchi aqlli dushman AI tizimini yaratish: devorga qotib qolmaslik, ko'rish chirog'i va 3 xil kayfiyat (Patrul, Shubhali tovush, Quturgan ta'qib).

Aqlli Dushmanning 4 Ta Asosiy Qoidasi:
1. Maydon Kataklari: Ekran bo'sh pol (yurish mumkin) va tosh devorlar (to'siq) to'plamiga bo'linadi.
2. Suv Oqimi Usuli: Dushman oldida tosh bo'lsa to'xtamaydi, balki yon tomondagi bo'sh katak orqali aylanib o'tadi.
3. Ko'rish Chirog'i: Chiroq rangi: ko'k (sokin patrul), sariq (shubhali shovqin), qizil (quturgan ta'qib).
4. Hujum va Xavf: Dushman yetib olganda o'yinchidan -1 Jon kamayadi va signal yangraydi.
02 To'siqlarni Aylanib O'tish Mantig'i (Suv Oqimi)

To'siqlarni aylanib o'tish tekshiruvi mantig'i:

// Agar oldinda tosh devor bo'lsa, 4 ta qo'shni katakni tekshiramiz
const dirs = [[0,-1], [0,1], [-1,0], [1,0]]; // Yuqori, Past, Chap, O'ng
let bestTile = null, minDistance = 9999;
for (const [dx, dy] of dirs) {
  const nextX = enemy.col + dx, nextY = enemy.row + dy;
  if (grid[nextY][nextX] === 0) { // Bo'sh pol!
    const dist = Math.abs(hero.col - nextX) + Math.abs(hero.row - nextY);
    if (dist < minDistance) { minDistance = dist; bestTile = {x: nextX, y: nextY}; }
  }
}
if (bestTile) { enemy.col = bestTile.x; enemy.row = bestTile.y; }
