OTISHMA ARXITEKTURASI

Sichqoncha Kursoridan O'qqacha: 4 Bosqich

O'yinlarda o'q tasodifan uchmaydi. Bu kursor koordinatalarini aniq harakat vektoriga aylantiruvchi matematik zanjirdir.

  • 1. Nishonni aniqlash: Sichqoncha yoki barmoq bosilgan nuqta (targetX, targetY).
  • 2. Masofa farqi: dx = targetX - heroX va dy = targetY - heroY hisoblanadi.
  • 3. Burchakni topish: angle = Math.atan2(dy, dx) orqali burchak topiladi.
  • 4. Tezlik vektorlari: vx = Math.cos(angle) * spd va vy = Math.sin(angle) * spd.

MATH.ATAN2 SEHRI

Nega Oddiy atan Emas, Aynan Math.atan2(dy, dx)?

Oddiy atan(dy/dx) da dx=0 bo'lsa nolga bo'lish xatosi chiqadi va burchak adashadi. Math.atan2 esa barcha 360 darajani aniq hisoblaydi.

  • Barcha 4 chorak: Burchakni -PI dan +PI gacha (-180° dan +180° gacha) aniq beradi.
  • Argumentlar tartibi: Avval Y, keyin X beriladi: Math.atan2(dy, dx).
  • Nolga bo'linmaydi: dx=0 bo'lsa, xatosiz 90 daraja (PI/2) qiymatini qaytaradi.
[Burchakni Hisoblash Kodi]
function getAimAngle(hero, target) {
  const dx = target.x - hero.x;
  const dy = target.y - hero.y;
  
  // Radiandagi burchak (-3.14 .. +3.14)
  const angle = Math.atan2(dy, dx);
  return angle;
}
TEZLIK VEKTORLARI

Uchish Traektoriyasi: Math.cos va Math.sin

O'q qaysi tomonga otilmasin, uning umumiy tezligi doim bir xil (masalan: 10 px/kadr) bo'lishi shart!

  • Gorizontal tezlik: vx = Math.cos(angle) * speed
  • Vertikal tezlik: vy = Math.sin(angle) * speed
  • Pifagor qoidasi: vx² + vy² = speed² (Tezlik o'zgarmas saqlanadi).
[O'q Yaratish Funksiyasi]
function shootBullet(hero, target) {
  const angle = Math.atan2(target.y - hero.y, target.x - hero.x);
  const speed = 12; // px per frame
  
  bullets.push({
    x: hero.x,
    y: hero.y,
    vx: Math.cos(angle) * speed,
    vy: Math.sin(angle) * speed,
    life: 60 // 60 kadr umr
  });
}
XOTIRANI TOZALASH

Xotira Oqishi (Memory Leak): O'qlarni O'chirish Shart!

Agar o'yinchi 500 marta o'q uzsa va ekrandan chiqib ketgan o'qlar massivdan o'chirilmasa, o'yin qotib qoladi (Memory Leak).

  • Orqadan aylanish: O'chirishda massiv indekslari surilmasligi uchun teskari sikl ishlatiladi.
  • Devorga urilish: Agar o'q tosh devorga tegsa, zudlik bilan o'chiriladi.
  • Ekranni tark etish: Ko'rinish chegarasidan chiqsa massivdan chiqariladi.
[Xavfsiz O'chirish Sikli]
for (let i = bullets.length - 1; i >= 0; i--) {
  const b = bullets[i];
  b.x += b.vx;
  b.y += b.vy;
  b.life--;

  // Devor to'qnashuvi yoki vaqt tugashi
  if (b.life <= 0 || isWall(b.x, b.y)) {
    createSparks(b.x, b.y); // Uchqunlar
    bullets.splice(i, 1);   // Xotiradan tozalash
  }
}
