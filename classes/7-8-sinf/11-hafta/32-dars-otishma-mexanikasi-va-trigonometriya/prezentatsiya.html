UY VAZIFASI TAHLILI VA KO'PRIK

O'tgan Dars Xatolari va Bugungi Yangi Mavzuga Ko'prik

Keng Tarqalgan Xato: atan2 Argumentlari Adashishi

Ko'pchilik Math.atan2(dx, dy) deb yozadi! Doimo birinchi dy (vertikal), keyin dx (gorizontal) kelishi shart: Math.atan2(dy, dx).

Oltin Yechim Standarti

const dx = targetX - hero.x;
const dy = targetY - hero.y;
const angle = Math.atan2(dy, dx); // To'g'ri burchak (rad)

30 Soniyalik Blitz Savol

Kursor qahramonning to'g'ri o'ng tomonida (dy = 0, dx > 0). Burchak necha radian bo'ladi?

Javob: Aynan 0 radian! cos(0)=1, sin(0)=0 (to'g'ri o'ngga uchadi).

Bugungi Yangi Mavzuga Ko'prik

Labirintimiz bor, endi qahramonimizga qurol kerak! Bugun Vibecoding orqali nishonga olish va otishma fizikasini quramiz.

OTISHMA ARXITEKTURASI

Kursor Koordinatalari va Qahramon Nigohi

O'yin qayerga nishonga olinganini qanday biladi? 2D Canvas maydonidagi ikki nuqta birlashtiriladi:

  • 1-Nuqta (Qahramon): Qahramon markazi (hero.x, hero.y).
  • 2-Nuqta (Kursor): Sichqoncha yoki barmoq tekkan koordinata.
  • Delta (Farq): dx = targetX - hero.x, dy = targetY - hero.y.
// Kursor burchagini olish
window.addEventListener('mousemove', (e) => {
const rect = canvas.getBoundingClientRect();
const mouseX = e.clientX - rect.left;
const mouseY = e.clientY - rect.top;
const dx = mouseX - hero.x;
const dy = mouseY - hero.y;
hero.angle = Math.atan2(dy, dx);
});
TRIGONOMETRIYA VA RADIANLAR

Math.atan2 Sehri: 360 Darajali Doiraviy Radianlar

Oddiy atan(y/x) nolga bo'lish xatosiga uchraydi. Math.atan2(dy, dx) esa barcha 4 chorakni to'liq qamrab oladi:

  • Diapazon: -PI (-3.14) dan +PI (+3.14) gacha radianlar.
  • 0 rad: To'g'ri o'ngga qarash (sharq).
  • PI/2 rad: To'g'ri pastga qarash (Canvas da Y pastga qarab o'sadi).
  • -PI/2 rad: To'g'ri yuqoriga qarash (shimol).

TEZLIK VEKTORLARI (COS VA SIN)

O'qni Uchirish: cos va sin Orqali Tezlik Vektorlari

O'q istalgan burchakda bir xil doimiy tezlikda uchishi uchun tezlik ikki vektorga bo'linadi:

// O'q obyektini yaratish
const speed = 12; // Piksel/freym
const vx = Math.cos(angle) * speed;
const vy = Math.sin(angle) * speed;
bullets.push({ x: hero.x, y: hero.y, vx, vy });

Nega Oddiy x += speed Ishlamaydi?

Trigonometriyalarsiz o'qlar faqat 4 tomonga ucha oladi va diagonallar 1.41 barobar tezroq bo'lib ketadi.

O'yin Tsiklida Harakat

Har bir freymda (60 FPS): bullet.x += bullet.vx; bullet.y += bullet.vy;

XOTIRA XAVFSIZLIGI VA TOZALASH

splice() Tuzog'i: Nega Teskari Sikl Ishlatiladi?

Katta Xato: Xotira Oqishi (Memory Leak)

Ekrandan chiqqan o'qlar o'chirib tashlanmasa, massiv minglab oshib ketadi va o'yin qotib qoladi!

To'g'ri Sikl Tuzog'i (Indeks Surilishi)

Oddiy 0 dan length gacha siklda bitta o'q o'chirilsa, keyingi o'q tekshirilmay o'tib ketadi!

// Oltin Yechim: Teskari Sikl (Reverse Loop)
for (let i = bullets.length - 1; i >= 0; i--) {
const b = bullets[i];
b.x += b.vx; b.y += b.vy;
// Agar ekrandan chiqsa yoki devorga urilsa:
if (isOutOfBounds(b) || checkWallHit(b)) {
createSparks(b.x, b.y);
bullets.splice(i, 1); // Xavfsiz o'chirish!
}
}
