1-USTUN: TOSH LABIRINT

1-Ustun: Qorong'u Labirint va Tosh Devorlar

O'yin maydoni 20x13 katakli shaxmat doskasiga o'xshaydi:

  • 🟩 Bo'sh pol: Qahramon strelkalar yoki WASD bilan erkin yuradi.
  • ⬛ Tosh devorlar: O'tib bo'lmaydigan qattiq to'siqlar.
  • Silliq sirg'anish: Devorga urilganda qotib qolmasdan yonlab sirg'aladi.
// To'siqlar tekshiruvi (Collision Check)
const nextX = hero.x + dx;
const nextY = hero.y + dy;
// Agar oldinda bo'sh pol bo'lsa, qadam bosamiz:
if (isWalkable(nextX, nextY)) {
  hero.x = nextX;
  hero.y = nextY;
}
2-USTUN: MASH'ALA NURI

2-Ustun: Qorong'ilik va Mash'ala Nuri

Nega butun ekran yorug' bo'lsa o'yin zerikarli? Chunki kutilmagan sirlar bo'lmaydi!

  • Radial yorug'lik: Qahramon atrofida 140px radiusli mash'ala yonadi.
  • Silliq chekkalar: Markazda yorug', chetida esa sirli qorong'ilik.
  • Kutilmagan kashfiyot: Quti yoki portalga yaqinlashmaguncha uni ko'rib bo'lmaydi!

Canvas Mash'ala Texnologiyasi:

1. Butun ekranni to'q qora rang bilan bo'yaymiz.
2. Qahramon turgan joyda createRadialGradient yaratamiz.
3. globalCompositeOperation = 'destination-out' bilan qorong'ulikni teshik ochib yoritamiz!

3-USTUN: KIBER-BLASTER

3-Ustun: Kiber-Blaster va Rangli Uchqunlar

O'yinchi kursor bilan nishonga oladi va sichqoncha bilan lazer otadi:

  • Uchqunlar portlashi: Devorga urilganda 6–8 ta yorqin zarracha sochiladi!
  • Qurol zarbasi: Otganda qahramonning biroz siljishi o'yinni yoqimli qiladi!
