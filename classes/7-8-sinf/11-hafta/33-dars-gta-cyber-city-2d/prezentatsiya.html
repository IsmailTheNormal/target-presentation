2-BOSQICH: SPORTKAR FIZIKASI

Avtomobil Fizikasi: Tezlanish, Rul va Asfaltda Drift

Avtomobil Harakat Tenglamasi

// W - gaz, S - tormoz / orqaga:
if (keys['KeyW']) car.speed += car.accel;
if (keys['KeyS']) car.speed -= car.brake;

// Rul faqat mashina yurganda buriladi:
if (Math.abs(car.speed) > 0.2) {
  if (keys['KeyA']) car.angle -= car.turnSpeed;
  if (keys['KeyD']) car.angle += car.turnSpeed;
}

// Ishqalanish (Inersiya):
car.speed *= 0.985;
car.x += Math.cos(car.angle) * car.speed;
car.y += Math.sin(car.angle) * car.speed;

Mashina yuqori tezlikda (speed > 4) keskin burilganda, g'ildiraklar sirpanadi. Orqa g'ildiraklar ostida asfaltdagi qora drift izlarini hosil qilamiz:

if (Math.abs(car.speed) > 4 && turning) {

3-BOSQICH: 'F' TUGMASI BILAN O'TIRISH

Holat Mashinasi: Piyoda ↔ Haydovchi Rejimi

Mashinaga Yaqinlikni Tekshirish

window.addEventListener('keydown', (e) => {
  if (e.code === 'KeyF') {
    if (!player.inCar) {
      // Mashinagacha masofa:
      const dist = Math.hypot(player.x - car.x, player.y - car.y);
      if (dist < 50) {
        player.inCar = true;
        playSFX('doorClose');
      }
    } else {
      // Mashinadan tushish:
      player.inCar = false;
      player.x = car.x + Math.sin(car.angle) * 30;
      player.y = car.y - Math.cos(car.angle) * 30;
      playSFX('doorOpen');
    }
  }
});
