CHEGARALAR VA CHEKKA HOLATLAR

Labirintning 3 Oltin Qoidasi: Chegara, Berk Ko'cha va Chiqish

1. Chegara Devori

Tashqariga Chiqmaslik

Konchi koordinatasi 1 <= x < cols - 1 bo'lishi shart. Eng chekka kataklar doim devor (1) bo'lib qoladi.

2. Dead-End Qopqonlari

Berk Ko'chalarga Sandiq

Agar biror katakning 3 tomoni devor bo'lsa, bu berk ko'cha! U yerga xazina sandig'i qo'yiladi.

3. Chiqish Eshigi

Eng Uzoq Chiqish

Chiqish portali (Exit) qazishning eng oxirgi nuqtasiga qo'yiladi. Bu o'yinchi uchun eng uzun sarguzashtni ta'minlaydi.

Xaritadagi Belgilar Standarti:
0 = Bo'sh Yo'l (Floor) · 1 = Tosh Devor (Wall) · P = O'yinchi (Player Spawn) · C = Oltin Sandiq (Chest) · E = Chiqish Portali (Exit)
GENERATOR FUNKSIYASI KODI

JavaScript-da generateDungeon() Generator Kodi

function generateDungeon(cols, rows, maxFloors) {
  // 1. To'liq devor bilan to'ldirish (1)
  const map = Array.from({ length: rows }, () => Array(cols).fill(1));

  let x = Math.floor(cols / 2);
  let y = Math.floor(rows / 2);
  map[y][x] = 0; // Spawn nuqtasi

  let carved = 1;
  const dirs = [
    { dx: 0, dy: -1 }, // Yuqori
    { dx: 0, dy: 1 },  // Past
    { dx: -1, dy: 0 }, // Chap
    { dx: 1, dy: 0 }   // O'ng
  ];

  while (carved < maxFloors) {
    const dir = dirs[Math.floor(Math.random() * dirs.length)];
    const nx = x + dir.dx;
    const ny = y + dir.dy;

    // Chegarani tekshirish (chekkada devor qolishi shart)
    if (nx > 0 && nx < cols - 1 && ny > 0 && ny < rows - 1) {
      x = nx;
      y = ny;
      if (map[y][x] === 1) {
        map[y][x] = 0;
        carved++;
      }
    }
  }
  return { map, exit: { x, y } };
}
