Xavfsiz va To'g'ri O(1) To'qnashuv

function isWall(worldX, worldY) {
  const col = Math.floor(worldX / TILE_SIZE);
  const row = Math.floor(worldY / TILE_SIZE);
  if (row < 0 || row >= ROWS || col < 0 || col >= COLS) return true;
  return map[row][col] === 1; // 1 = Devor
}

World Space (Dunyo) vs Screen Space (Ekran)

Professional o'yin dasturlashda ob'ektlar ikkita alohida koordinata tekisligida yashaydi:

Dunyodagi O'rni (World Space)

Qahramon Haqiqatda Qayerda?

  • Butun xaritaning chap yuqori burchagidan (0, 0) boshlanadi
  • Qahramon koordinatalari katta bo'lishi mumkin: (1850, 1420)
  • Fizika va to'qnashuvlar FAQAT World Spaceda tekshiriladi
Ekrandagi O'rni (Screen Space)

Monitor Ekranida Qayerda Chiziladi?

  • Brauzer oynasi (Canvas)ning chap burchagidan boshlanadi
  • Asosiy proyeksiya formulasi: ScreenX = WorldX - CameraX
  • Kamera butun dunyoni ctx.translate(-camX, -camY) bilan suradi

Canvas Oltin Qoidasi: Har bir devorning koordinatasini qayta hisoblab o'tirmaymiz! Bir marta ctx.translate(-camera.x, -camera.y) qilamiz, butun dunyoni oddiy koordinatalarda chizamiz va oxirida ctx.restore() qilamiz!

KAMERA MATEMATIKASI

Qahramonni Markazlashtirish va Chegara (Clamping)

1. Kamerani Markazlashtirish

Qahramon monitor markazida turishi uchun kameraning koordinatasi ekran kengligi va balandligining yarmiga orqada yurishi kerak:

// Qahramonni ekranning o'rtasiga qo'yish
camera.x = player.x - (VIEWPORT_WIDTH / 2);
camera.y = player.y - (VIEWPORT_HEIGHT / 2);

2. Bo'shliqqa Chiqmaslik (Clamping)

Agar chegaralanmasa, kamera xaritadan tashqaridagi qora bo'shliqni ko'rsatib qo'yadi! Uni 0 va dunyo chegaralari orasida qulflaymiz:

// Chegaralardan chiqib ketmaslik
const maxCamX = WORLD_WIDTH - VIEWPORT_WIDTH;
const maxCamY = WORLD_HEIGHT - VIEWPORT_HEIGHT;

camera.x = Math.max(0, Math.min(camera.x, maxCamX));
camera.y = Math.max(0, Math.min(camera.y, maxCamY));

SILLIQ HARAKAT

Kameraning Silliq Kuzatuvi: Lerp Formulasi

Qattiq bog'langan kamera har qadamda silkinib ko'zni toliqtiradi. Silliq kino effektini olish uchun Chiziqli Interpolyatsiya (Lerp) ishlatiladi:

Matematik Formula

Har bir kadrda (frame) kamera qahramonga qarab masofaning belgilangan foiziga siljiydi:

// Lerp: camera.x += (target - current) * speed
const targetX = player.x - VIEWPORT_WIDTH / 2;
const targetY = player.y - VIEWPORT_HEIGHT / 2;

// Silliq 10% yaqinlashish har kadrda
camera.x += (targetX - camera.x) * 0.1;
camera.y += (targetY - camera.y) * 0.1;

Tezlik Koeffitsiyenti (Speed)

  • speed = 1.0 ➔ Qattiq bog'lanish, darhol burilish
  • speed = 0.1 ➔ Eng zo'r muvozanat va muloyimlik
  • speed = 0.02 ➔ Og'ir kinokamera yoki dron effekti

💡 Pro Maslahat: Agar qahramon yugursa (Shift), kamerani biroz orqaroqqa tortib ko'rish burchagini kengaytirish mumkin!

MASH'ALA NURINI CHIZISH

Radial Gradient Bilan Mash'ala Nurini Yaratish

Radial Gradient Mantig'i

Gradient ikkita aylana orasida quriladi: ichki aylana (yorug' o'zak) va tashqi aylana (tuman chegarasi):

// Mash'ala nuri: Markazdan chetga xiralashish
const innerRadius = 25;
const outerRadius = 150;

const grad = ctx.createRadialGradient(
  playerScreenX, playerScreenY, innerRadius,
  playerScreenX, playerScreenY, outerRadius
);

grad.addColorStop(0, "rgba(0, 0, 0, 0)");   // Markaz: 100% shaffof
grad.addColorStop(0.7, "rgba(5, 8, 16, 0.4)"); // Yarim soya
grad.addColorStop(1, "rgba(5, 8, 16, 0.98)");  // Mutlaq qorong'ilik

Jonli Olov Effekti (Flicker)

Haqiqiy mash'ala hech qachon bir tekis turmaydi. Unga sinus to'lqini va tasodifiy miltillash qo'shamiz:

// Har kadrda mash'ala o'lchamini tebratish
const time = Date.now() * 0.005;
const flicker = Math.sin(time) * 6 + (Math.random() * 3);
const dynamicRadius = baseRadius + flicker;
Bu g'ordagi haqiqiy olovdek ajoyib kinematik atmosfera beradi!

XOTIRALI TUMAN

Xarita Xotirasi: Kashf Qilingan Joylarni Eslab Qolish

Kashfiyot Matritsasi

Xaritaga teng o'lchamli 2D mantiqiy (boolean) massiv yaratamiz. Qahramon mash'alasi tegishi bilan unga true yoziladi:

// Har bir xonaning kashf etilganligini saqlash
const explored = Array(ROWS).fill(null).map(() => Array(COLS).fill(false));

function updateExploration(playerX, playerY, radius) {
  // Mash'ala atrofidagi kataklarni true qilish
  const pCol = Math.floor(playerX / TILE);
  const pRow = Math.floor(playerY / TILE);
  // ... Atrofdagi radiusdagi kataklar:
  explored[r][c] = true;
}

Kashf Qilingan Joylarni Ko'rsatish

  • explored[r][c] === false ➔ Mutlaq qora kvadrat
  • explored === true, uzoqda ➔ 50% xiralikdagi ko'k/kulrang devor
  • Hozir mash'ala ostida ➔ 100% to'liq yorug'lik
