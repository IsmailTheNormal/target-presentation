Kamerani Markazlashtirish va Chegaralash (Clamping)

2D dvigatelda ekran oynasi (Viewport) o'lchami viewW x viewH, butun xarita esa worldW x worldH ga teng. updateCamera funksiyasini to'ldiring: kamera qahramon markaziga qaralsin va hech qachon xarita chegarasidan tashqariga chiqib ketmasin:

// Boshlang'ich kod andozasi: function updateCamera(player, camera, viewW, viewH, worldW, worldH) { // 1. Ekran markaziga hisoblash: let targetX = player.x - (viewW / 2); let targetY = player.y - (viewH / 2); // 2. Math.max va Math.min bilan clamping: // ... kodingizni yozing ... }

✅ Etalon Clamping Kodi

function updateCamera(player, camera, viewW, viewH, worldW, worldH) {
  let targetX = player.x - (viewW / 2);
  let targetY = player.y - (viewH / 2);
  camera.x = Math.max(0, Math.min(targetX, worldW - viewW));
  camera.y = Math.max(0, Math.min(targetY, worldH - viewH));
  return camera;
}

Mash'ala Nuri va destination-out Maskasi

Canvasda butun ekranni qora tuman pardasi bilan qoplab, destination-out orqali qahramon koordinatasi (px, py) atrofida yumshoq radial gradientli mash'ala nurini o'yuvchi funksiyani yozing:

function renderFog(ctx, viewW, viewH, px, py, radius) { ctx.save(); // 1. Qorong'ilik pardasi: // 2. destination-out kompozitsiyasi: // 3. createRadialGradient mash'ala teshigi: ctx.restore(); }

✅ Etalon Tuman O'yish Kodi

function renderFog(ctx, viewW, viewH, px, py, radius) {
  ctx.save();
  ctx.fillStyle = "rgba(5, 8, 16, 0.95)";
  ctx.fillRect(0, 0, viewW, viewH);

  ctx.globalCompositeOperation = "destination-out";
  let grad = ctx.createRadialGradient(px, py, 15, px, py, radius);
  grad.addColorStop(0, "rgba(0,0,0,1)");
  grad.addColorStop(0.7, "rgba(0,0,0,0.8)");
  grad.addColorStop(1, "rgba(0,0,0,0)");

  ctx.fillStyle = grad;
  ctx.beginPath();
  ctx.arc(px, py, radius, 0, Math.PI * 2);
  ctx.fill();
  ctx.restore();
}

Kiber-Chaqiruv: Xarita Xotirasi (explored[r][c])

Qahramon o'tgan koridorlar yana mutlaq qorong'ilikka aylanib qolmasdan, xira yarim tuman soyasida ko'rinib turishi uchun qanday ma'lumotlar tuzilmasi va render tsikli qo'llaniladi? Arxitekturani tushuntiring:

✅ Xarita Xotirasi Arxitekturasi

2D massiv yaratiladi: explored[row][col] = boolean. Tayl mash'ala nuriga tushishi bilan explored[row][col] = true qilinadi. Render jarayonida: agar explored == false bo'lsa -> qop-qora blok; agar explored == true lekin qahramon uzoqda bo'lsa -> yarim xira soya rgba(0,0,0,0.6); agar qahramon yonida bo'lsa -> 100% to'liq yorug'likda chiziladi.
