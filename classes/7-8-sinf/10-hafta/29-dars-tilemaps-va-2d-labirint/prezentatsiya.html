// ❌ Xato:

Oltin Yechim (Best Practice)

2D Matritsa va Panjara (Tilemap): O(1) Tezlik

Butun xarita 0 va 1 lardan iborat 2D massivga yoziladi. Devorga urilish bitta amal bilan `map[row][col] === 1` tekshiriladi ($O(1)$ tezlikda)!

// ✅ To'g'ri:
const map = [[1,1,1,1],[1,0,0,1],[1,1,1,1]];
function isWall(x, y) { return map[Math.floor(y/32)][Math.floor(x/32)] === 1; }
30s Blits-Nazorat

`map[row][col]` da qaysi biri Y va qaysi biri X? Javob: row — qator (Y / vertikal), col — ustun (X / gorizontal)!

INLINE SVG · TIZIM SXEMASI

2D Massivdan Ekrandagi Canvas Piksellarigacha

Matritsaning qatori (row) Y o'qiga, ustuni (col) esa X o'qiga ko'paytiriladi: col * TILE_SIZE. O'ngdagi kataklarni bosib ko'ring!

👆 Ekranda istalgan katakni bosing: devor (1) va yo'l (0) o'zgaradi!
ALGORITM · RENDER

Ichma-ich Sikllar: Matritsani Chizuvchi Dvigatel

Xaritani ekranga chiqarish uchun ikkita sikl kerak: qatorlar bo'ylab (row) va ustunlar bo'ylab (col).

const TILE_SIZE = 32;

function drawMap(ctx, map) {{
  for (let row = 0; row < map.length; row++) {{
    for (let col = 0; col < map[row].length; col++) {{
      const tile = map[row][col];
      if (tile === 1) {{
        ctx.fillStyle = "#4A5568";  // Tosh devor
        ctx.fillRect(col * TILE_SIZE, row * TILE_SIZE, TILE_SIZE, TILE_SIZE);
      }} else if (tile === 2) {{
        ctx.fillStyle = "#ECC94B";  // Oltin tanga
        ctx.fillRect(col * TILE_SIZE + 10, row * TILE_SIZE + 10, 12, 12);
      }}
    }}
  }}
}}
FIZIKA OPTIMIZATSIYASI

Piksellar AABB To'qnashuvi vs Panjara To'qnashuvi (O(1))

1-Chorakda o'rgangan to'rtburchaklar to'qnashuvi (AABB) 1000 ta devorda o'yinni qotirib qo'yadi. Tilemap esa 1 ta amal bilan yechadi!

Har bir devorni tekshirish: O(N)

1000 devor = har kadrda 1000 ta if

Dushmanlar va o'qlar ko'payishi bilan kompyuter qotishni (FPS pasayishi) boshlaydi.

Bitta katakni tekshirish: O(1)

map[nextRow][nextCol] === 1

O'yinchi qadam bosayotgan joy devormi? Koordinatani 32 ga bo'lamiz va darhol bilamiz!

CHEGARA XATOLARI

Klassik Xatolik: 'Cannot read properties of undefined'

Agar o'yinchi xaritadan tashqariga (masalan, row = -1) chiqishga urinsa, JavaScript darhol qulaydi.

Xavfli Kod (Himoyasiz)
function canMove(row, col) {{
  return map[row][col] !== 1;
}}

Agar row = -1 bo'lsa, map[-1] undefined beradi va dastur butunlay to'xtab qoladi!

Xavfsiz Qalqon (Guarded)
function isWalkable(row, col) {{
  if (row < 0 || row >= map.length) return false;
  if (col < 0 || col >= map[0].length) return false;
  return map[row][col] !== 1;
}}

Avval massiv chegaralarini tekshiramiz, keyin katakka murojaat qilamiz. Crash xavfi nol!

KIBER-TEST · BILIMNI TEKSHIRISH

Viktorina: O'yinchi Pikselini Matritsa Katagiga Qanday Aylantiramiz?

O'yinchi piksel koordinatasi: player.x = 75, player.y = 100. TILE_SIZE = 32. O'yinchi qaysi katakda turibdi?

A) col = player.x * 32, row = player.y * 32 (Ko'paytirish)
B) col = Math.floor(player.x / 32), row = Math.floor(player.y / 32) (Bo'lish va pastga yaxlitlash)
C) col = player.x + 32, row = player.y + 32 (Qo'shish)
D) col = player.x % 32, row = player.y % 32 (Qoldiq)
To'g'ri javob: B!

Chunki 75 / 32 = 2.34 -> Math.floor uni 2 ga yaxlitlaydi (col = 2). 100 / 32 = 3.12 -> uni 3 ga yaxlitlaydi (row = 3). Demak, qahramon map[3][2] katagida joylashgan!
