Matritsalar va Xaritalar (Tilemaps) — Mustaqil Amaliy Vazifa

2D massivlar, ichma-ich render sikllari, panjara indeksi formulasi va $O(1)$ to'qnashuv fizikasi.

Topshiriq 1

1. Piksellarni Matritsa Indeksiga Aylantirish

2.5 Ball

Tayl o'lchami 32 piksel bo'lgan o'yinda qahramon koordinatasi: player.x = 210, player.y = 145. Formulani yozing va qahramon turgan aniq row va col indekslarini hisoblab bering.

Etalon Yechim:

Formulalar: col = Math.floor(player.x / 32); row = Math.floor(player.y / 32);
Hisob: col = Math.floor(210 / 32) = 6;
row = Math.floor(145 / 32) = 4.
Qahramon map[4][6] katagida joylashgan!

Topshiriq 2

2. To'qnashuv Tezligi: O(1) va O(N) ning Asosiy Farqi

2.5 Ball

Nima uchun 2000 ta to'siqni AABB to'rtburchaklar bilan tekshirish o'yinni qotirib qo'yadi, lekin Tilemap panjarasida map[row][col] tekshiruvi O(1) vaqtda bir zumda bajariladi?

Etalon Yechim:

AABB usulida dvigatel har bir kadrda (sekundiga 60 marta) 2000 ta devorni for siklida tekshirishi kerak. Tilemapda esa sikl umuman aylanmaydi: o'yinchining kelgusi qadami formuladan to'g'ridan-to'g'ri massiv manziliga (O(1)) boradi va bitta operatsiyada yechiladi.

Topshiriq 3

3. Xatolikdan Qalqon: Massiv Chegaralarini Tekshirish

2.5 Ball

O'yinchi xaritadan tashqariga chiqib ketganda 'Cannot read properties of undefined' xatoligi chiqmasligi uchun to'liq xavfsiz canMove(map, row, col) funksiyasi kodini yozing.

Etalon Yechim:

function canMove(map, row, col) {
  if (row < 0 || row >= map.length) return false;
  if (col < 0 || col >= map[0].length) return false;
  return map[row][col] !== 1;
}

Topshiriq 4

4. Dinamik Devorni Buzish: Massivni Jonli O'zgartirish

2.5 Ball

O'yinda devor buzilganda (masalan, bomba portlaganda yoki o'yinchi toshni qaziganda) ushbu devor bo'sh yo'lga aylanishi uchun massiv qaysi kod bilan yangilanadi va ekranda qanday aks etadi?

Etalon Yechim:

Shunchaki: map[row][col] = 0; buyrug'ini berish kifoya. Keyingi kadrda drawMap() funksiyasi ushbu katakda 0 ni ko'radi va devor o'rniga qora pol chizadi. Qahramon esa to'siqsiz o'tib ketadi!
