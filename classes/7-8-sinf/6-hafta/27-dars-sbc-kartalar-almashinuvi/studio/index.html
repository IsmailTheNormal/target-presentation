reduce, filter, every, Set

SBC mexanikasi geym-dizaynda murakkab cheklovlarni qanoatlantirish (Constraint Satisfaction) hisoblanadi. Har bir talab matematik predikat funksiya sifatida ifodalanadi.

// 1. Tarkib O'rtacha OVR Reytingini hisoblash (Array.prototype.reduce) const calcTeamOvr = (squad) => { if (squad.length === 0) return 0; const totalOvr = squad.reduce((sum, player) => sum + player.ovr, 0); return Math.floor(totalOvr / squad.length); }; // 2. Noyob Ligalar sonini hisoblash (Set orqali duplikatlarni tozalash) const countUniqueLeagues = (squad) => { const leagues = squad.map(p => p.league); return new Set(leagues).size; }; // 3. Muayyan liga yoki millatdagi o'yinchilar soni (Array.prototype.filter) const countByLeague = (squad, targetLeague) => { return squad.filter(p => p.league === targetLeague).length; }; // 4. Har bir talabning bajarilishini tekshirish (Array.prototype.every) const isSbcCompleted = (squad, rules) => { return rules.every(rule => rule.check(squad) === true); };
