JAVASCRIPT ALGORITMLARI

Predikatlar va Array.prototype.filter()

Dasturlashda predikat nima?

Predikat — bu har bir element uchun rost (true) yoki yolg'on (false) qiymat qaytaruvchi mantiqiy funksiya.

filter() metodi massivdagi har bir elementni predikatdan o'tkazib, faqat true qaytarganlarini yangi massivga yig'adi.

// Talab: Min 3 ta APL o'yinchisi const isEpl = (p) => p.league === "Premier League"; const eplPlayers = squad.filter(isEpl); if (eplPlayers.length >= 3) { console.log("APL sharti bajarildi! ✓"); }

Algoritmik murakkablik: O(n), bu yerda n = 11

Predikatlar orqali shartlar tushunarli va xatosiz tekshiriladi
JAMOA REYTINGI

Array.prototype.reduce() orqali OVR Hisoblash

Jamoaviy OVR qanday hisoblanadi?

SBC shartlarida eng ko'p uchraydigan talab: "Min. Squad OVR: 84".

Biz 11 ta o'yinchining OVR qiymatlarini yig'indisini topib, 11 ga bo'lamiz.

Formula: Avg OVR = Math.floor(Σ OVR / 11)

// reduce yordamida yig'indini hisoblash const totalOvr = squad.reduce((accumulator, player) => { return accumulator + player.ovr; }, 0); const teamOvr = Math.floor(totalOvr / 11); const isOvrValid = teamOvr >= challenge.minOvr;

Akkumulyator har qadamda summani o'zida to'playdi

reduce() massivni yagona qiymatga (skalyarga) keltiruvchi asosiy metod
NOYOB QIYMATLAR

Set To'plamlari: Takrorlanmas Ligalar va Millatlar

JavaScript da Set nima?

Set — faqat noyob (takrorlanmas) qiymatlarni saqlaydigan to'plam. Agar bir xil liganing 5 ta o'yinchisi kelsa ham, Set ichida u faqat 1 marta hisoblanadi.

Xususiyat: set.size to'plamdagi noyob elementlar sonini beradi!

// Shart: Min 3 xil Liga va Min 4 xil Millat const leagues = squad.map(p => p.league); const uniqueLeaguesCount = new Set(leagues).size; const nations = squad.map(p => p.nation); const uniqueNationsCount = new Set(nations).size; const isHybridValid = uniqueLeaguesCount >= 3 && uniqueNationsCount >= 4;

Set duplikatlarni avtomatik ravishda O(n) vaqtda yo'qotadi

Set — gibrid talablarni tekshirish uchun eng qulay ma'lumotlar tuzilmasi
YAXLIT TEKSHIRUV

Array.prototype.every() va Yakuniy Qaror

'Submit' tugmasi qachon faollashadi?

SBC da bitta shart bajarilmasa ham tarkib topshirilmaydi. Mantiqiy "VA" (AND - &&) operatori barcha talablar bajarilishini talab qiladi.

Qoida: rules.every(r => r.check(squad) === true)

// Qoidalar massivi const rules = [ { name: "Count", check: sq => sq.length === 11 }, { name: "OVR", check: sq => getOvr(sq) >= 84 }, { name: "EPL", check: sq => getEpl(sq) >= 3 }, { name: "Chem", check: sq => getChem(sq) >= 18 } ]; const canSubmit = rules.every(rule => rule.check(squad)); submitButton.disabled = !canSubmit;
every() birinchi xatoda tekshiruvni to'xtatadi (resursni tejaydi)
