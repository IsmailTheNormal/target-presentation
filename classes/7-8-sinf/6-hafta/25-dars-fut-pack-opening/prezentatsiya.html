Dasturda Kumulyativ Taqsimot Funksiyasi (CDF)

Kompyuter faqat 0.0 dan 0.999... gacha tasodifiy o'nlik son qaytaradi (`Math.random()`). Buni turli noyoblikdagi kartalar bilan qanday bog'lash mumkin?

// Oraliqlar taqsimoti (Cumulative Probability Mapping) // [0.000 — 0.005) → 0.5% → ICON (90+ OVR) // [0.005 — 0.050) → 4.5% → WALKOUT STAR (86-89 OVR) // [0.050 — 0.250) → 20.0% → RARE GOLD (82-85 OVR) // [0.250 — 1.000) → 75.0% → COMMON GOLD (75-81 OVR)
📐 Nega aynan kumulyativ yig'indi?

Chunki barcha hodisalar ehtimolligi yig'indisi qat'iy 100% (1.0) ga teng. Bosqichma-bosqich oshib boruvchi chegara orqali tekshirish (`< 0.005`, so'ng `< 0.05`) chalkashlikni yo'qotadi.

❌ O'yinchilarning Xato Tushunchasi:

"Icon chiqish ehtimoli 1%. Agar men 100 ta paket ochsam, menga 100% kafolat bilan Icon chiqadi!" — bu qo'pol matematik xatodir.

✔️ Haqiqiy Matematik Formula:

100 ta urinishda bitta ham karta CHIQMASLIK ehtimoli: (0.99)100 ≈ 36.6%! Ya'ni har 3 nafar o'yinchidan bittasi barcha tangalarini yo'qotadi!
