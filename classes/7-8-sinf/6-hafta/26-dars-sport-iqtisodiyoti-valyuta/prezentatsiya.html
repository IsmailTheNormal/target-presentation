MUVOZANAT TENGLAMASI • MATEMATIKA

Virtual Valyuta Muvozanati Formulasi

Markaziy bankning bosh vazifasi — tangalarning kirishi (Inflow) va chiqib ketishi (Outflow) o'rtasida tenglikni saqlashdir:

// Iqtisodiy o'sish tenglamasi (Net Money Delta) ΔMoneySupply = Daily_Minting - Daily_Sinks; // Agar ΔMoneySupply > 0 → Inflyatsiya! Narxlar qimmatlaydi. // Agar ΔMoneySupply < 0 → Deflyatsiya! Narxlar tushadi. // Agar ΔMoneySupply ≈ 0 → BARQAROR BOZOR (Ideal Equilibrium)!
🟢 Kirish Manbalari (Minting):

O'yin mukofotlari, haftalik bonuslar, turnir yutuqlari va sovg'alar.

🔴 Yoqish Manbalari (Coin Sinks):

5% transfer solig'i, do'kondan paket ochish (-54% yoqiladi), turnir badallari.

// Tranzaksiyani hisoblash kodi (Database Transaction) let salePrice = 100000; // 100,000 tanga let taxAmount = Math.round(salePrice * 0.05); // 5,000 tanga YO'Q BO'LDI! let sellerPayout = salePrice - taxAmount; // Sotuvchi 95,000 oladi // Natija: Butun iqtisodiyotdan 5,000 tanga yoqildi (Deflationary pressure).

ISTE'MOL NARXLARI INDEKSI • CPI

Inflyatsiyani Qanday O'lchash Kerak: Narxlar Indeksi (CPI)

Iqtisodchilar har hafta "10 ta Eng Ommabop O'yinchi Savati" (Meta Basket) qiymatini monitoring qilib boradilar:

// Inflyatsiya formulasini hisoblash let baseBasketPrice = 125000; // 1-kun narxi let currentBasketPrice = getCurrentBasketSum(); // Bugungi narx let CPI = (currentBasketPrice / baseBasketPrice) * 100; // CPI == 100% → Narxlar o'zgarmagan (Ideal holat) // CPI == 150% → Narxlar 50% ga qimmatlagan (Inflyatsiya xavfi) // CPI == 80% → Narxlar 20% ga arzonlagan (Deflyatsiya xavfi)
Yashil Xavfsiz Hudud (95% — 110%):

Ideal muvozanat. O'yinchilar maqbul vaqt ichida yangi o'yinchilarni sotib ola biladilar.

Qizil Xavfli Hudud (> 130%):

Bozorda tanga haddan tashqari ko'p. Soliqni oshirish yoki jozibador paketlar chiqarish shart.
