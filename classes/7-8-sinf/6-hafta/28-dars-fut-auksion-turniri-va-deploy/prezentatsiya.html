O'YINLAR NAZARIYASI VA AUKSION

'G'olibning Qarzi' (Winner's Curse) Tuzog'i

Winner's Curse nima?

Auksionda g'olib bo'lgan kishi ko'pincha eng yuqori baho bergan bo'ladi. Agar siz raqobatchilardan qizishib ketib, kartaning real qiymatidan 2 barobar ko'p to'lasangiz — siz yutasiz, lekin byudjetingiz tugab bankrot bo'lasiz!

Oltin qoida: Har bir pozitsiya uchun maksimal narx chegarasini (Cap) oldindan belgilang!

1-5-5 Savdo Strategiyasi:

  • 1 Superyulduz (Mbappé yoki Haaland): Byudjetning 30%
  • 5 ta Asosiy Tayanch (87–89 OVR): Byudjetning 50%
  • 5 ta Taktik Tejamkor (84–86 OVR): Byudjetning 20%

Muvozanatli tarkib bitta yakkaxon yulduzdan ancha kuchliroq!

Moliyaviy intizom g'alabaning 80 foizini belgilaydi

O'YIN SIMULYATSIYASI

Turnir Match Engine: OVR va Ehtimollik

Bosqichdagi g'alaba formulasi:

Gol urish ehtimolligi har bir jamoaning OVR reytingi va jamoaviy kimyosiga asoslanadi:

P(Goal) = (TeamOVR + Chem * 0.2) / (OppOVR + OppChem * 0.2 + 50)

Hatto kuchli jamoa ham stoxastik dispersiya tufayli gol o'tkazib yuborishi mumkin.

// 90 daqiqalik stoxastik simulyatsiya function simulatePlayoff(teamA, teamB) { let scoreA = 0, scoreB = 0; for (let min = 1; min <= 90; min += 15) { if (Math.random() < calcGoalProb(teamA, teamB)) scoreA++; if (Math.random() < calcGoalProb(teamB, teamA)) scoreB++; } return { scoreA, scoreB }; }
Aniq matematika stadionning jonli hayajoniga aylanadi
