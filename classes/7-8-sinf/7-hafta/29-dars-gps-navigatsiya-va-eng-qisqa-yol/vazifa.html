2-Topshiriq: Dijkstra Algoritmi Bo'yicha Eng Qisqa Yo'lni Hisoblash

Yuqoridagi 1-topshiriq grafigidan foydalanib, Maktabdan (A) Stadionga (D) borishning eng qisqa yo'lini Dijkstra algoritmi qadamma-qadam tahlili asosida toping: Yo'l A ➔ B ➔ D qancha masofa bo'ladi? Yo'l A ➔ B ➔ C ➔ D qancha bo'ladi? Eng optimal marshrut qaysi?

DIJKSTRA TAHLILI:
1. 1-variant: A ➔ B ➔ D = 500m + 600m = 1100 metr.
2. 2-variant: A ➔ C ➔ D = 800m + 400m = 1200 metr.
3. 3-variant: A ➔ B ➔ C ➔ D = 500m + 300m + 400m = 1200 metr.
Xulosa: Eng qisqa va tez yo'l: A ➔ B ➔ D (1100 metr).

3-Topshiriq: Haversine Sferik Masofa Formulasi

Yer yuzidagi ikki GPS nuqta: (lat1, lon1) va (lat2, lon2) orasidagi masofani hisoblovchi JavaScript funksiyasini yozing. Nega oddiy tekislikdagi Pifagor formulasidan ko'ra Haversine formulasi aniqroq ekanligini tushuntiring.

HAVERSINE FORMULASI KODI:
function haversine(lat1, lon1, lat2, lon2) {
  const R = 6371; // km
  const toRad = deg => deg * Math.PI / 180;
  const dLat = toRad(lat2 - lat1);
  const dLon = toRad(lon2 - lon1);
  const a = Math.sin(dLat/2)**2 + Math.cos(toRad(lat1)) * Math.cos(toRad(lat2)) * Math.sin(dLon/2)**2;
  return R * 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1-a));
}
Sababi: Yer tekis emas, balki sferik shar shaklida.

4-Topshiriq: HTML5 Geolocation API Integratsiyasi

Brauzerda tugma bosilganda foydalanuvchining joriy kenglik va uzunlik koordinatalarini ekranga chiqaruvchi va agar foydalanuvchi ruxsat bermasa xatoni ushlovchi to'liq JavaScript kodini yozing.

GEOLOCATION KODI:
function getMyGPS() {
  if (!navigator.geolocation) return alert('GPS qo\'llab-quvvatlanmaydi');
  navigator.geolocation.getCurrentPosition(
    pos => {
      console.log('Kenglik:', pos.coords.latitude, 'Uzunlik:', pos.coords.longitude);
    },
    err => {
      console.error('Geolokatsiyaga ruxsat berilmadi:', err.message);
    },
    { enableHighAccuracy: true, timeout: 5000 }
  );
}
