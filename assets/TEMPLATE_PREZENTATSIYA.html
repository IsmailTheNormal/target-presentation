⚠️ Keng Tarqalgan Xato (Pitfall)

O'quvchilar ko'p hollarda asinxron funksiyalarda await kalit so'zini unutib, ma'lumot o'rniga Promise obyektini qaytardilar.

// ❌ Xato yechim:
const data = fetchData(); // [object Promise]

✅ Oltin Yechim (Golden Standard)

Asinxron chaqiriq har doim await bilan kutib olinadi va try/catch bloki ichida xavfsiz o'raladi.

// ✅ To'g'ri yechim:
const data = await fetchData();

⚡ 30 Soniyalik Blitz Tekshiruv

Savol: Nima uchun Promise statusi 'pending' bo'lib qoladi? Javob: Asinxron jarayon hali yakunlanmaganligi sababli.

Asosiy Mexanizm

Tizimning Fundamental Arxitekturasi

Deterministik dasturlash va Agentik fikrlash o'rtasidagi asosiy farqlar hamda ularning o'zaro bog'liqligi.

1. Thought (Fikr)

LLM kiruvchi holatni tahlil qilib, navbatdagi qaysi vositani ishlatish kerakligini rejalashtiradi.

2. Action (Harakat)

Model JSON Schema formatida parametrlar bilan tashqi funksiyani chaqiradi.

3. Observation (Kuzatuv)

Tizim qaytargan javob agent kontekstiga tushadi va sikl yakuniy xulosagacha davom etadi.

Jonli Bilim Sinovi

Kiber-Sinov: Qaysi Qismda Xatolik Mavjud?

Doskada yoki qurilmangizda to'g'ri variantni tanlang va yechim tahlilini oching.

Savol: ReAct tsiklida cheksiz aylanib qolmaslik (Infinite Loop) uchun qanday cheklov qo'yilishi shart?

A) Faqat bitta vosita (single tool) ishlatish
B) Maksimal qadamlar chegarasi (max_iterations) va Loop Guard qo'yish
C) Model haroratini (temperature) 1.0 ga ko'tarish
Tahlil va Standart:

To'g'ri javob: B. Agar vosita xato qaytarsa yoki agent maqsadga erisha olmasa, u cheksiz tsiklga tushib qolishi mumkin. Shuning uchun muhandislik standartlarida doimo max_iterations = 10 chegarasi qo'yiladi.
